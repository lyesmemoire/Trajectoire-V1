Ce document définit ce que le candidat doit ressentir à chaque étape de son parcours avec Trajectoire.

# COURBE ÉMOTIONNELLE GLOBALE

## Phase 1 : Découverte (Session 1)

- **Émotion dominante** : Curiosité
- **Évolution** : Curiosité → Intérêt → Engagement
- **Objectif** : Créer l'engagement
- **Durée** : 1 session

## Phase 2 : Apprentissage (Sessions 2-4)

- **Émotion dominante** : Défi constructif
- **Évolution** : Défi → Réflexion → Satisfaction
- **Objectif** : Construire les compétences
- **Durée** : 3 sessions

## Phase 3 : Consolidation (Sessions 5-7)

- **Émotion dominante** : Confiance croissante
- **Évolution** : Confiance → Satisfaction → Fierté
- **Objectif** : Renforcer la confiance
- **Durée** : 3 sessions

## Phase 4 : Transformation (Session 8+)

- **Émotion dominante** : Confiance professionnelle
- **Évolution** : Confiance → Sérénité → Ambition
- **Objectif** : Transformer la relation professionnelle
- **Durée** : Continue

---

# PRINCIPES ÉMOTIONNELS

## Principe 1 : Progression émotionnelle

Chaque session doit faire progresser l'état émotionnel du candidat vers plus de confiance et de sérénité.

## Principe 2 : Respect des émotions

Le candidat a le droit de ressentir ce qu'il ressent. Trajectoire ne nie jamais ses émotions.

## Principe 3 : Transformation positive

Les émotions difficiles (anxiété, doute) doivent être transformées en émotions positives (confiance, sérénité).

## Principe 4 : Authenticité

Les émotions doivent être authentiques. Trajectoire ne crée jamais de fausses émotions.

## Principe 5 : Durabilité

Les émotions positives doivent devenir durables, pas seulement temporaires.

---

# CONCLUSION

L'empreinte émotionnelle de Trajectoire est conçue pour transformer le candidat.

Avant : Curiosité, scepticisme, légère anxiété.

Pendant : Intérêt, engagement, défi constructif, réflexion.

Après : Confiance, sérénité, fierté, espérance.

Après plusieurs semaines : Confiance durable, sérénité, motivation.

Après plusieurs mois : Confiance professionnelle, ambition, gratitude.

C'est cette transformation qui est l'objectif ultime de Trajectoire.
