## Scénarios

### Junior Backend

**Description** : Entretien pour un développeur backend junior (0-2 ans d'expérience).

**Configuration**
- **Planner** : Focus sur les fondamentaux (data structures, algorithms, basic backend concepts)
- **Director** : Adaptatif, tolérant à l'imprécision, encourageant
- **Persona** : Google (curieux et intellectuel)
- **Difficulty** : Faible (questions simples, guidance fréquent)
- **Evaluation** : Focus sur le potentiel et l'apprentissage
- **ATS** : Analyse du CV vs Junior Backend requirements
- **Memory** : Apprentissage initial, peu de contexte
- **Learning** : Mode apprentissage, feedback fréquent

**Compétences évaluées**
- Data structures (arrays, lists, maps, sets)
- Algorithms (sorting, searching, basic recursion)
- Backend basics (HTTP, REST, databases)
- Problem solving (basic)
- Communication (clarté)

**Questions types**
- "Parlez-moi d'un projet que vous avez réalisé."
- "Comment implémenteriez-vous X ?"
- "Quelle est la différence entre Y et Z ?"
- "Comment résoudriez-vous ce problème ?"

**Durée** : 45 minutes

## Conclusion

Le Scenario Library définit tous les scénarios d'entretien, chacun configurant automatiquement le Planner, le Director, la Persona, la Difficulty, l'Evaluation, l'ATS, la Memory et le Learning.

Les points clés sont :
1. **17 scénarios** : Junior Backend, Senior Backend, Lead Backend, Principal Engineer, Staff Engineer, CTO, Startup, Consulting, Product Manager, HR Screening, Incident Production, System Design, Architecture Review, Live Coding, Behavioral, Salary Negotiation
2. **Configuration automatique** : Chaque scénario configure 8 paramètres (Planner, Director, Persona, Difficulty, Evaluation, ATS, Memory, Learning)
3. **Compétences évaluées** : Chaque scénario évalue des compétences spécifiques
4. **Questions types** : Chaque scénario a des questions types
5. **Durée** : Chaque scénario a une durée spécifique

Ce document doit être utilisé comme référence pour l'implémentation du Planner et du Director.
