# MVP-001 — CV Intelligence

## Identité

MVP-001 EST LE PREMIER MODULE DU MVP DU MOTEUR COGNITIF RH.

MVP-001 EST CONFORME À RFC-ARCHITECTURE-BASELINE-V1.

MVP-001 EST CONFORME À RFC-RH-004 CV KNOWLEDGE MODEL.

MVP-001 UTILISE LE KNOWLEDGE PACK KP-001 ET KP-002.

MVP-001 ALIMENTE LES RUNTIMES EXISTANTS.

## Objectif

DÉMONTRER LA CAPACITÉ DU MOTEUR COGNITIF À IMPORTER UN CV, EXTRAIRE LES CONNAISSANCES, LES NORMALISER ET CONSTRUIRE UN GRAPHE DE CONNAISSANCES CANDIDAT.

## Fonctionnalités

### 1. Import d'un CV

- SUPPORTER LES FORMATS PDF ET DOCX
- EXTRAIRE LE TEXTE BRUT
- EXTRAIRE LA STRUCTURE DU DOCUMENT
- GÉRER LES ERREURS D'IMPORT

### 2. Extraction des connaissances

IDENTIFIER ET EXTRAIRE :

- INFORMATIONS PERSONNELLES (nom, prénom, email, téléphone, adresse)
- EXPÉRIENCES PROFESSIONNELLES (poste, entreprise, durée, responsabilités)
- FORMATION (diplôme, établissement, année, domaine)
- COMPÉTENCES (hard skills, soft skills)
- CERTIFICATIONS (nom, organisme, date)
- LANGUES (langue, niveau)
- CENTRES D'INTÉRÊT

### 3. Normalisation avec KP-001 et KP-002

- NORMALISER LES INTITULÉS DE POSTES AVEC KP-001
- NORMALISER LES COMPÉTENCES AVEC KP-002
- UTILISER LES SYNONYMES POUR LA RECONNAISSANCE
- ASSIGNER LES NIVEAUX DE COMPÉTENCES
- DÉTECTER LES COMPÉTENCES TRANSFÉRABLES

### 4. Construction du graphe de connaissances

ALIMENTER LES RUNTIMES :

- ENTITY RUNTIME : CRÉER LES ENTITÉS CANDIDAT, EXPÉRIENCE, FORMATION, COMPÉTENCE
- ATTRIBUTE RUNTIME : ASSIGNER LES ATTRIBUTS À CHAQUE ENTITÉ
- RELATIONSHIP RUNTIME : CRÉER LES RELATIONS ENTRE ENTITÉS
- SEMANTIC GRAPH RUNTIME : CONSTRUIRE LE GRAPHE SÉMANTIQUE DU CANDIDAT

### 5. Identification des éléments

IDENTIFIER :

- LES MÉTIERS DU CANDIDAT
- LES COMPÉTENCES DU CANDIDAT
- LES DIPLÔMES DU CANDIDAT
- LES CERTIFICATIONS DU CANDIDAT
- LES NIVEAUX D'EXPÉRIENCE

### 6. Génération de la fiche candidat normalisée

PRODUIRE UNE FICHE CANDIDAT STRUCTURÉE CONTENANT :

- INFORMATIONS PERSONNELLES NORMALISÉES
- EXPÉRIENCES NORMALISÉES
- FORMATION NORMALISÉE
- COMPÉTENCES NORMALISÉES
- CERTIFICATIONS NORMALISÉES
- SCORES DE PROFIL

## Architecture

### Composants

- CV IMPORT SERVICE : SERVICE D'IMPORT DE CV
- KNOWLEDGE EXTRACTOR : EXTRACTEUR DE CONNAISSANCES
- NORMALIZER : NORMALISATEUR AVEC KP-001 ET KP-002
- GRAPH BUILDER : CONSTRUCTEUR DE GRAPHE
- ENTITY RUNTIME : RUNTIME D'ENTITÉS
- ATTRIBUTE RUNTIME : RUNTIME D'ATTRIBUTS
- RELATIONSHIP RUNTIME : RUNTIME DE RELATIONS
- SEMANTIC GRAPH RUNTIME : RUNTIME DE GRAPHE SÉMANTIQUE

### Flux de données

```
CV (PDF/DOCX)
    ↓
CV IMPORT SERVICE
    ↓
TEXTE BRUT + STRUCTURE
    ↓
KNOWLEDGE EXTRACTOR
    ↓
DONNÉES BRUTES
    ↓
NORMALIZER (KP-001, KP-002)
    ↓
DONNÉES NORMALISÉES
    ↓
GRAPH BUILDER
    ↓
ENTITY RUNTIME → ATTRIBUTE RUNTIME → RELATIONSHIP RUNTIME
    ↓
SEMANTIC GRAPH RUNTIME
    ↓
FICHE CANDIDAT NORMALISÉE
```

## Critères d'acceptation

### Critère 1 : Import réussi

LE CV DOIT ÊTRE IMPORTÉ AVEC SUCCÈS DANS LES FORMATS PDF ET DOCX.

### Critère 2 : Extraction précise

LES CONNAISSANCES DOIVENT ÊTRE EXTRAITES AVEC UNE PRÉCISION ≥ 80%.

### Critère 3 : Normalisation correcte

LES INTITULÉS DE POSTES ET COMPÉTENCES DOIVENT ÊTRE NORMALISÉS AVEC KP-001 ET KP-002.

### Critère 4 : Graphe construit

LE GRAPHE DE CONNAISSANCES DOIT ÊTRE CONSTRUIT DANS LES RUNTIMES.

### Critère 5 : Fiche générée

LA FICHE CANDIDAT NORMALISÉE DOIT ÊTRE GÉNÉRÉE AVEC SUCCÈS.
