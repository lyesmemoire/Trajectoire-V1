# 📘 Product Language Guidelines — StudioEntretien.fr

## Règle d'Or

Si un terme ressemble à une conférence technique sur l'IA ou à un diagnostic clinique, il doit être supprimé ou remplacé.

| Terme INTERDIT      | Remplaçant OBLIGATOIRE  | Justification              |
| :------------------ | :---------------------- | :------------------------- |
| Behavioral Analysis | Conseils                | Trop clinique / Intimidant |
| Cognitive Pressure  | Stress                  | Jargon inutile             |
| DNA Profile         | Votre style             | Trop abstrait              |
| Adaptive Scoring    | Évaluation              | Trop "machine"             |
| Emotional Mapping   | Ressenti                | Trop "laboratoire"         |
| Verbosity Index     | Longueur des réponses   | Trop technique             |
| Ownership Ratio     | Prise de responsabilité | Manque de clarté           |

## Ton de Voix

- **Calme** : Pas d'exclamations inutiles.
- **Professionnel** : Un mentor, pas un assistant.
- **Précis** : Une action claire par feedback.
- **Protecteur** : Reconstruire la confiance après l'effort.
