# RH-120 — Salarié

## Identité

RH-120 EST LE DOCUMENT MÉTIER DÉFINISSANT LE SALARIÉ RH.

RH-120 EST LA SOURCE OFFICIELLE DE CONNAISSANCE POUR LE SALARIÉ.

RH-120 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LE SALARIÉ.

RH-120 EST LA RÉFÉRENCE NORMATIVE POUR TOUT SALARIÉ.

## Définitions

### Salarié

UN SALARIÉ EST UNE PERSONNE PHYSIQUE LIÉE À L'ORGANISATION PAR UN CONTRAT DE TRAVAIL.

LE SALARIÉ EST SOUMIS AU DROIT DU TRAVAIL.

LE SALARIÉ EST SOUMIS AUX CONVENTIONS COLLECTIVES.

LE SALARIÉ EST SOUMIS AUX ACCORDS D'ENTREPRISE.

LE SALARIÉ EST SOUMIS AU RÈGLEMENT INTÉRIEUR.

LE SALARIÉ REÇOIT UNE RÉMUNÉRATION EN ÉCHANGE DE SON TRAVAIL.

### Employé

UN EMPLOYÉ EST UN SALARIÉ DE L'ORGANISATION.

L'EMPLOYÉ EST UTILISÉ COMME TERME GÉNÉRIQUE.

L'EMPLOYÉ INCLUT LES CADRES.

L'EMPLOYÉ INCLUT LES NON-CADRES.

L'EMPLOYÉ INCLUT LES AGENTS DE MAÎTRISE.

L'EMPLOYÉ INCLUT LES OUVRIERS.

### Cadre

UN CADRE EST UN SALARIÉ AYANT UN STATUT DE CADRE.

LE CADRE EST SOUMIS À DES RÈGLES SPÉCIFIQUES.

LE CADRE EST SOUMIS À DES CONVENTIONS SPÉCIFIQUES.

LE CADRE EST SOUMIS À DES ACCORDS SPÉCIFIQUES.

LE CADRE EST CLASSÉ DANS LA CONVENTION COLLECTIVE.

### Non-cadre

UN NON-CADRE EST UN SALARIÉ N'AYANT PAS LE STATUT DE CADRE.

LE NON-CADRE EST SOUMIS À DES RÈGLES SPÉCIFIQUES.

LE NON-CADRE EST SOUMIS À DES CONVENTIONS SPÉCIFIQUES.

LE NON-CADRE EST SOUMIS À DES ACCORDS SPÉCIFIQUES.

LE NON-CADRE EST CLASSÉ DANS LA CONVENTION COLLECTIVE.
