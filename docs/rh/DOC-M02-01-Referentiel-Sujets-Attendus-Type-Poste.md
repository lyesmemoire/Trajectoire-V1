## 1. Objectif

Définir le référentiel des sujets attendus par type de poste pour le MVP-META-02 Silence Intelligence Engine. Ce document structure les sujets qu'un candidat légitime mentionne naturellement pour 10 types de postes RH.

---

## 2. Principe Fondateur

Pour chaque type de poste, le moteur maintient une liste des sujets qu'un candidat légitime mentionne naturellement. L'absence de ces sujets dans un entretien peut révéler une lacune, un évitement ou une inadéquation.

---

## 3. Structure du Référentiel

Pour chaque type de poste, les sujets sont classés en 3 catégories :

**Catégorie A — Sujets presque toujours mentionnés :**
Sujets qu'un vrai professionnel du poste mentionne spontanément dans 90%+ des cas.

**Catégorie B — Sujets souvent mentionnés :**
Sujets mentionnés dans 60-90% des cas par des candidats légitimes.

**Catégorie C — Sujets mentionnés par les meilleurs profils :**
Sujets qui distinguent les candidats d'excellence (mentionnés dans 30-60% des cas, mais par les meilleurs).

---

## 4. Référentiel par Type de Poste

### 4.1 POSTE 1 — DRH (Directeur des Ressources Humaines)

**Catégorie A — Sujets presque toujours mentionnés :**
- Son équipe RH (composition, taille, structure)
- Son DG ou directeur de rattachement
- Le CSE et les relations sociales
- La politique salariale (principes, enjeux)
- Le recrutement (volumes, enjeux, processus)
- La formation et le développement des talents
- Les enjeux RH de l'entreprise (challenges actuels)
- Les outils RH utilisés (SIRH, ATS, etc.)
- Les résultats obtenus (avec chiffres : turnover, satisfaction, etc.)

**Catégorie B — Sujets souvent mentionnés :**
- Les transformations RH conduites
- Les conflits gérés (relations sociales, individuels)
- Les projets transversaux menés
- Le budget RH (montant, gestion)
- Les partenaires sociaux (syndicats, négociations)
- La culture d'entreprise
- La diversité et l'inclusion

**Catégorie C — Sujets mentionnés par les meilleurs profils :**
- La vision RH de l'entreprise (alignement avec la stratégie)
- L'alignement RH / stratégie business
- Les indicateurs de performance RH (KPIs, tableaux de bord)
- L'impact business des décisions RH (ROI des initiatives)
- La transformation digitale RH
- L'employer branding
- La marque employeur

## 6. Stockage et Gestion

### 6.1 Schéma SQL

```sql
CREATE TABLE expected_topics (
  id VARCHAR(36) PRIMARY KEY,
  position_type VARCHAR(50) NOT NULL,
  
  category_a JSON NOT NULL,
  category_b JSON NOT NULL,
  category_c JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_expected_topics_position ON expected_topics(position_type);

CREATE TABLE expected_topics_library (
  id VARCHAR(36) PRIMARY KEY,
  
  positions JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
