## 1. Objectif

Définir la bibliothèque de validation émotionnelle pour MVP-036 Active Listening Engine. Cette bibliothèque contient 50 situations où le candidat exprime quelque chose d'émotionnellement chargé et les réponses de validation appropriées pour montrer de l'empathie avant de passer à la question suivante.

---

## 2. Principe Fondateur

Quand le candidat exprime quelque chose d'émotionnellement chargé (un échec, une difficulté, une peur), le moteur ne passe pas directement à la question suivante. Il valide d'abord l'émotion. La réponse froide (machine) est "Question suivante." La réponse chaleureuse (DRH humain) valide l'émotion avant de continuer.

## 5. Stockage et Gestion

### 5.1 Schéma SQL

```sql
CREATE TABLE emotional_validation (
  id VARCHAR(36) PRIMARY KEY,
  category VARCHAR(50) NOT NULL,
  
  situation TEXT NOT NULL,
  cold_response TEXT NOT NULL,
  warm_response TEXT NOT NULL,
  
  emotion VARCHAR(50) NOT NULL,
  validation TEXT NOT NULL,
  transition TEXT NOT NULL,
  
  persona_adaptation JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_emotional_validation_category ON emotional_validation(category);

CREATE TABLE emotional_validation_library (
  id VARCHAR(36) PRIMARY KEY,
  
  categories JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
