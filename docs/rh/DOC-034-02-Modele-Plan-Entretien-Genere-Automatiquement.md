## 1. Objectif

Définir le modèle de plan d'entretien généré automatiquement pour MVP-034 Interview Orchestrator. Ce modèle structure la génération automatique d'un plan d'entretien personnalisé pour chaque candidat, chaque poste, et chaque contexte, basé sur l'analyse des documents et les patterns de la mémoire institutionnelle.

---

## 2. Principe Fondateur

Chaque entretien est unique. Le plan d'entretien doit être personnalisé pour CE candidat, CE poste, dans CE contexte. Le moteur génère automatiquement ce plan en analysant les documents, en identifiant les zones d'ombre, et en proposant des questions ciblées basées sur les patterns de la mémoire institutionnelle.

### 3.4 Objectifs par Acte

**Acte 1 — Ouverture :**
- Créer un cadre de confiance
- Présenter le déroulé de l'entretien
- Observer le candidat en mode naturel
- Calibrer le niveau d'aise initial
- Poser les bases de la relation

**Acte 2 — Exploration :**
- Comprendre la trajectoire réelle
- Valider les compétences clés
- Identifier les patterns de comportement
- Détecter les signaux positifs et vigilances
- Construire une image cohérente du parcours

**Acte 3 — Approfondissement :**
- Explorer les soft skills en profondeur
- Évaluer la personnalité professionnelle
- Tester les valeurs et motivations réelles
- Évaluer le culture fit
- Explorer le potentiel long terme

**Acte 4 — Challenge :**
- Tester la réaction sous pression
- Explorer les zones d'ombre identifiées
- Vérifier la cohérence sous stress
- Évaluer la résilience réelle
- Clarifier les points ambigus restants

**Acte 5 — Clôture :**
- Donner la parole au candidat
- Observer ses vraies questions
- Conclure la relation positivement
- Informer sur les suites
- Collecter les dernières observations

### 3.5 5 Questions Incontournables

**Question N°1 — Parcours :**
```
[Question spécifique basée sur le CV et les zones d'ombre]
Exemple : "Vous avez mentionné une expérience chez X.
         Parlez-moi de la décision qui vous a amené à quitter
         cette entreprise pour rejoindre Y."
```

**Question N°2 — Compétence Clé 1 :**
```
[Question STAR ciblée sur la compétence la plus critique]
Exemple : "Donnez-moi un exemple d'une situation où vous avez
         dû [compétence clé]. Quelle était la situation ?
         Qu'avez-vous fait ? Quel a été le résultat ?"
```

**Question N°3 — Soft Skill Critique :**
```
[Question comportementale sur le soft skill le plus critique]
Exemple : "Racontez-moi une fois où vous avez dû faire preuve
         de [soft skill]. Comment avez-vous réagi ?"
```

**Question N°4 — Motivation :**
```
[Question projectionnelle sur les motivations profondes]
Exemple : "Dans 5 ans, qu'est-ce que vous voulez avoir accompli
         professionnellement ? Pourquoi ?"
```

**Question N°5 — Culture Fit :**
```
[Question sur l'environnement de travail idéal]
Exemple : "Décrivez le manager idéal pour vous. Pourquoi ?"
```

### 3.9 Adaptations Recommandées

**Si le candidat est très à l'aise :**
- Augmenter le niveau de challenge
- Explorer davantage les zones d'ombre
- Questions plus directes

**Si le candidat est stressé :**
- Réduire le niveau de challenge
- Commencer par des questions plus simples
- Créer plus de cadre de confiance

**Si le candidat est expansif :**
- Structurer davantage les échanges
- Ramener aux faits concrets
- Limiter les digressions

**Si le candidat est réservé :**
- Donner plus de temps de réflexion
- Questions plus ouvertes
- Encourager l'expression

## 5. Stockage et Gestion

### 5.1 Schéma SQL

```sql
CREATE TABLE interview_plan (
  id VARCHAR(36) PRIMARY KEY,
  interview_id VARCHAR(36) NOT NULL,
  
  header JSON NOT NULL,
  candidate_analysis JSON NOT NULL,
  time_allocation JSON NOT NULL,
  objectives_by_act JSON NOT NULL,
  must_ask_questions JSON NOT NULL,
  destabilizing_questions JSON NOT NULL,
  signals_to_watch JSON NOT NULL,
  decision_criteria JSON NOT NULL,
  recommended_adaptations JSON NOT NULL,
  recruiter_notes JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  FOREIGN KEY (interview_id) REFERENCES interview(id)
);

CREATE INDEX idx_interview_plan_interview ON interview_plan(interview_id);
CREATE INDEX idx_interview_plan_status ON interview_plan((metadata->>'$.status'));
```
