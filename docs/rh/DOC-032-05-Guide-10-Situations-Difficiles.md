## 1. Objectif

Définir le guide des 10 situations difficiles les plus fréquentes en entretien avec les stratégies recommandées pour MVP-032 Conversational Intelligence Engine. Ce guide fournit au recruteur des stratégies éprouvées pour gérer les situations conversationnelles difficiles et transformer les défis en opportunités d'évaluation.

---

## 2. Principe Fondateur

Un maître RH sait gérer les situations difficiles avec calme et bienveillance. Chaque situation difficile est une opportunité d'évaluer le candidat sous un angle différent. Le guide fournit des stratégies spécifiques pour chaque situation, permettant au recruteur de transformer les défis en moments d'évaluation précieux.

---

## 3. Les 10 Situations Difficiles

### 3.1 Situation 1 — Le Candidat qui Parle Trop

**Symptôme :**
Réponses de 5 minutes à des questions simples. Le recruteur perd le contrôle du temps et de la direction de l'entretien.

**Stratégie :**
Interruption bienveillante et structurante. L'interruption doit être respectueuse mais ferme pour reprendre le contrôle.

**Rebond recommandé :**
```
"Je vous arrête un instant.
En une phrase : quel était le résultat principal de cette action ?
Ensuite, nous pourrons revenir sur les détails si nécessaire."
```

**Variante :**
```
"Merci pour ces détails.
Pour aller plus vite : quel a été l'impact principal de cette action ?"
```

**Tone :** Structurant, bienveillant

**Ce que cela évalue :**
- Capacité à synthétiser
- Conscience de l'impact
- Respect du temps d'autrui

---

### 3.2 Situation 2 — Le Candidat qui Parle Trop Peu

**Symptôme :**
Réponses de 10 mots à des questions ouvertes. L'entretien ne produit pas d'information suffisante pour évaluer le candidat.

**Stratégie :**
Questions très ouvertes et bienveillantes. Reformulation de l'invitation à développer avec un ton patient et encourageant.

**Rebond recommandé :**
```
"Prenez le temps qu'il faut.
Je voudrais vraiment comprendre ce qui s'est passé.
Décrivez-moi la situation en détail,
avec le contexte et votre action."
```

**Variante :**
```
"Je sens que vous hésitez.
Il n'y a pas de bonne ou de mauvaise réponse.
Je veux simplement comprendre votre approche.
Prenez votre temps."
```

**Tone :** Bienveillant, patient

**Ce que cela évalue :**
- Capacité à développer une pensée
- Niveau de confiance
- Communication sous pression

---

### 3.3 Situation 3 — Le Candidat qui Challenge le Recruteur

**Symptôme :**
"Pourquoi vous me posez cette question ?"
"Quelle est la réponse que vous cherchez ?"
Le candidat met en question la légitimité du recruteur.

**Stratégie :**
Ne pas se défendre. Ne pas céder. Rester calme et expliquer l'objectif de la question sans se justifier excessivement.

**Rebond recommandé :**
```
"Excellente question.
Je cherche à comprendre comment vous gérez [situation X].
Il n'y a pas de bonne réponse attendue.
Je veux simplement comprendre votre approche."
```

**Variante :**
```
"C'est une question légitime.
Cette question me permet d'évaluer [dimension].
Il n'y a pas de piège, juste une volonté de comprendre."
```

**Tone :** Calme, explicatif

**Ce que cela évalue :**
- Intelligence émotionnelle
- Capacité à gérer l'autorité
- Communication dans l'adversité

---

### 3.4 Situation 4 — Le Candidat Sur-préparé

**Symptôme :**
Réponses parfaites et identiques à des questions classiques. Aucune spontanéité. Le candidat semble réciter un script.

**Stratégie :**
Questions inattendues hors script. Questions sur des situations très spécifiques qu'on ne peut pas préparer. Briser le pattern pour voir la vraie personne.

**Rebond recommandé :**
```
"Vos réponses sont très structurées.
Je vais vous poser une question différente :
parlez-moi d'une situation où vous avez échoué.
Qu'avez-vous appris de cet échec ?"
```

**Variante :**
```
"Changeons de rythme.
Parlez-moi d'une décision que vous avez regrettée.
Pourquoi l'avez-vous prise ?
Que feriez-vous différemment aujourd'hui ?"
```

**Tone :** Direct, inattendu

**Ce que cela évalue :**
- Authenticité
- Capacité à improviser
- Gestion de l'échec

---

### 3.5 Situation 5 — Le Candidat Émotionnellement Submergé

**Symptôme :**
Stress visible qui empêche de donner le meilleur de soi. Tremblements, bégaiements, sueurs, respiration rapide.

**Stratégie :**
Pause. Désescalade. Recentrage bienveillant. Créer un espace sécurisant pour permettre au candidat de se calmer.

**Rebond recommandé :**
```
"Prenez un moment.
L'entretien n'est pas une compétition.
Je cherche à vous connaître, pas à vous piéger.
Respirez, prenez votre temps."
```

**Variante :**
```
"Je vois que vous êtes stressé.
C'est tout à fait normal.
Prenez une pause de 30 secondes.
Respirez profondément.
On reprend quand vous serez prêt."
```

**Tone :** Empathique, rassurant

**Ce que cela évalue :**
- Résilience
- Capacité à gérer le stress
- Intelligence émotionnelle

---

### 3.6 Situation 6 — Le Candidat qui Critique ses Anciens Employeurs

**Symptôme :**
Discours négatif récurrent sur les anciens managers et entreprises. Le candidat se positionne en victime.

**Stratégie :**
Ne pas valider ni invalider. Creuser pour distinguer critique légitime et ponctuelle vs pattern systémique problématique. Orienter vers l'apprentissage.

**Rebond recommandé :**
```
"Qu'est-ce que vous avez appris
de cette expérience difficile ?
Comment cela a-t-il influencé votre façon
de travailler aujourd'hui ?"
```

**Variante :**
```
"Je comprends que cela a été difficile.
Comment avez-vous réagi dans l'instant ?
Qu'auriez-vous pu faire différemment ?"
```

**Tone :** Constructif, orienté apprentissage

**Ce que cela évalue :**
- Responsabilité personnelle
- Capacité à apprendre
- Intelligence relationnelle

---

### 3.7 Situation 7 — Le Silence Total du Candidat

**Symptôme :**
Le candidat ne sait pas quoi répondre. Silence long et inconfortable. Le candidat semble bloqué.

**Stratégie :**
Laisser le silence 5 secondes. Si silence long : reformuler la question de manière plus simple. Si toujours rien : reformuler en exemple concret.

**Rebond recommandé (après 5 secondes) :**
```
"Je reformule : [version plus simple de la question]
Prenez le temps qu'il faut."
```

**Variante (si toujours rien) :**
```
"Par exemple, dans une situation comme X,
comment réagiriez-vous ?"
```

**Tone :** Patient, simplificateur

**Ce que cela évalue :**
- Capacité à gérer l'incertitude
- Flexibilité cognitive
- Communication sous pression

---

### 3.8 Situation 8 — Le Candidat qui Donne des Réponses Trop Génériques

**Symptôme :**
"Je suis quelqu'un de rigoureux et orienté résultats."
Aucun exemple. Aucun fait. Que des clichés et des qualités génériques.

**Stratégie :**
Demander systématiquement l'exemple concret. Refuser les réponses sans fait. Insister sur la contextualisation.

**Rebond recommandé :**
```
"Donnez-moi un exemple précis
qui illustre ce que vous dites.
Une situation réelle, récente,
où vous avez fait preuve de cette rigueur."
```

**Variante :**
```
"C'est une qualité importante.
Mais pour que je puisse l'évaluer,
j'ai besoin d'un exemple concret.
Parlez-moi d'une situation spécifique."
```

**Tone :** Direct, factuel

**Ce que cela évalue :**
- Capacité à contextualiser
- Conscience de soi
- Communication précise

---

### 3.9 Situation 9 — Le Candidat qui Ment (Probablement)

**Symptôme :**
Incohérence entre le CV et les mots. Dates qui ne correspondent pas. Réponses qui changent quand on repose la même question différemment.

**Stratégie :**
Ne pas accuser. Creuser factuellement. Faire remarquer l'incohérence de manière neutre et laisser le candidat l'expliquer.

**Rebond recommandé :**
```
"Aidez-moi à comprendre.
Votre CV indique X.
Et vous venez de dire Y.
Comment ces deux éléments s'articulent-ils ?"
```

**Variante :**
```
"Je note une différence entre ce que vous avez dit
et ce que j'ai dans votre CV.
Pouvez-vous m'aider à comprendre cette différence ?"
```

**Tone :** Neutre, factuel

**Ce que cela évalue :**
- Intégrité
- Capacité à gérer l'incohérence
- Communication sous pression

---

### 3.10 Situation 10 — Le Candidat Exceptionnel qui Surprend

**Symptôme :**
Le candidat dépasse les attentes. Ses réponses révèlent quelque chose d'inattendu et de remarquable. Le candidat montre une qualité rare.

**Stratégie :**
Ne pas rester sur la grille. Explorer ce territoire inattendu. S'adapter au candidat et creuser ce qui le rend exceptionnel.

**Rebond recommandé :**
```
"Ce que vous venez de dire est intéressant.
Je voudrais explorer cela davantage.
Parlez-moi de..."
```

**Variante :**
```
"C'est une perspective originale.
Je veux comprendre comment vous avez développé cette approche.
Pouvez-vous me donner un autre exemple ?"
```

**Tone :** Curieux, enthousiaste

**Ce que cela évalue :**
- Originalité
- Capacité à penser différemment
- Potentiel exceptionnel

## 4. Structure de Données (TypeScript)

```typescript
interface DifficultSituation {
  situationId: string;
  situationNumber: number;
  
  title: string;
  symptoms: string[];
  
  strategy: {
    description: string;
    approach: string;
  };
  
  recommendedRebound: {
    formulation: string;
    tone: string;
  };
  
  alternativeRebound?: {
    formulation: string;
    tone: string;
  };
  
  whatItEvaluates: string[];
  
  metadata: {
    createdAt: Date;
    version: string;
    usageCount: number;
    effectivenessScore: number;
  };
}

interface DifficultSituationsGuide {
  guideId: string;
  version: string;
  createdAt: Date;
  
  situations: DifficultSituation[];
  
  classification: {
    bySymptom: {
      [symptom: string]: DifficultSituation[];
    };
    byStrategy: {
      [strategy: string]: DifficultSituation[];
    };
  };
  
  metadata: {
    totalSituations: number;
    lastUpdated: Date;
  };
}
```

## 5. Stockage et Gestion

### 5.1 Schéma SQL

```sql
CREATE TABLE difficulty_situation (
  id VARCHAR(36) PRIMARY KEY,
  situation_number INT NOT NULL UNIQUE,
  
  title VARCHAR(255) NOT NULL,
  symptoms JSON NOT NULL,
  strategy JSON NOT NULL,
  recommended_rebound JSON NOT NULL,
  alternative_rebound JSON,
  what_it_evaluates JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_difficulty_situation_number ON difficulty_situation(situation_number);

CREATE TABLE difficulty_situations_guide (
  id VARCHAR(36) PRIMARY KEY,
  version VARCHAR(50) NOT NULL,
  created_at TIMESTAMP NOT NULL,
  
  situations JSON NOT NULL,
  classification JSON NOT NULL,
  metadata JSON NOT NULL,
  
  UNIQUE KEY idx_difficulty_situations_guide_version (version)
);
```
