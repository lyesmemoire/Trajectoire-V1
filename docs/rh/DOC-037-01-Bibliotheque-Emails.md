## 1. Objectif

Définir la bibliothèque d'emails pour MVP-037 Candidate Experience Engine. Cette bibliothèque contient 20 templates d'emails couvrant toutes les situations de communication avec le candidat, de l'invitation à l'entretien jusqu'à la décision finale, en passant par le feedback et l'enquête de satisfaction.

---

## 2. Principe Fondateur

L'entretien ne commence pas quand le candidat ouvre sa bouche. Il commence quand il reçoit l'invitation à l'entretien. Il se termine quand il reçoit la décision finale. Tout ce qui se passe entre ces deux moments est l'expérience candidat. Un grand cabinet mondial soigne chaque micro-moment de cette expérience.

## 6. Situations Spéciales

### 6.1 Situation 15 — Enquête de Satisfaction Candidat

**Contexte :** Enquête 24h après la décision

**Template :**
```
Bonjour [Prénom],

J'espère que vous allez bien.

Afin d'améliorer notre processus de recrutement, nous aimerions avoir votre retour sur votre expérience.

Cette enquête ne prend que 2 minutes :

1. Avez-vous senti que votre profil a été vraiment évalué ? (1 à 5)
2. L'entretien vous a-t-il semblé professionnel et bienveillant ? (1 à 5)
3. Recommanderiez-vous ce processus à un pair ? (NPS 0 à 10)

Un mot pour décrire votre expérience :
[votre réponse]

Merci pour votre temps et votre feedback.

Bien à vous,
[Persona DRH]
[Poste]
[Entreprise]
```

## 8. Stockage et Gestion

### 8.1 Schéma SQL

```sql
CREATE TABLE email_template (
  id VARCHAR(36) PRIMARY KEY,
  situation VARCHAR(255) NOT NULL,
  phase VARCHAR(50) NOT NULL,
  
  subject VARCHAR(255) NOT NULL,
  body TEXT NOT NULL,
  
  variables JSON NOT NULL,
  persona_adaptation JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_email_template_phase ON email_template(phase);
CREATE INDEX idx_email_template_situation ON email_template(situation);

CREATE TABLE email_library (
  id VARCHAR(36) PRIMARY KEY,
  
  phases JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 11. Conclusion

La bibliothèque d'emails contient 20 templates couvrant toutes les situations de communication avec le candidat, de l'invitation à l'entretien jusqu'à la décision finale. Les emails sont organisés en 4 phases (avant l'entretien, après l'entretien, feedback, situations spéciales) et sont adaptés selon le persona.

**Points clés :**
- 20 templates d'emails pour 20 situations différentes
- Phase 1 : Avant l'entretien (5 situations)
- Phase 3 : Après l'entretien (5 situations)
- Feedback candidat : 4 niveaux (4 situations)
- Situations spéciales (6 situations)
- Adaptation par persona (4 personas)
- Structure de données TypeScript
- Stockage et gestion SQL
- API endpoints pour la gestion
- Métriques d'utilisation et de qualité
