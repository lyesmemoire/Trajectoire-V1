# DOC-M02-03 : Questions Révélatrices Associées à Chaque Silence

**Version:** 1.0  
**Date:** 2026-08-04

---

## 1. Objectif

Définir les questions révélatrices associées à chaque silence pour le MVP-META-02 Silence Intelligence Engine. Ce document structure les questions à poser pour révéler ce que le silence cache.

---

## 2. Principe Fondateur

Chaque silence a une question révélatrice associée. La formulation de la question est essentielle pour obtenir une réponse qui révèle la vérité derrière le silence.

---

## 3. Questions Révélatrices par Silence

### 3.1 SILENCE 1 — Sur le Manager

**Question principale :**
"Vous ne m'avez pas parlé de votre manager chez [entreprise]. Comment décririez-vous cette relation ?"

**Variantes :**
- "Quelle était la nature de votre relation avec votre manager chez [entreprise] ?"
- "Comment travailliez-vous avec votre manager dans votre poste précédent ?"
- "Pouvez-vous me décrire votre manager et votre relation de travail ?"

**Conseils de formulation :**
- Nommer explicitement l'entreprise pour contextualiser
- Utiliser le passé pour éviter la défensive
- Formuler de manière ouverte pour encourager la sincérité

**Ce que la réponse révèle :**
- Réponse fluide et positive → Relation normale, sujet non saillant
- Hésitation puis généralités → Relation difficile minimisée
- Critique directe → Conflit ouvert
- Refus de commenter → Signal fort de problème

---

### 3.2 SILENCE 2 — Sur les Collègues

**Question principale :**
"Dans vos projets, avec qui travailliez-vous principalement ? Décrivez-moi une collaboration qui vous a marqué."

**Variantes :**
- "Comment collaborez-vous avec vos collègues dans votre travail quotidien ?"
- "Pouvez-vous me donner un exemple de collaboration réussie avec une équipe ?"
- "Quelle est votre manière de travailler avec les autres sur vos projets ?"

**Conseils de formulation :**
- Demander un exemple concret pour éviter les généralités
- Utiliser le passé pour contextualiser
- Formuler de manière positive pour encourager le partage

**Ce que la réponse révèle :**
- Réponse détaillée sur les collaborations → Capacité relationnelle
- Réponse vague ou évasive → Difficulté relationnelle ou travail en silo
- Insistance sur le travail individuel → Orientation solitaire

---

### 3.3 SILENCE 3 — Sur les Chiffres

**Question principale :**
"Quel est le résultat dont vous êtes le plus fier ? Chiffrez-le pour moi."

**Variantes :**
- "Pouvez-vous me donner un exemple de résultat chiffré que vous avez obtenu ?"
- "Quels indicateurs utilisez-vous pour mesurer votre performance ?"
- "Comment mesurez-vous le succès de vos projets ? Donnez-moi des chiffres."

**Conseils de formulation :**
- Demander explicitement des chiffres
- Lier la demande à un résultat positif pour réduire la résistance
- Formuler de manière directe pour obtenir une réponse précise

**Ce que la réponse révèle :**
- Réponse chiffrée spontanée → Orientation résultats
- Difficulté à chiffrer → Orientation processus ou résultats peu significatifs
- Refus de chiffrer → Résultats à cacher

---

### 3.4 SILENCE 4 — Sur l'Entreprise Actuelle

**Question principale :**
"Qu'est-ce que vous appréciez le plus dans votre entreprise actuelle ?"

**Variantes :**
- "Qu'avez-vous aimé chez votre employeur actuel ?"
- "Quels sont les aspects positifs de votre entreprise actuelle ?"
- "Pourquoi restez-vous chez votre employeur actuel depuis [X] ans ?"

**Conseils de formulation :**
- Formuler de manière positive pour éviter la critique
- Demander ce qui est apprécié, pas ce qui n'est pas
- Lier à la durée pour contextualiser

**Ce que la réponse révèle :**
- Réponse positive → Relation saine avec l'employeur
- Difficulté à trouver du positif → Départ conflictuel probable
- Critiques uniquement → Risque de discours négatif après départ

**Variantes :**
- "Quelle est la difficulté la plus importante que vous ayez rencontrée ?"

**Conseils de formulation :**
- Normaliser l'existence de difficultés pour réduire la défensive
- Lier à l'apprentissage pour valoriser la croissance

**Ce que la réponse révèle :**
- Réponse honnête sur un échec → Capacité de recul et d'apprentissage
- Réponse évasive → Peur du jugement ou manque de recul
- Refus d'admettre un échec → Perfectionnisme défensif

```typescript
  silenceId: string;

  mainQuestion: string;
  variants: string[];
  
  formulationTips: string[];
  responseRevelations: {
    positiveResponse: string;
    vagueResponse: string;
    refusalResponse: string;
  };
  
  metadata: {
    version: string;
    createdAt: Date;
    lastUpdated: Date;
  };
}

interface RevealingQuestionsLibrary {
  libraryId: string;
  
  questions: RevealingQuestion[];
  
  categories: {
    professional: string[];
    personal: string[];
    relational: string[];
    results: string[];
  };
  
  metadata: {
    version: string;
    createdAt: Date;
    lastUpdated: Date;
  };
}
```

## 5. Stockage et Gestion

### 5.1 Schéma SQL

```sql
CREATE TABLE revealing_question (
  id VARCHAR(36) PRIMARY KEY,
  silence_id VARCHAR(36) NOT NULL,
  silence_name VARCHAR(100) NOT NULL,
  
  main_question TEXT NOT NULL,
  variants JSON NOT NULL,
  formulation_tips JSON NOT NULL,
  response_revelations JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_revealing_question_silence ON revealing_question(silence_id);

CREATE TABLE revealing_questions_library (
  id VARCHAR(36) PRIMARY KEY,
  
  questions JSON NOT NULL,
  categories JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
