## 1. Objectif

Définir la spécification de l'avatar vidéo pour MVP-035 Voice & Avatar Authenticity. Ce document structure les caractéristiques de l'avatar DRH photo-réaliste pour les entretiens en visioconférence, incluant les expressions faciales adaptatives, le langage corporel simulé, le contact visuel, et le niveau de réalisme cible.

---

## 2. Principe Fondateur

L'avatar vidéo est optionnel et doit être photo-réaliste. Le candidat ne doit pas être certain qu'il parle à une IA. Il doit vivre l'expérience d'un entretien avec un humain professionnel. L'avatar doit avoir des expressions faciales adaptatives, un langage corporel simulé, et maintenir un contact visuel naturel.

---

## 3. Avatar DRH Photo-Réaliste

### 3.1 Caractéristiques Visuelles

**Apparence générale :**
- Photo-réalisme élevé
- Ressemblance à un humain professionnel
- Âge et style adaptés au persona
- Vêtements professionnels appropriés
- Environnement de bureau réaliste

**Paramètres techniques :**
- Résolution : 1080p minimum
- FPS : 30 FPS minimum
- Latence : < 200 ms
- Synchronisation audio-vidéo : < 50 ms

### 3.2 Expressions Faciales Adaptatives

**Expressions d'écoute :**
- Hochements de tête pendant l'écoute
- Sourires discrets sur les bonnes réponses
- Légère interrogation sur les flous
- Approbation discrète sur les preuves
- Concentration visible pendant les réponses longues

**Expressions d'intérêt :**
- Sourires plus marqués sur les réponses pertinentes
- Yeux légèrement élargis sur les points intéressants
- Inclinaison de tête vers l'avant
- Contact visuel maintenu

**Expressions de réflexion :**
- Légère contraction des sourcils
- Regard vers le haut ou sur le côté
- Main sur le menton (simulée)
- Pause dans les mouvements

**Expressions de challenge :**
- Regard direct et intense
- Légère contraction des sourcils
- Posture plus rigide
- Contact visuel maintenu

### 3.3 Micro-Expressions Authentiques

**Micro-expressions positives :**
- Sourire de Duchenne (yeux et bouche)
- Légère ouverture des yeux
- Relâchement des muscles faciaux
- Légère inclinaison de tête

**Micro-expressions neutres :**
- Expression calme et professionnelle
- Yeux ouverts normalement
- Muscles faciaux relâchés
- Posture neutre

**Micro-expressions négatives :**
- Légère contraction des sourcils
- Léger plissement des yeux
- Légère tension des muscles faciaux
- Posture plus rigide

### 3.4 Langage Corporel Simulé

**Posture :**
- Attentive et ouverte
- Légère inclinaison vers l'avant pour les questions importantes
- Recul léger pour les questions de challenge
- Mouvements subtils et naturels

**Gestes :**
- Prise de notes visible
- Gestes de la main pour accompagner la parole
- Hochements de tête
- Inclinaisons de tête

**Mouvements :**
- Mouvements subtils et naturels
- Pas de mouvements répétitifs
- Pas de mouvements robotiques
- Variabilité naturelle

### 3.5 Contact Visuel

**Maintien du contact visuel :**
- Contact visuel maintenu pendant les réponses
- Légères pauses naturelles
- Regard vers les notes simulées
- Retour au contact visuel rapide

**Variation du contact visuel :**
- Contact visuel plus intense pour les questions importantes
- Contact visuel plus léger pour les transitions
- Contact visuel maintenu pour les réponses courtes
- Contact visuel variable pour les réponses longues

## 5. Niveau de Réalisme Cible

### 5.1 Objectif de Réalisme

**Le candidat ne doit pas être certain qu'il parle à une IA :**
- L'avatar doit être indiscernable d'un humain professionnel
- Les expressions doivent être naturelles et variées
- Les mouvements doivent être fluides et non robotiques
- Le synchronisme audio-vidéo doit être parfait

### 5.2 Critères de Réalisme

**Critères visuels :**
- Photo-réalisme : ≥ 4.5/5
- Expressions naturelles : ≥ 4.5/5
- Mouvements fluides : ≥ 4.5/5
- Synchronisme audio-vidéo : ≥ 4.5/5

**Critères comportementaux :**
- Contact visuel naturel : ≥ 4.5/5
- Langage corporel naturel : ≥ 4.5/5
- Variabilité des expressions : ≥ 4.5/5
- Adaptation au contexte : ≥ 4.5/5

### 5.3 Avertissement Éthique Obligatoire

**Avant l'entretien, le candidat doit être informé :**
- "Vous allez interagir avec un système assisté par IA."
- "Ce système utilise un avatar vidéo photo-réaliste."
- "La transparence est non négociable."
- Réf. RH-000 Charte Fondatrice

**L'avatar ne doit pas :**
- Tromper le candidat sur sa nature
- Se faire passer pour un humain sans information préalable
- Utiliser une ressemblance avec une personne réelle sans consentement
- Violer la vie privée ou l'image d'une personne

## 7. Stockage et Gestion

### 7.1 Schéma SQL

```sql
CREATE TABLE video_avatar (
  id VARCHAR(36) PRIMARY KEY,
  persona_id VARCHAR(36) NOT NULL,
  
  visual_characteristics JSON NOT NULL,
  facial_expressions JSON NOT NULL,
  micro_expressions JSON NOT NULL,
  body_language JSON NOT NULL,
  eye_contact JSON NOT NULL,
  realism_target JSON NOT NULL,
  ethical_warning JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  FOREIGN KEY (persona_id) REFERENCES vocal_persona(id)
);

CREATE INDEX idx_video_avatar_persona ON video_avatar(persona_id);
```
