# RH-100 — Recrutement

## Identité

RH-100 EST LE DOCUMENT MÉTIER DÉFINISSANT LE RECRUTEMENT RH.

RH-100 EST LA SOURCE OFFICIELLE DE CONNAISSANCE POUR LE RECRUTEMENT.

RH-100 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LE RECRUTEMENT.

RH-100 EST LA RÉFÉRENCE NORMATIVE POUR TOUT PROCESSUS DE RECRUTEMENT.

## Définitions

### Recrutement

LE RECRUTEMENT EST LE PROCESSUS D'ACQUISITION DE TALENTS.

LE RECRUTEMENT EST UN PROCESSUS STRUCTURÉ.

LE RECRUTEMENT EST UN PROCESSUS DOCUMENTÉ.

LE RECRUTEMENT EST UN PROCESSUS MESURÉ.

LE RECRUTEMENT EST UN PROCESSUS ÉVALUÉ.

### Besoin de recrutement

LE BESOIN DE RECRUTEMENT EST LA NÉCESSITÉ D'ACQUÉRIR UN NOUVEL EMPLOYÉ.

LE BESOIN DE RECRUTEMENT EST IDENTIFIÉ PAR LE DÉPARTEMENT.

LE BESOIN DE RECRUTEMENT EST VALIDÉ PAR LES RESSOURCES HUMAINES.

LE BESOIN DE RECRUTEMENT EST JUSTIFIÉ PAR DES CRITÈRES OBJECTIFS.

### Candidat

UN CANDIDAT EST UNE PERSONNE QUI POSTULE À UN POSTE.

LE CANDIDAT EST ÉVALUÉ SUR SES COMPÉTENCES.

LE CANDIDAT EST ÉVALUÉ SUR SES QUALIFICATIONS.

LE CANDIDAT EST ÉVALUÉ SUR SON EXPÉRIENCE.

LE CANDIDAT EST PROTÉGÉ PAR LE DROIT DU TRAVAIL.

### Offre d'emploi

L'OFFRE D'EMPLOI EST UNE PROPOSITION DE CONTRAT.

L'OFFRE D'EMPLOI EST FAITE AU CANDIDAT SÉLECTIONNÉ.

L'OFFRE D'EMPLOI INCLUT LES CONDITIONS DE TRAVAIL.

L'OFFRE D'EMPLOI INCLUT LA RÉMUNÉRATION.

L'OFFRE D'EMPLOI EST DOCUMENTÉE.

L'OFFRE D'EMPLOI EST SIGNÉE PAR LES DEUX PARTIES.
