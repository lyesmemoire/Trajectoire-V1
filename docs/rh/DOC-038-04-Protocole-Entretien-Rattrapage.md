## 1. Objectif

Définir le protocole d'entretien de rattrapage pour MVP-038 Stress Management Engine. Ce document structure le processus pour offrir un second entretien court dans un format différent aux candidats qui ont été fortement stressés pendant l'entretien initial, afin d'obtenir une évaluation juste.

---

## 2. Principe Fondateur

Si un candidat a été fortement stressé pendant l'entretien, son évaluation peut être sous-estimée. Le candidat ne doit pas être pénalisé pour son stress si son profil mérite d'être réévalué. Le moteur alerte le recruteur et recommande d'offrir un second entretien court dans un format différent avant de décider.

---

## 3. Déclenchement du Protocole

### 3.1 Critères de Déclenchement

**Niveau de stress élevé :**
- Niveau de stress détecté : 3 ou 4
- Durée du stress élevé : Plus de 50% de l'entretien
- Échec des protocoles de désescalade : Stress non réduit

**Profil méritant :**
- Score de matching initial : ≥ 70/100
- Expérience pertinente : Correspond au poste
- Compétences clés : Présentes dans le CV

**Disponibilité du candidat :**
- Candidat toujours intéressé
- Disponibilité pour un second entretien
- Consentement explicite

### 3.2 Alerte au Recruteur

**Message d'alerte :**
```
ALERTE : Stress Élevé Détecté

Candidat : [Nom]
Entretien : [Date]
Niveau de stress : 3 ou 4
Durée du stress élevé : [X]%

Ce candidat présentait un niveau de stress élevé pendant l'entretien.
Son évaluation peut être sous-estimée.

Recommandation : Offrir un second entretien court dans un format différent avant de décider.

Profil méritant : Oui/Non
Score de matching : [X]/100
```

### 3.3 Décision du Recruteur

**Options :**
- Accepter la recommandation : Offrir un second entretien
- Rejeter la recommandation : Décider sur l'entretien initial
- Demander plus d'informations : Analyser plus en détail

**Validation :**
- Le recruteur doit valider la recommandation
- Le recruteur peut ajuster les paramètres du second entretien
- Le recruteur peut refuser si le profil n'est pas méritant

## 4. Format du Second Entretien

### 4.1 Formats Possibles

**Format 1 — Entretien téléphonique :**
- Durée : 20-30 minutes
- Avantage : Moins stressant que présentiel/visio
- Adapté pour : Candidats très stressés en présentiel/visio

**Format 2 — Entretien visio avec caméra désactivée :**
- Durée : 20-30 minutes
- Avantage : Moins stressant que caméra activée
- Adapté pour : Candidats stressés par la caméra

**Format 3 — Entretien écrit asynchrone :**
- Durée : 30-45 minutes
- Avantage : Pas de pression temps réel
- Adapté pour : Candidats très bloqués

**Format 4 — Entretien en présentiel dans un environnement différent :**
- Durée : 30-40 minutes
- Avantage : Environnement plus détendu
- Adapté pour : Candidats stressés par l'environnement initial

### 4.2 Sélection du Format

**Critères de sélection :**
- Niveau de stress initial
- Format de l'entretien initial
- Préférence du candidat
- Disponibilité du recruteur

**Algorithme de sélection :**
- Si entretien initial = présentiel → Téléphonique ou visio caméra désactivée
- Si entretien initial = visio → Téléphonique ou écrit asynchrone
- Si entretien initial = téléphonique → Écrit asynchrone
- Si stress très élevé → Écrit asynchrone

## 5. Plan du Second Entretien

### 5.1 Objectifs

**Objectif principal :**
- Obtenir une évaluation juste du candidat
- Révéler le vrai candidat, pas le candidat stressé
- Confirmer ou infirmer le potentiel du candidat

**Objectifs secondaires :**
- Évaluer les compétences clés non évaluées
- Valider les compétences évaluées
- Obtenir des exemples concrets

### 5.2 Structure

**Introduction (5 minutes) :**
- Accueil chaleureux
- Explication du format
- Rassurement sur le but de l'entretien
- Normalisation de la situation

**Questions faciles (5-10 minutes) :**
- Questions très ouvertes et positives
- Questions sur les motivations
- Questions sur les réussites
- Reconstruction de la confiance

**Questions adaptées (10-15 minutes) :**
- Questions simplifiées sur les compétences clés
- Questions adaptées au format
- Questions ciblées sur les domaines non évalués

**Conclusion (5 minutes) :**
- Récapitulatif
- Questions du candidat
- Prochaines étapes

### 5.3 Questions

**Questions d'introduction :**
- "Comment allez-vous aujourd'hui ?"
- "Avez-vous eu le temps de réfléchir à notre dernier échange ?"
- "Avez-vous des questions sur le processus ?"

**Questions faciles :**
- "Qu'est-ce qui vous a donné envie de postuler pour ce poste ?"
- "Qu'est-ce que vous aimez dans votre métier actuel ?"
- "Parlez-moi d'une réussite dont vous êtes fier."

**Questions adaptées :**
- Selon les compétences clés non évaluées
- Simplifiées par rapport à l'entretien initial
- Adaptées au format sélectionné

## 6. Adaptation selon le Format

### 6.1 Entretien Téléphonique

**Adaptations :**
- Ton plus chaleureux et rassurant
- Rythme plus lent
- Plus de pauses
- Questions plus ouvertes

**Avantages :**
- Moins stressant que présentiel/visio
- Plus intime
- Permet de se concentrer sur la voix

**Inconvénients :**
- Pas de communication non-verbale
- Difficile d'évaluer certaines compétences

### 6.2 Entretien Visio avec Caméra Désactivée

**Adaptations :**
- Ton plus chaleureux
- Rythme normal
- Questions adaptées au format audio

**Avantages :**
- Moins stressant que caméra activée
- Permet de partager des écrans si nécessaire
- Communication vocale

**Inconvénients :**
- Pas de communication non-verbale visuelle
- Difficile d'évaluer certaines compétences

### 6.3 Entretien Écrit Asynchrone

**Adaptations :**
- Questions plus détaillées
- Temps de réponse illimité
- Possibilité de reformuler

**Avantages :**
- Pas de pression temps réel
- Permet de réfléchir
- Moins stressant

**Inconvénients :**
- Difficile d'évaluer les compétences orales
- Difficile d'évaluer la personnalité
- Temps plus long

### 6.4 Entretien Présentiel dans un Environnement Différent

**Adaptations :**
- Environnement plus détendu (café, espace informel)
- Ton plus décontracté
- Rythme plus lent

**Avantages :**
- Communication non-verbale complète
- Environnement plus détendu
- Permet d'évaluer toutes les compétences

**Inconvénients :**
- Toujours présentiel (peut être stressant)
- Nécessite déplacement

---

## 7. Comparaison des Évaluations

### 7.1 Analyse Comparative

**Comparaison des scores :**
- Score initial : Score de l'entretien initial
- Score de rattrapage : Score du second entretien
- Écart : Différence entre les deux scores

**Interprétation :**
- Écart ≤ 10% : Stress n'a pas affecté significativement l'évaluation
- Écart 10-30% : Stress a affecté modérément l'évaluation
- Écart ≥ 30% : Stress a affecté significativement l'évaluation

### 7.2 Décision Finale

**Si écart ≤ 10% :**
- Conserver l'évaluation initiale
- Décider sur l'évaluation initiale

**Si écart 10-30% :**
- Prendre en compte les deux évaluations
- Moyenner les scores
- Décider sur la moyenne

**Si écart ≥ 30% :**
- Donner plus de poids à l'évaluation de rattrapage
- Utiliser l'évaluation de rattrapage comme référence
- Décider sur l'évaluation de rattrapage

## 8. Communication avec le Candidat

### 8.1 Proposition du Second Entretien

**Email de proposition :**
```
Bonjour [Prénom],

Suite à notre entretien du [date], nous avons apprécié votre profil.

Nous avons remarqué que vous étiez peut-être un peu stressé pendant l'entretien.
C'est tout à fait normal et nous comprenons que cela puisse affecter la qualité des échanges.

Pour nous assurer d'avoir une évaluation juste de votre potentiel, nous souhaiterions vous proposer un second entretien court dans un format différent :
- [Format proposé]
- Durée : [X] minutes
- Date proposée : [date]

L'objectif est de vous mettre dans les meilleures conditions pour montrer qui vous êtes vraiment.

Dites-nous si cela vous intéresse et si la date proposée vous convient.

Bien à vous,
[Persona DRH]
```

### 8.2 Confirmation du Second Entretien

**Email de confirmation :**
```
Bonjour [Prénom],

Je confirme notre second entretien :
- Date : [date]
- Heure : [heure]
- Format : [format]
- Durée : [X] minutes
- [Détails techniques si applicable]

L'objectif est de vous mettre dans les meilleures conditions.
Prenez votre temps, il n'y a pas de pression.

À très bientôt,
[Persona DRH]
```

### 8.3 Résultat du Second Entretien

**Email de résultat :**
```
Bonjour [Prénom],

Merci pour ce second entretien.

Nous avons pu apprécier votre profil dans de meilleures conditions.
Votre évaluation a été ajustée en conséquence.

[Si retenu] : Nous avons le plaisir de vous proposer...
[Si refusé] : Après réflexion, nous avons décidé de...
[Si attente] : Nous avons besoin de plus de temps pour...

Merci encore pour votre intérêt pour [Entreprise].

[Persona DRH]
```

## 13. Conclusion

Le protocole d'entretien de rattrapage offre un second entretien court dans un format différent aux candidats qui ont été fortement stressés pendant l'entretien initial. Le moteur alerte le recruteur si le niveau de stress est élevé (3 ou 4) et le profil est méritant. Le second entretien peut être téléphonique, visio avec caméra désactivée, écrit asynchrone, ou présentiel dans un environnement différent. Les évaluations sont comparées et la décision finale est ajustée en conséquence.

**Points clés :**
- Critères de déclenchement (stress niveau 3-4, profil méritant)
- Alerte au recruteur avec recommandation
- 4 formats possibles (téléphonique, visio caméra désactivée, écrit asynchrone, présentiel différent)
- Plan du second entretien (introduction, questions faciles, questions adaptées, conclusion)
- Adaptation selon le format
- Comparaison des évaluations (initial vs rattrapage)
- Décision finale ajustée selon l'écart
- Communication avec le candidat (proposition, confirmation, résultat)
- Structure de données TypeScript
- Stockage et gestion SQL
- API endpoints pour la gestion
- Métriques de déclenchement et d'efficacité
