# RH-130 — Poste

## Identité

RH-130 EST LE DOCUMENT MÉTIER DÉFINISSANT LE POSTE RH.

RH-130 EST LA SOURCE OFFICIELLE DE CONNAISSANCE POUR LE POSTE.

RH-130 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LE POSTE.

RH-130 EST LA RÉFÉRENCE NORMATIVE POUR TOUT POSTE.

## Définitions

### Poste

UN POSTE EST UNE FONCTION SPÉCIFIQUE AU SEIN DE L'ORGANISATION.

LE POSTE EST LIÉ À UNE DESCRIPTION DE POSTE.

LE POSTE EST LIÉ À DES RESPONSABILITÉS.

LE POSTE EST LIÉ À DES COMPÉTENCES REQUISES.

LE POSTE EST LIÉ À DES QUALIFICATIONS REQUISES.

LE POSTE EST LIÉ À DES CONDITIONS DE TRAVAIL.

LE POSTE EST RATTACHÉ À UN DÉPARTEMENT.

### Fiche de poste

LA FICHE DE POSTE EST UN DOCUMENT DÉCRIVANT LE POSTE.

LA FICHE DE POSTE CONTIENT L'INTITULÉ DU POSTE.

LA FICHE DE POSTE CONTIENT LA DESCRIPTION DU POSTE.

LA FICHE DE POSTE CONTIENT LES RESPONSABILITÉS.

LA FICHE DE POSTE CONTIENT LES COMPÉTENCES REQUISES.

LA FICHE DE POSTE CONTIENT LES QUALIFICATIONS REQUISES.

LA FICHE DE POSTE CONTIENT LES CONDITIONS DE TRAVAIL.

LA FICHE DE POSTE CONTIENT LA RÉMUNÉRATION.

LA FICHE DE POSTE EST VALIDÉE PAR LES RESSOURCES HUMAINES.

LA FICHE DE POSTE EST VALIDÉE PAR LE DÉPARTEMENT.

### Responsabilités

LES RESPONSABILITÉS SONT LES TÂCHES ET MISSIONS DU POSTE.

LES RESPONSABILITÉS SONT DÉFINIES DANS LA FICHE DE POSTE.

LES RESPONSABILITÉS SONT ÉVALUÉES LORS DES ENTRETIENS.

LES RESPONSABILITÉS SONT ÉVALUÉES LORS DES REVUES DE PERFORMANCE.

LES RESPONSABILITÉS SONT DOCUMENTÉES.

LES RESPONSABILITÉS SONT TRAÇABLES.
