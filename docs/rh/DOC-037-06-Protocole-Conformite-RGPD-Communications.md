## 1. Objectif

Définir le protocole de conformité RGPD pour les communications avec les candidats dans le cadre de MVP-037 Candidate Experience Engine. Ce document structure les obligations légales, les droits des candidats, les protocoles de consentement, et les mesures de sécurité pour garantir la conformité avec le RGPD.

---

## 2. Principe Fondateur

La conformité RGPD est une obligation légale et une exigence éthique. Toute communication avec les candidats doit respecter les principes de transparence, de consentement, et de protection des données personnelles. Le candidat doit être informé de ses droits et doit pouvoir exercer ces droits facilement.

---

## 3. Références Réglementaires

### 3.1 RGPD (Règlement Général sur la Protection des Données)

**Principes clés :**
- Licéité, loyauté et transparence (Article 5)
- Minimisation des données (Article 5)
- Exactitude des données (Article 5)
- Limitation de la conservation (Article 5)
- Intégrité et confidentialité (Article 5)
- Responsabilité (Article 5)

**Droits des personnes :**
- Droit d'accès (Article 15)
- Droit de rectification (Article 16)
- Droit à l'effacement (Article 17)
- Droit à la limitation du traitement (Article 18)
- Droit à la portabilité (Article 20)
- Droit d'opposition (Article 21)

### 3.2 Loi Informatique et Libertés (France)

**Obligations :**
- Déclaration à la CNIL (si applicable)
- Information des personnes
- Sécurité des données
- Conservation limitée

## 4. Information des Candidats

### 4.1 Politique de Confidentialité

**Contenu minimum :**
- Identité du responsable du traitement
- Finalités du traitement
- Base légale du traitement
- Destinataires des données
- Durée de conservation
- Droits des candidats
- Droit d'introduire une réclamation

**Template de politique :**
```
Politique de Confidentialité - Candidats

1. Responsable du traitement
   [Nom de l'entreprise]
   [Adresse]
   [Email de contact]

2. Finalités du traitement
   Vos données personnelles sont collectées dans le cadre de notre processus de recrutement pour :
   - Gérer votre candidature
   - Évaluer votre profil
   - Communiquer avec vous
   - Améliorer notre processus de recrutement

3. Base légale
   Le traitement est basé sur votre consentement explicite et l'exécution de mesures précontractuelles.

4. Destinataires
   Vos données sont accessibles aux équipes RH et aux recruteurs impliqués dans le processus.

5. Durée de conservation
   Vos données sont conservées pendant [X] années après la fin du processus de recrutement.

6. Vos droits
   Vous avez le droit d'accéder, de rectifier, d'effacer, de limiter, et de porter vos données.
   Pour exercer ces droits, contactez-nous à [email].

7. Réclamation
   Vous avez le droit d'introduire une réclamation auprès de la CNIL.
```

### 4.2 Information lors de la Candidature

**Informations à fournir :**
- Collecte des données personnelles
- Finalités du traitement
- Consentement explicite
- Durée de conservation
- Droits des candidats

**Template d'information :**
```
En soumettant votre candidature, vous acceptez que :
- Vos données personnelles soient collectées et traitées dans le cadre de notre processus de recrutement.
- Vos données soient conservées pendant [X] années.
- Vous soyez informé de vos droits (accès, rectification, effacement, limitation, portabilité, opposition).

Vous pouvez retirer votre consentement à tout moment en nous contactant à [email].
```

## 5. Consentement

### 5.1 Principe du Consentement

**Caractéristiques :**
- Libre : sans contrainte ni pression
- Spécifique : pour une finalité précise
- Éclairé : informé des conséquences
- Sans ambiguïté : clair et explicite

**Méthodes de consentement :**
- Case à cocher lors de la candidature
- Signature électronique
- Consentement explicite par email

### 5.2 Template de Consentement

**Case à cocher :**
```
[ ] J'accepte que mes données personnelles soient collectées et traitées dans le cadre du processus de recrutement de [Entreprise].

J'ai lu et accepté la politique de confidentialité : [Lien]
```

**Consentement par email :**
```
Bonjour [Prénom],

Pour finaliser votre candidature, nous avons besoin de votre consentement explicite pour le traitement de vos données personnelles.

Veuillez répondre à cet email avec "J'accepte" pour confirmer votre consentement.

[Politique de confidentialité en pièce jointe]

Merci,
[Équipe RH]
```

## 6. Droits des Candidats

### 6.1 Droit d'Accès

**Description :**
Le candidat a le droit d'obtenir la confirmation que ses données sont traitées et l'accès à ces données.

**Procédure :**
- Demande par email à [email]
- Réponse dans un délai de 30 jours
- Fourniture d'une copie des données

**Template de réponse :**
```
Bonjour [Prénom],

Suite à votre demande d'accès à vos données personnelles, voici les informations que nous détenons à votre sujet :

[Données personnelles]

Ces données sont traitées dans le cadre de notre processus de recrutement.

Si vous souhaitez exercer d'autres droits (rectification, effacement, limitation), n'hésitez pas à nous contacter.

Bien à vous,
[DPO]
```

### 6.2 Droit de Rectification

**Description :**
Le candidat a le droit d'obtenir la rectification de données inexactes.

**Procédure :**
- Demande par email à [email]
- Réponse dans un délai de 30 jours
- Rectification des données

**Template de réponse :**
```
Bonjour [Prénom],

Suite à votre demande de rectification, nous avons mis à jour vos données personnelles :

[Données rectifiées]

Les modifications ont été effectuées dans notre système.

Bien à vous,
[DPO]
```

### 6.3 Droit à l'Effacement

**Description :**
Le candidat a le droit d'obtenir l'effacement de ses données personnelles dans certaines conditions.

**Conditions :**
- Candidature refusée
- Consentement retiré
- Données non nécessaires pour le processus

**Procédure :**
- Demande par email à [email]
- Réponse dans un délai de 30 jours
- Effacement des données (sauf obligation légale)

**Template de réponse :**
```
Bonjour [Prénom],

Suite à votre demande d'effacement, nous avons supprimé vos données personnelles de notre système.

[Si conservation obligatoire : Certaines données doivent être conservées pour des obligations légales pendant [X] années.]

Bien à vous,
[DPO]
```

### 6.4 Droit à la Limitation

**Description :**
Le candidat a le droit d'obtenir la limitation du traitement de ses données.

**Procédure :**
- Demande par email à [email]
- Réponse dans un délai de 30 jours
- Limitation du traitement

**Template de réponse :**
```
Bonjour [Prénom],

Suite à votre demande de limitation, nous avons limité le traitement de vos données personnelles.

Vos données ne seront plus utilisées que pour [finalités limitées].

Bien à vous,
[DPO]
```

### 6.5 Droit à la Portabilité

**Description :**
Le candidat a le droit de recevoir ses données dans un format structuré et couramment utilisé.

**Procédure :**
- Demande par email à [email]
- Réponse dans un délai de 30 jours
- Fourniture des données en format structuré

**Template de réponse :**
```
Bonjour [Prénom],

Suite à votre demande de portabilité, voici vos données personnelles au format structuré :

[Données au format CSV/JSON]

Bien à vous,
[DPO]
```

### 6.6 Droit d'Opposition

**Description :**
Le candidat a le droit de s'opposer au traitement de ses données pour des raisons liées à sa situation particulière.

**Procédure :**
- Demande par email à [email]
- Réponse dans un délai de 30 jours
- Arrêt du traitement (sauf motif légitime impérieux)

**Template de réponse :**
```
Bonjour [Prénom],

Suite à votre demande d'opposition, nous avons cessé le traitement de vos données personnelles.

[Si motif légitime impérieux : Cependant, nous devons continuer à traiter certaines données pour [motif].]

Bien à vous,
[DPO]
```

## 7. Conservation des Données

### 7.1 Durée de Conservation

**Règles :**
- Candidats refusés après CV : 1 an
- Candidats refusés après entretien : 2 ans
- Candidats finalistes : 3 ans
- Candidats retenus : Conservation pendant la durée de l'emploi + 5 ans

**Automaticité :**
- Suppression automatique à l'expiration du délai
- Notification avant suppression (30 jours)
- Archivage anonymisé si nécessaire

### 7.2 Anonymisation

**Procédure :**
- Suppression des données personnelles directes (nom, email, téléphone)
- Conservation des données anonymisées pour les statistiques
- Impossible de réidentifier le candidat

---

## 8. Sécurité des Données

### 8.1 Mesures Techniques

**Chiffrement :**
- Chiffrement des données en transit (TLS)
- Chiffrement des données au repos (AES-256)
- Chiffrement des emails sensibles

**Contrôle d'accès :**
- Authentification forte (MFA)
- Autorisation basée sur les rôles
- Journalisation des accès

### 8.2 Mesures Organisationnelles

**Formation :**
- Formation RGPD pour le personnel RH
- Sensibilisation à la protection des données
- Mise à jour régulière des connaissances

**Procédures :**
- Procédure en cas de violation de données
- Procédure de réponse aux demandes des candidats
- Audit régulier de la conformité

---

## 9. Violation de Données

### 9.1 Détection

**Signes de violation :**
- Accès non autorisé
- Perte de données
- Divulgation accidentelle
- Altération de données

### 9.2 Notification

**À la CNIL :**
- Délai : 72 heures après détection
- Contenu : Nature, conséquences, mesures prises

**Aux candidats :**
- Délai : Sans retard injustifié si risque élevé
- Contenu : Nature, conséquences, mesures, conseils

**Template de notification :**
```
Cher candidat,

Nous vous informons d'un incident de sécurité impliquant vos données personnelles.

Nature de l'incident : [Description]
Conséquences potentielles : [Description]
Mesures prises : [Description]
Conseils : [Conseils]

Nous vous prions de nous excuser pour cet incident.

Bien à vous,
[DPO]
```

## 11. Stockage et Gestion

### 11.1 Schéma SQL

```sql
CREATE TABLE gdpr_compliance (
  id VARCHAR(36) PRIMARY KEY,
  
  regulatory_references JSON NOT NULL,
  candidate_information JSON NOT NULL,
  consent JSON NOT NULL,
  candidate_rights JSON NOT NULL,
  data_retention JSON NOT NULL,
  data_security JSON NOT NULL,
  data_breach JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE TABLE gdpr_consent_log (
  id VARCHAR(36) PRIMARY KEY,
  candidate_id VARCHAR(36) NOT NULL,
  
  consent_type VARCHAR(50) NOT NULL,
  consent_given BOOLEAN NOT NULL,
  consent_date TIMESTAMP NOT NULL,
  consent_method VARCHAR(50) NOT NULL,
  consent_details JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_gdpr_consent_log_candidate ON gdpr_consent_log(candidate_id);
CREATE INDEX idx_gdpr_consent_log_date ON gdpr_consent_log(consent_date);

CREATE TABLE gdpr_rights_request (
  id VARCHAR(36) PRIMARY KEY,
  candidate_id VARCHAR(36) NOT NULL,
  
  request_type VARCHAR(50) NOT NULL,
  request_date TIMESTAMP NOT NULL,
  request_status VARCHAR(20) NOT NULL,
  response_date TIMESTAMP,
  response_details TEXT,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_gdpr_rights_request_candidate ON gdpr_rights_request(candidate_id);
CREATE INDEX idx_gdpr_rights_request_status ON gdpr_rights_request(request_status);
```

## 14. Conclusion

Le protocole de conformité RGPD structure les obligations légales, les droits des candidats, les protocoles de consentement, et les mesures de sécurité pour garantir la conformité avec le RGPD. Le candidat est informé de ses droits et peut exercer ces droits facilement. - Conservation des données (durées limitées, anonymisation)
- Sécurité des données (mesures techniques et organisationnelles)
- Violation de données (détection, notification CNIL et candidats)
- Structure de données TypeScript

- API endpoints pour la gestion
- Métriques de conformité et de sécurité
