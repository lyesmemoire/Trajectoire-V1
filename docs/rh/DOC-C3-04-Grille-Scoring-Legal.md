## 1. Objectif

Définir la grille de scoring légal pour le Correctif 3 Legal Knowledge Validation. Ce document structure les règles de calcul du score légal, les ajustements selon le niveau de responsabilité, l'intégration au score global, et les alertes correspondantes.

---

## 2. Principe Fondateur

Le scoring légal évalue la maîtrise des connaissances légales obligatoires pour le poste. Le score est calculé sur une échelle de 1 à 5, basé sur le nombre d'éléments critiques mentionnés. Le score est ajusté selon le niveau de responsabilité (junior, senior, executive) et intégré au score global avec pondération.

---

## 3. Échelle de Scoring Légal

### 3.1 Score 5/5 — Maîtrise Juridique Confirmée

**Condition :**
- Tous les éléments critiques présents

**Note :**
"Maîtrise juridique confirmée"

**Interprétation :**
- Le candidat maîtrise les connaissances légales requises
- Aucune lacune critique détectée
- Prêt à occuper le poste

**Ajustement :**
- Aucun ajustement nécessaire

### 3.2 Score 4/5 — Maîtrise Juridique Solide

**Condition :**
- Tous les éléments critiques présents
- Quelques éléments significatifs manquants

**Note :**
"Maîtrise juridique solide. Points à approfondir sur [éléments significatifs manquants]."

**Interprétation :**
- Le candidat maîtrise les connaissances légales critiques
- Lacunes mineures sur des points significatifs
- Peut être formé sur les points manquants

**Ajustement :**
- Ajustement mineur selon le niveau

### 3.3 Score 3/5 — Lacune Critique Isolée

**Condition :**
- 1 élément critique absent
- Éléments significatifs présents

**Note :**
"Lacune sur [point X]. À approfondir."

**Interprétation :**
- Le candidat a une lacune critique isolée
- Lacune peut être comblée par formation
- Vigilance requise sur ce point

**Ajustement :**
- Ajustement modéré selon le niveau

### 3.4 Score 2/5 — Lacunes Significatives

**Condition :**
- 2 éléments critiques absents
- Ou 1 critique + plusieurs significatifs

**Note :**
"Lacunes significatives. Formation juridique nécessaire."

**Interprétation :**
- Le candidat a plusieurs lacunes critiques
- Formation juridique requise
- Risque opérationnel modéré

**Ajustement :**
- Ajustement significatif selon le niveau

### 3.5 Score 1/5 — Connaissances Insuffisantes

**Condition :**
- 3 éléments critiques ou plus absents

**Note :**
"Connaissances juridiques insuffisantes pour ce poste. Risque opérationnel élevé."

**Alerte rouge :**
- Connaissances juridiques insuffisantes pour ce poste
- Risque opérationnel élevé

**Interprétation :**
- Le candidat ne maîtrise pas les connaissances légales requises
- Non recommandé pour le poste
- Formation intensive nécessaire

**Ajustement :**
- Ajustement sévère selon le niveau

## 4. Calcul du Score

### 4.1 Formule de Base

**Score de base :**
Score = 5 - (Nombre d'éléments critiques manquants × 2)

**Exemples :**
- 0 critiques manquants : Score = 5 - 0 = 5/5
- 1 critique manquant : Score = 5 - 2 = 3/5
- 2 critiques manquants : Score = 5 - 4 = 1/5
- 3 critiques manquants : Score = 5 - 6 = -1 → plafonné à 1/5

### 4.2 Ajustement par Éléments Significatifs

**Si 0 critique manquant :**
- 0-2 significatifs manquants : Score = 5/5
- 3-4 significatifs manquants : Score = 4/5
- 5+ significatifs manquants : Score = 3/5

**Si 1 critique manquant :**
- 0-2 significatifs manquants : Score = 3/5
- 3+ significatifs manquants : Score = 2/5

**Si 2 critiques manquants :**
- Quel que soit le nombre de significatifs : Score = 1/5

### 4.3 Plafond et Plancher

**Plafond :**
- Score maximum : 5/5

**Plancher :**
- Score minimum : 1/5

## 5. Ajustement selon le Niveau de Responsabilité

### 5.1 Niveau Junior (0-3 ans d'expérience)

**Tolérance :**
- 1 élément critique manquant acceptable
- Score attendu minimum : 3/5

**Ajustement :**
- Si score ≥ 3/5 : Ajustement = 0%
- Si score = 2/5 : Ajustement = -10%
- Si score = 1/5 : Ajustement = -20%

**Interprétation :**
- Score 3/5 : Acceptable pour un junior
- Score 2/5 : Lacunes à combler par formation
- Score 1/5 : Non recommandé

### 5.2 Niveau Senior (3-7 ans d'expérience)

**Tolérance :**
- 0 élément critique manquant acceptable
- Score attendu minimum : 4/5

**Ajustement :**
- Si score = 5/5 : Ajustement = 0%
- Si score = 4/5 : Ajustement = -10%
- Si score = 3/5 : Ajustement = -20%
- Si score = 2/5 : Ajustement = -30%
- Si score = 1/5 : Ajustement = -40%

**Interprétation :**
- Score 5/5 : Maîtrise confirmée
- Score 4/5 : Maîtrise solide
- Score 3/5 : Lacune critique isolée
- Score 2/5 : Lacunes significatives
- Score 1/5 : Non recommandé

### 5.3 Niveau Executive (7+ ans d'expérience)

**Tolérance :**
- 0 élément critique manquant acceptable
- Score attendu minimum : 5/5

**Ajustement :**
- Si score = 5/5 : Ajustement = 0%
- Si score = 4/5 : Ajustement = -15%
- Si score = 3/5 : Ajustement = -30%
- Si score = 2/5 : Ajustement = -45%
- Si score = 1/5 : Ajustement = -60%

**Interprétation :**
- Score 5/5 : Maîtrise confirmée
- Score 4/5 : Lacune mineure
- Score 3/5 : Lacune critique inacceptable
- Score 2/5 : Lacunes significatives
- Score 1/5 : Non recommandé

## 6. Intégration au Score Global

### 6.1 Pondération par Type de Poste

**Poste DRH / Juridique :**
- Poids du score légal : 20%
- Poids du score compétences : 80%

**Poste RH Junior :**
- Poids du score légal : 10%
- Poids du score compétences : 90%

**Poste Autre (non RH/Juridique) :**
- Poids du score légal : 0%
- Poids du score compétences : 100%

### 6.2 Formule de Calcul

**Pour poste DRH / Juridique :**
Score Global = (Score Compétences × 0.8) + (Score Légal × 0.2)

**Pour poste RH Junior :**
Score Global = (Score Compétences × 0.9) + (Score Légal × 0.1)

**Exemple :**
- Score compétences : 80/100
- Score légal : 3/5 = 60/100
- Poste DRH : Score global = (80 × 0.8) + (60 × 0.2) = 64 + 12 = 76/100

### 6.3 Ajustement du Score Global

**Si score légal ajusté :**
- Le score légal ajusté est utilisé dans le calcul
- Le score global est recalculé
- L'impact est proportionnel au poids

**Exemple :**
- Score compétences : 80/100
- Score légal initial : 3/5 = 60/100
- Ajustement niveau senior : -20%
- Score légal ajusté : 48/100
- Poste DRH : Score global = (80 × 0.8) + (48 × 0.2) = 64 + 9.6 = 73.6/100

## 7. Alertes

### 7.1 Alerte Orange

**Condition :**
- Score légal = 3/5 pour niveau senior ou executive
- Score légal = 2/5 pour niveau junior

**Message :**
"Lacune critique détectée sur [point X]. Vigilance requise."

**Action recommandée :**
- Approfondir ce point lors de l'entretien
- Vérifier si la lacune peut être comblée par formation
- Considérer l'impact sur le poste

### 7.2 Alerte Rouge

**Condition :**
- Score légal = 1/5 pour tous les niveaux
- Score légal = 2/5 pour niveau senior ou executive

**Message :**
"Connaissances juridiques insuffisantes pour ce poste. Risque opérationnel élevé."

**Action recommandée :**
- Non recommandé pour le poste
- Formation juridique intensive nécessaire
- Considérer un autre candidat

## 8. Consignation dans le Debrief

### 8.1 Informations Consignées

Pour chaque évaluation légale, le debrief contient :

**Score légal :**
- Score brut (avant ajustement)
- Score ajusté (après ajustement selon niveau)
- Ajustement appliqué

**Détail des éléments :**
- Éléments critiques cités
- Éléments critiques manquants
- Éléments significatifs cités
- Éléments significatifs manquants

**Interprétation :**
- Note explicative
- Niveau de maîtrise
- Recommandation

**Alerte :**
- Niveau d'alerte (aucune, orange, rouge)
- Message d'alerte
- Action recommandée

## 10. Stockage et Gestion

### 10.1 Schéma SQL

```sql
CREATE TABLE legal_scoring_entry (
  id VARCHAR(36) PRIMARY KEY,
  candidate_id VARCHAR(36) NOT NULL,
  interview_id VARCHAR(36) NOT NULL,
  
  scored_at TIMESTAMP NOT NULL,
  
  case_type VARCHAR(50) NOT NULL,
  domain VARCHAR(50) NOT NULL,
  expected_level VARCHAR(20) NOT NULL,
  
  raw_score INT NOT NULL,
  adjusted_score INT NOT NULL,
  adjustment DECIMAL(5,2) NOT NULL,
  
  elements JSON NOT NULL,
  interpretation JSON NOT NULL,
  alert JSON NOT NULL,
  global_impact JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_legal_scoring_candidate ON legal_scoring_entry(candidate_id);

CREATE INDEX idx_legal_scoring_case_type ON legal_scoring_entry(case_type);

CREATE TABLE legal_scoring_grid (
  id VARCHAR(36) PRIMARY KEY,
  
  scoring_scale JSON NOT NULL,
```

## 13. Conclusion

La grille de scoring légal définit l'échelle de 1 à 5 pour évaluer la maîtrise des connaissances légales. Score 5/5 : tous les éléments critiques présents (maîtrise confirmée). Score 4/5 : tous les éléments critiques présents, quelques significatifs manquants (maîtrise solide). Score 3/5 : 1 élément critique absent (lacune isolée). Score 2/5 : 2 éléments critiques absents (lacunes significatives). Score 1/5 : 3 éléments critiques ou plus absents (connaissances insuffisantes, alerte rouge). Le score est calculé avec la formule : Score = 5 - (Nombre de critiques manquants × 2). L'ajustement selon le niveau : junior (tolérance 1 critique, score min 3/5), senior (tolérance 0 critique, score min 4/5), executive (tolérance 0 critique, score min 5/5). L'intégration au score global : 20% pour DRH/Juridique, 10% pour RH Junior, 0% pour autres. Alertes orange et rouge selon le score et le niveau.

**Points clés :**
- Échelle de scoring : 1/5 à 5/5
- Score 5/5 : tous éléments critiques présents
- Score 3/5 : 1 critique manquant
- Score 1/5 : 3+ critiques manquants (alerte rouge)
- Formule : Score = 5 - (critiques manquants × 2)
- Ajustement par niveau (junior, senior, executive)
- Intégration au score global avec pondération
- Alertes orange et rouge
- Consignation détaillée dans le debrief
- Structure de données TypeScript
- Stockage et gestion SQL
- API endpoints pour le scoring
- Métriques de scoring et d'alertes
