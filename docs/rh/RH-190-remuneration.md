# RH-190 — Rémunération

## Identité

RH-190 EST LE DOCUMENT MÉTIER DÉFINISSANT LA RÉMUNÉRATION RH.

RH-190 EST LA SOURCE OFFICIELLE DE CONNAISSANCE POUR LA RÉMUNÉRATION.

RH-190 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LA RÉMUNÉRATION.

RH-190 EST LA RÉFÉRENCE NORMATIVE POUR TOUTE RÉMUNÉRATION.

## Définitions

### Rémunération

LA RÉMUNÉRATION EST LA CONTREPARTIE FINANCIÈRE DU TRAVAIL FOURNI PAR LE SALARIÉ.

LA RÉMUNÉRATION EST SOUMISE AU DROIT DU TRAVAIL.

LA RÉMUNÉRATION EST SOUMISE AUX CONVENTIONS COLLECTIVES.

LA RÉMUNÉRATION EST SOUMISE AUX ACCORDS D'ENTREPRISE.

LA RÉMUNÉRATION EST SOUMISE AU RÈGLEMENT INTÉRIEUR.

LA RÉMUNÉRATION EST DOCUMENTÉE.

LA RÉMUNÉRATION EST TRAÇABLE.

### Salaire

LE SALAIRE EST LA RÉMUNÉRATION D'UN SALARIÉ.

LE SALAIRE EST VERSÉ MENSUELLEMENT.

LE SALAIRE EST SOUMIS AUX COTISATIONS SOCIALES.

LE SALAIRE EST SOUMIS À L'IMPÔT SUR LE REVENU.

LE SALAIRE EST DÉFINI DANS LE CONTRAT DE TRAVAIL.

### Salaire brut

LE SALAIRE BRUT EST LA RÉMUNÉRATION AVANT DÉDUCTIONS.

LE SALAIRE BRUT INCLUT LES COTISATIONS SOCIALES.

LE SALAIRE BRUT INCLUT LES PRIMES SI APPLICABLE.

LE SALAIRE BRUT INCLUT LES AVANTAGES SI APPLICABLE.

LE SALAIRE BRUT EST DÉFINI DANS LE CONTRAT DE TRAVAIL.

### Salaire net

LE SALAIRE NET EST LA RÉMUNÉRATION APRÈS DÉDUCTIONS.

LE SALAIRE NET EST LE SALAIRE BRUT MOINS LES COTISATIONS.

LE SALAIRE NET EST LE SALAIRE BRUT MOINS L'IMPÔT.

LE SALAIRE NET EST VERSÉ AU SALARIÉ.

LE SALAIRE NET EST INDIQUÉ SUR LE BULLETIN DE PAIE.
