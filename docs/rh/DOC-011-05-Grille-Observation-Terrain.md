# DOC-011-05 : Grille d'Observation Terrain

**Version:** 1.0  
**Date:** 2026-08-03  
**Statut:** Draft  
**Auteur:** Trajectoire Team

---

## 1. Objectif

Définir la grille d'observation terrain pour les sessions d'observation directe des beta recruteurs utilisant le moteur en conditions réelles. L'observation directe permet de capturer des insights que le feedback verbal ne peut pas révéler.

---

## 2. Principe Fondateur

Observation directe conseillée : assister à une session d'utilisation réelle du moteur par le recruteur.

**Objectifs :**
- Observer le recruteur utiliser le moteur dans son environnement naturel
- Capturer les points de friction
- Noter les moments de confusion
- Noter les réussites
- Noter les contournements
- Identifier les comportements non verbaux

---

## 3. Préparation de l'Observation

### 3.1 Planification

**Avant l'observation :**
- Planifier l'observation avec le recruteur
- Obtenir l'accord pour l'observation
- Définir la durée de l'observation (30-60 minutes)
- Préparer la grille d'observation
- Préparer l'enregistrement (avec accord)

**Formulaire de consentement :**

## 6. Instructions d'Observation

### 6.1 Pendant l'Observation

- Observer sans intervenir
- Noter les points de friction immédiatement
- Noter les moments de confusion immédiatement
- Noter les réussites immédiatement
- Noter les contournements immédiatement
- Observer les comportements non verbaux
- Enregistrer les verbalisations

### 6.2 Immédiatement Après l'Observation

- Compléter la grille dans les 2 heures
- Discuter des observations avec le recruteur
- Valider les interprétations
- Documenter les insights

### 6.3 Analyse Croisée

Comparer les observations avec :
- Le feedback verbal du recruteur
- Les observations des autres betas
- Les patterns communs
- Les besoins divergents

---

## 7. Stockage et Gestion

### 7.1 Stockage

Les grilles d'observation sont stockées dans :

- **Google Drive** : Dossier partagé avec l'équipe
- **Notion** : Base de données structurée
- **Git** : Version control (format markdown)

### 7.2 Nom de Fichier

Format : `OBS-BETA-[BETA-ID]-[YYYY-MM-DD].md`

Exemple : `OBS-BETA-BG001-2026-10-20.md`

### 7.3 Confidentialité

Les données d'observation sont :
- Anonymisées avant analyse
- Conservées conformément au RGPD
- Détruites après analyse
- Accessibles uniquement à l'équipe produit

## 9. Conclusion

La grille d'observation terrain permet de capturer des insights précieux que le feedback verbal ne peut pas révéler. Une observation rigoureuse et une documentation complète garantissent que ces insights sont exploitables.

**Points clés :**
- Observation sans intervention
- Documentation en temps réel
- Capture des comportements non verbaux
- Validation avec le recruteur
- Confidentialité et conformité RGPD
