## 1. Objectif

Définir le guide des 8 types d'entretiens pour MVP-034 Interview Orchestrator. Ce guide structure les spécificités de chaque type d'entretien, incluant la durée, les objectifs, les actes impliqués, et les particularités à prendre en compte pour une orchestration optimale.

---

## 2. Principe Fondateur

Chaque type d'entretien a ses propres objectifs, contraintes, et particularités. Le moteur doit adapter son orchestration en fonction du type d'entretien : durée, actes impliqués, focus thématique, niveau de challenge, et intervenants.

---

## 3. Type 1 — Entretien de Présélection Téléphonique

### 3.1 Caractéristiques

**Durée :** 15 à 30 minutes

**Objectif :** Filtrer rapidement les candidats sur les critères éliminatoires

**Actes impliqués :** Acte 0 (Pré-entretien) - Acte 1 (Ouverture) - Acte 2 (Exploration simplifiée) - Acte 5 (Clôture) - Acte 6 (Post-entretien)

**Intervenant :** RH ou Recruteur junior

### 3.2 Spécificités

**Pas de lecture non verbale possible :**
- Focus sur la communication orale
- Écoute active des réponses
- Attention aux hésitations et aux reformulations

**Questions plus directes et fermées :**
- Vérification des critères éliminatoires
- Questions factuelles sur le parcours
- Vérification de la disponibilité
- Vérification des prétentions salariales

**Vérification des critères éliminatoires :**
- Disponibilité géographique
- Prétentions salariales
- Permis de conduire (si requis)
- Langues requises
- Expérience minimale

**Évaluation de la communication orale :**
- Clarté de l'expression
- Fluidité de la parole
- Capacité à synthétiser
- Professionnalisme

### 3.3 Répartition du Temps

- Acte 1 — Ouverture : 2-3 minutes
- Acte 2 — Exploration : 10-20 minutes
- Acte 5 — Clôture : 2-3 minutes
- Acte 6 — Post-entretien : 5 minutes

### 3.4 Questions Clés

**Critères éliminatoires :**
- "Êtes-vous disponible pour travailler à [lieu] ?"
- "Quelles sont vos prétentions salariales ?"
- "Parlez-moi de votre expérience en [compétence clé]"
- "Pourquoi cherchez-vous à changer de poste ?"

**Communication orale :**
- "Présentez-vous en 2 minutes."
- "Qu'est-ce qui vous motive dans ce poste ?"

### 3.5 Décision

**Recommandé :** Passer au round suivant

**Refusé :** Critère éliminatoire

**À approfondir :** Besoin de plus d'informations

## 4. Type 2 — Entretien RH Standard

### 4.1 Caractéristiques

**Durée :** 45 à 60 minutes

**Objectif :** Évaluation complète du candidat

**Actes impliqués :** Acte 0 - Acte 1 - Acte 2 - Acte 3 - Acte 4 - Acte 5 - Acte 6

**Intervenant :** RH ou Recruteur

### 4.2 Spécificités

**Séquence complète :**
- Tous les actes sont impliqués
- Focus équilibré entre compétences, soft skills, et motivations
- Évaluation du culture fit

**Focus soft skills et culture fit :**
- 30-35% du temps sur l'Acte 3 (Approfondissement)
- Questions comportementales STAR
- Évaluation de la personnalité professionnelle

**Évaluation de la motivation :**
- Questions projectionnelles
- Vérification de la cohérence motivation / poste
- Évaluation du risque de désengagement

### 4.3 Répartition du Temps

- Acte 1 — Ouverture : 3-5 minutes
- Acte 2 — Exploration : 12-18 minutes
- Acte 3 — Approfondissement : 15-20 minutes
- Acte 4 — Challenge : 10-12 minutes
- Acte 5 — Clôture : 3-5 minutes
- Acte 6 — Post-entretien : 10-15 minutes

### 4.4 Questions Clés

**Soft skills :**
- "Racontez-moi une fois où vous avez dû faire preuve de [soft skill]."
- "Comment gérez-vous les conflits ?"

**Culture fit :**
- "Décrivez le manager idéal pour vous."
- "Dans quel type d'équipe avez-vous le mieux travaillé ?"

**Motivations :**
- "Dans 5 ans, qu'est-ce que vous voulez avoir accompli ?"
- "Qu'est-ce qui vous ferait quitter ce poste ?"

### 4.5 Décision

**Recommandé :** Passer au round suivant ou offre directe

**Refusé :** Inadéquation culturelle ou compétences insuffisantes

**À approfondir :** Besoin de validation technique ou second round

## 5. Type 3 — Entretien Technique / Métier

### 5.1 Caractéristiques

**Durée :** 60 à 90 minutes

**Objectif :** Valider les compétences techniques

**Actes impliqués :** Acte 0 - Acte 1 - Acte 2 (technique) - Acte 3 - Acte 4 (cas pratique) - Acte 5 - Acte 6

**Intervenant :** Expert technique ou Manager

### 5.2 Spécificités

**Acte 2 centré sur les compétences techniques :**
- Questions techniques ciblées
- Vérification de la profondeur d'expertise
- Questions sur les projets passés
- Évaluation de la capacité technique

**Acte 4 inclut cas pratique ou test :**
- Mise en situation technique
- Problème à résoudre
- Code review ou analyse
- Évaluation du raisonnement technique

**Grille technique spécifique :**
- Compétences techniques spécifiques au poste
- Niveau de maîtrise requis
- Outils et technologies

### 5.3 Répartition du Temps

- Acte 1 — Ouverture : 3-5 minutes
- Acte 2 — Exploration technique : 20-30 minutes
- Acte 3 — Approfondissement : 10-15 minutes
- Acte 4 — Cas pratique : 20-30 minutes
- Acte 5 — Clôture : 3-5 minutes
- Acte 6 — Post-entretien : 10-15 minutes

### 5.4 Questions Clés

**Compétences techniques :**
- "Parlez-moi de votre expérience avec [technologie]."
- "Comment avez-vous résolu [problème technique] ?"
- "Quelle est votre approche pour [défi technique] ?"

**Cas pratique :**
- "Voici un problème technique. Comment le résoudriez-vous ?"
- "Analysez ce code et proposez des améliorations."

### 5.5 Décision

**Recommandé :** Compétences techniques validées

**Refusé :** Compétences techniques insuffisantes

**À approfondir :** Besoin de validation supplémentaire

---

## 6. Type 4 — Entretien de Direction / C-Level

### 6.1 Caractéristiques

**Durée :** 90 à 120 minutes

**Objectif :** Évaluation leadership et vision

**Actes impliqués :** Acte 0 - Acte 1 - Acte 2 - Acte 3 - Acte 4 (renforcé) - Acte 5 - Acte 6

**Intervenant :** DG / Fondateur / Conseil

### 6.2 Spécificités

**Focus sur la vision stratégique :**
- Questions sur la vision à long terme
- Évaluation de la capacité à penser stratégiquement
- Questions sur les décisions stratégiques passées

**Évaluation du leadership transformationnel :**
- Capacité à transformer une organisation
- Gestion du changement
- Inspiration et motivation des équipes

**Questions sur la gestion des crises :**
- Expérience de gestion de crises
- Réaction sous pression
- Prise de décision en situation d'incertitude

**Évaluation de la représentation externe :**
- Capacité à représenter l'entreprise
- Communication avec les parties prenantes
- Négociation et influence

### 6.3 Répartition du Temps

- Acte 1 — Ouverture : 5-10 minutes
- Acte 2 — Exploration : 20-30 minutes
- Acte 3 — Approfondissement : 25-35 minutes
- Acte 4 — Challenge renforcé : 25-30 minutes
- Acte 5 — Clôture : 5-10 minutes
- Acte 6 — Post-entretien : 15-20 minutes

### 6.4 Questions Clés

**Vision stratégique :**
- "Quelle est votre vision pour ce poste dans 3 ans ?"
- "Quelles sont les 3 priorités stratégiques que vous fixeriez ?"

**Leadership :**
- "Racontez-moi une transformation que vous avez menée."
- "Comment gérez-vous les résistances au changement ?"

**Gestion des crises :**
- "Racontez-moi une crise que vous avez gérée."
- "Comment prenez-vous des décisions en situation d'incertitude ?"

### 6.5 Décision

**Recommandé :** Leadership et vision validés

**Refusé :** Leadership ou vision insuffisants

**À approfondir :** Besoin de validation par d'autres intervenants

## 7. Type 5 — Entretien Panel (Multi-Intervenants)

### 7.1 Caractéristiques

**Durée :** 60 à 90 minutes

**Objectif :** Évaluation multi-perspectives

**Actes impliqués :** Acte 0 - Acte 1 - Acte 2 - Acte 3 - Acte 4 - Acte 5 - Acte 6

**Intervenants :** RH + Manager + Expert technique + Autre

### 7.2 Spécificités

**Coordination des intervenants :**
- Répartition des questions par intervenant
- Éviter les redondances
- Couvrir tous les angles

**Répartition des questions par intervenant :**
- RH : Culture fit / Soft skills / Motivations
- Manager direct : Compétences métier / Adéquation équipe
- Expert technique : Compétences techniques / Profondeur expertise
- Direction : Vision / Leadership / Potentiel long terme
- Pair : Collaboration / Dynamique équipe

**Éviter les redondances et les angles morts :**
- Le moteur coordonne les questions
- Il identifie les redondances potentielles
- Il suggère des questions pour couvrir les angles morts

**Synthèse multi-intervenants post-entretien :**
- Chaque intervenant cote via le moteur
- Le moteur synthétise les évaluations
- Il identifie les convergences et divergences
- Il propose une synthèse argumentée

### 7.3 Répartition du Temps

- Acte 1 — Ouverture : 5 minutes
- Acte 2 — Exploration : 15-20 minutes
- Acte 3 — Approfondissement : 20-25 minutes
- Acte 4 — Challenge : 15-20 minutes
- Acte 5 — Clôture : 5-10 minutes
- Acte 6 — Post-entretien : 20-30 minutes (synthèse multi-intervenants)

### 7.4 Questions Clés

**Par intervenant :**
- RH : "Qu'est-ce qui vous motive ?"
- Manager : "Comment travaillerez-vous avec l'équipe ?"
- Expert : "Comment résoudriez-vous [problème technique] ?"
- Direction : "Quelle est votre vision pour ce rôle ?"

### 7.5 Décision

**Recommandé :** Convergence des évaluations positives

**Refusé :** Divergence significative ou évaluations négatives

**À approfondir :** Divergence à clarifier

---

## 8. Type 6 — Entretien de Cas / Assessment

### 8.1 Caractéristiques

**Durée :** 120 à 180 minutes

**Objectif :** Évaluation en conditions réelles

**Actes impliqués :** Acte 0 - Acte 1 - CAS CENTRAL - Acte 4 - Acte 5 - Acte 6

**Intervenant :** Manager + Expert

### 8.2 Spécificités

**Cas business central (30 à 60 minutes) :**
- Scénario business réaliste
- Problème complexe à résoudre
- Données et contextes fournis
- Objectifs clairs définis

**Présentation par le candidat :**
- Présentation orale de la solution
- Justification des décisions
- Réponses aux questions

**Questions sur le raisonnement :**
- Pourquoi cette approche ?
- Quelles alternatives avez-vous considérées ?
- Quels risques avez-vous identifiés ?

**Évaluation de la structure de pensée :**
- Capacité à structurer un problème complexe
- Logique du raisonnement
- Capacité à prioriser
- Créativité dans la solution

### 8.3 Répartition du Temps

- Acte 1 — Ouverture : 5-10 minutes
- Présentation du cas : 5-10 minutes
- Travail du candidat : 30-60 minutes
- Présentation de la solution : 15-20 minutes
- Questions sur le raisonnement : 20-30 minutes
- Acte 5 — Clôture : 5-10 minutes
- Acte 6 — Post-entretien : 20-30 minutes

### 8.4 Questions Clés

**Sur le cas :**
- "Quelle est votre analyse de la situation ?"
- "Quelle solution proposez-vous ?"
- "Pourquoi cette approche plutôt qu'une autre ?"
- "Quels risques avez-vous identifiés ?"

**Sur le raisonnement :**
- "Comment êtes-vous arrivé à cette conclusion ?"
- "Quelles alternatives avez-vous considérées ?"

### 8.5 Décision

**Recommandé :** Raisonnement et solution validés

**Refusé :** Raisonnement ou solution insuffisants

**À approfondir :** Besoin de clarification sur certains aspects

---

## 9. Type 7 — Entretien de Second Round

### 9.1 Caractéristiques

**Durée :** 45 à 60 minutes

**Objectif :** Approfondir les points restants

**Actes impliqués :** Acte 0 (ciblé) - Acte 3 (focus points restants) - Acte 4 - Acte 5 - Acte 6

**Intervenant :** Différent si possible

### 9.2 Spécificités

**Basé sur les zones d'ombre du Round 1 :**
- Le moteur identifie les points non clarifiés
- Il génère des questions spécifiques pour le Round 2
- Il priorise les zones d'ombre critiques

**Questions spécifiques préparées par le moteur :**
- Basées sur les incohérences détectées
- Basées sur les signaux de vigilance
- Basées sur les zones d'ombre résiduelles

**Intervenant différent si possible :**
- Pour obtenir une perspective différente
- Pour tester la cohérence inter-rounds
- Pour éviter les biais du premier intervenant

**Comparaison avec le Round 1 :**
- Le moteur compare les réponses entre rounds
- Il identifie les cohérences et incohérences
- Il analyse l'évolution du candidat

### 9.3 Répartition du Temps

- Acte 1 — Ouverture : 3-5 minutes
- Acte 3 — Approfondissement ciblé : 20-25 minutes
- Acte 4 — Challenge ciblé : 10-15 minutes
- Acte 5 — Clôture : 3-5 minutes
- Acte 6 — Post-entretien : 10-15 minutes (comparaison inter-rounds)

### 9.4 Questions Clés

**Basées sur les zones d'ombre :**
- "Au Round 1, vous avez mentionné [X]. Pouvez-vous me donner plus de détails ?"
- "Il y a une incohérence entre [A] et [B]. Pouvez-vous clarifier ?"

**Basées sur les signaux de vigilance :**
- "Vous avez dit [X]. Pouvez-vous me donner un exemple concret ?"

### 9.5 Décision

**Recommandé :** Zones d'ombre clarifiées

**Refusé :** Incohérences persistantes ou zones d'ombre critiques

**À approfondir :** Besoin d'un troisième round

---

## 10. Type 8 — Entretien de Référencement

### 10.1 Caractéristiques

**Durée :** 20 à 30 minutes

**Objectif :** Validation par les pairs

**Actes impliqués :** Acte 0 (références) - Séquence spécifique

**Intervenant :** RH ou Recruteur

### 10.2 Spécificités

**Protocole de prise de références (réf. MVP-020) :**
- Sélection des références appropriées
- Questions ciblées sur les zones d'ombre
- Analyse de cohérence avec l'entretien

**Questions ciblées sur zones d'ombre :**
- Basées sur les signaux de vigilance de l'entretien
- Basées sur les incohérences détectées
- Basées sur les points à valider

**Analyse de cohérence avec l'entretien :**
- Comparaison des réponses du candidat et des références
- Identification des convergences et divergences
- Validation ou infirmation des hypothèses

### 10.3 Répartition du Temps

- Introduction : 2-3 minutes
- Questions sur la collaboration : 5-7 minutes
- Questions sur les compétences : 5-7 minutes
- Questions sur les soft skills : 5-7 minutes
- Clôture : 2-3 minutes

### 10.4 Questions Clés

**Collaboration :**
- "Comment a-t-il collaboré avec l'équipe ?"
- "Quelle était sa relation avec le manager ?"

**Compétences :**
- "Comment a-t-il performé sur [projet] ?"
- "Quelles sont ses forces ? Ses faiblesses ?"

**Soft skills :**
- "Comment gère-t-il le stress ?"
- "Comment communique-t-il ?"

### 10.5 Décision

**Recommandé :** Références positives et cohérentes

**Refusé :** Références négatives ou incohérences majeures

**À approfondir :** Références mitigées ou besoin de plus d'informations

## 11. Structure de Données (TypeScript)

```typescript
interface InterviewType {
  typeId: string;
  typeName: string;
  
  characteristics: {
    duration: {
      min: number;
      max: number;
    };
    objective: string;
    actsInvolved: number[];
    interviewer: string;
  };
  
  specifications: {
    description: string[];
    focusAreas: string[];
    specialConsiderations: string[];
  };
  
  timeAllocation: {
    act1: number;
    act2: number;
    act3: number;
    act4: number;
    act5: number;
    act6: number;
    custom?: {
      name: string;
      duration: number;
    }[];
  };

    category: string;
    questions: string[];
  }[];
  
  decisionCriteria: {
    recommended: string;
    rejected: string;
    toDeepen: string;
  };
  
  metadata: {
    version: string;
    lastUpdated: Date;
  };
}

interface InterviewTypeConfig {
  configId: string;
  interviewId: string;
  
  selectedType: string;
  customizations: {
    duration?: number;
    acts?: number[];
    interviewers?: string[];
  };
  
  metadata: {
    createdAt: Date;
    lastUpdated: Date;
  };
}
```

## 12. Stockage et Gestion

### 12.1 Schéma SQL

```sql
CREATE TABLE interview_type (
  id VARCHAR(36) PRIMARY KEY,
  type_name VARCHAR(50) NOT NULL UNIQUE,
  
  characteristics JSON NOT NULL,
  specifications JSON NOT NULL,
  time_allocation JSON NOT NULL,
  key_questions JSON NOT NULL,
  decision_criteria JSON NOT NULL,
  metadata JSON NOT NULL
);

CREATE TABLE interview_type_config (
  id VARCHAR(36) PRIMARY KEY,
  interview_id VARCHAR(36) NOT NULL,
  
  selected_type VARCHAR(50) NOT NULL,
  customizations JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  FOREIGN KEY (interview_id) REFERENCES interview(id),
  FOREIGN KEY (selected_type) REFERENCES interview_type(type_name)
);

CREATE INDEX idx_interview_type_config_interview ON interview_type_config(interview_id);
```
