# DOC-038-03 : Règles d'Adaptation du Plan d'Entretien sous Stress

**Version:** 1.0  
**Date:** 2026-08-03  
**Statut:** Draft  
**Auteur:** Trajectoire Team

---

## 1. Objectif

Définir les règles d'adaptation du plan d'entretien sous stress pour MVP-038 Stress Management Engine. Ce document structure les modifications du plan d'entretien selon le niveau de stress détecté, incluant l'adaptation des questions, du rythme, et des objectifs pour garantir une évaluation juste malgré le stress.

---

## 2. Principe Fondateur

Le plan d'entretien doit être adapté en temps réel selon le niveau de stress du candidat. L'objectif n'est pas de suivre le plan à tout prix, mais d'obtenir une évaluation juste du candidat. Le moteur ajuste dynamiquement les questions, le rythme, et les objectifs pour compenser le stress et révéler le vrai candidat.

---

## 3. Adaptation par Niveau de Stress

### 3.1 Niveau 0 — À l'aise, détendu

**Adaptation :**
- Aucune adaptation nécessaire
- Suivre le plan d'entretien normal
- Maintenir le rythme prévu
- Poser les questions prévues

**Objectifs :**
- Évaluer le candidat selon le plan normal
- Obtenir des réponses complètes et détaillées
- Couvrir tous les domaines prévus

**Questions :**
- Questions prévues dans le plan
- Complexité normale
- Ordre normal

### 3.2 Niveau 1 — Légèrement stressé, normal

**Adaptation :**
- Aucune adaptation majeure
- Maintenir le plan d'entretien normal
- Être légèrement plus patient
- Donner un peu plus de temps pour répondre

**Objectifs :**
- Évaluer le candidat selon le plan normal
- Obtenir des réponses complètes malgré le léger stress
- Couvrir tous les domaines prévus

**Questions :**
- Questions prévues dans le plan
- Complexité normale
- Ordre normal
- Temps de réponse légèrement augmenté (+10%)

### 3.3 Niveau 2 — Stress modéré, à surveiller

**Adaptation :**
- Adapter subtilement le plan d'entretien
- Réduire la complexité des questions
- Augmenter le temps de réponse
- Intégrer plus de questions de transition

**Objectifs :**
- Évaluer le candidat en compensant le stress
- Obtenir des réponses suffisantes malgré le stress modéré
- Couvrir les domaines essentiels

**Questions :**
- Questions prévues mais simplifiées
- Complexité réduite (-20%)
- Ordre normal avec plus de transitions
- Temps de réponse augmenté (+30%)
- Plus de questions ouvertes et bienveillantes

### 3.4 Niveau 3 — Stress élevé, adapter

**Adaptation :**
- Adapter significativement le plan d'entretien
- Réduire fortement la complexité des questions
- Augmenter considérablement le temps de réponse
- Changer l'ordre des questions (faciles d'abord)
- Intégrer des pauses

**Objectifs :**
- Évaluer le candidat en compensant fortement le stress
- Obtenir des réponses essentielles malgré le stress élevé
- Couvrir les domaines critiques uniquement

**Questions :**
- Questions adaptées (simplifiées)
- Complexité réduite (-50%)
- Ordre modifié (faciles d'abord)
- Temps de réponse augmenté (+50%)
- Questions très ouvertes et bienveillantes
- Intégration de pauses explicites

### 3.5 Niveau 4 — Stress bloquant, intervenir

**Adaptation :**
- Suspendre le plan d'entretien
- Intervenir pour réduire le stress
- Proposer de reporter l'entretien
- Ou changer complètement d'approche

**Objectifs :**
- Réduire le stress avant toute évaluation
- Obtenir une évaluation juste à un moment plus approprié
- Ne pas pénaliser le candidat pour son stress

**Questions :**
- Suspension des questions prévues
- Questions très simples et positives si continuation
- Report de l'entretien si stress persiste

## 4. Adaptation des Questions

### 4.1 Simplification des Questions

**Principe :**
Selon le niveau de stress, simplifier les questions pour permettre au candidat de répondre malgré le stress.

**Niveau 0-1 :**
- Questions normales
- Complexité : 100%
- Exemple : "Parlez-moi d'un projet complexe que vous avez géré."

**Niveau 2 :**
- Questions légèrement simplifiées
- Complexité : 80%
- Exemple : "Parlez-moi d'un projet que vous avez géré."

**Niveau 3 :**
- Questions fortement simplifiées
- Complexité : 50%
- Exemple : "Avez-vous déjà géré un projet ? Pouvez-vous me donner un exemple simple ?"

**Niveau 4 :**
- Questions très simples
- Complexité : 20%
- Exemple : "Qu'est-ce que vous aimez dans votre travail ?"

### 4.2 Adaptation du Type de Questions

**Principe :**
Selon le niveau de stress, adapter le type de questions pour réduire la pression cognitive.

**Niveau 0-1 :**
- Mix de questions ouvertes et fermées
- Questions techniques et comportementales
- Questions de situation

**Niveau 2 :**
- Plus de questions ouvertes
- Moins de questions techniques
- Plus de questions comportementales

**Niveau 3 :**
- Majorité de questions ouvertes
- Très peu de questions techniques
- Questions très comportementales et personnelles

**Niveau 4 :**
- Questions très ouvertes et positives
- Aucune question technique
- Questions personnelles et motivantes

### 4.3 Adaptation de l'Ordre des Questions

**Principe :**
Selon le niveau de stress, adapter l'ordre des questions pour commencer par des questions faciles et reconstruire la confiance.

**Niveau 0-1 :**
- Ordre normal du plan d'entretien
- Questions difficiles au début si prévu
- Progression normale

**Niveau 2 :**
- Ordre normal avec plus de transitions
- Questions faciles au début
- Progression douce

**Niveau 3 :**
- Ordre modifié : faciles d'abord
- Questions très faciles au début
- Progression très douce
- Retour aux questions normales si le stress diminue

**Niveau 4 :**
- Ordre complètement modifié
- Questions très faciles et positives uniquement
- Pas de progression vers des questions difficiles
- Report si stress persiste

---

## 5. Adaptation du Rythme

### 5.1 Adaptation du Débit de Parole

**Principe :**
Selon le niveau de stress, adapter le débit de parole pour ne pas submerger le candidat.

**Niveau 0-1 :**
- Débit normal
- Vitesse : 100%
- Pauses normales

**Niveau 2 :**
- Débit légèrement réduit
- Vitesse : 80%
- Pauses légèrement plus longues

**Niveau 3 :**
- Débit fortement réduit
- Vitesse : 60%
- Pauses beaucoup plus longues

**Niveau 4 :**
- Débit très réduit
- Vitesse : 40%
- Pauses très longues

### 5.2 Adaptation du Temps de Réponse

**Principe :**
Selon le niveau de stress, adapter le temps de réponse pour permettre au candidat de réfléchir sans pression.

**Niveau 0-1 :**
- Temps de réponse normal
- Délai : 5-10 secondes
- Pas de pression explicite

**Niveau 2 :**
- Temps de réponse augmenté
- Délai : 10-15 secondes
- Encouragement à prendre le temps

**Niveau 3 :**
- Temps de réponse fortement augmenté
- Délai : 15-20 secondes
- Encouragement explicite à prendre le temps

**Niveau 4 :**
- Temps de réponse très augmenté
- Délai : 20-30 secondes
- Pause explicite si nécessaire

### 5.3 Adaptation des Pauses

**Principe :**
Selon le niveau de stress, adapter les pauses pour permettre au candidat de respirer et se calmer.

**Niveau 0-1 :**
- Pauses normales entre les questions
- Durée : 2-3 secondes
- Naturelles

**Niveau 2 :**
- Pauses légèrement plus longues
- Durée : 3-5 secondes
- Explicitement bienveillantes

**Niveau 3 :**
- Pauses beaucoup plus longues
- Durée : 5-10 secondes
- Explicitement rassurantes

**Niveau 4 :**
- Pauses très longues
- Durée : 10-20 secondes
- Explicitement apaisantes

---

## 6. Adaptation des Objectifs

### 6.1 Adaptation de la Couverture

**Principe :**
Selon le niveau de stress, adapter la couverture des domaines d'évaluation pour se concentrer sur l'essentiel.

**Niveau 0-1 :**
- Couverture complète
- Tous les domaines prévus
- Évaluation exhaustive

**Niveau 2 :**
- Couverture quasi-complète
- Domaines essentiels prioritaires
- Évaluation quasi-exhaustive

**Niveau 3 :**
- Couverture partielle
- Domaines critiques uniquement
- Évaluation ciblée

**Niveau 4 :**
- Couverture minimale
- Domaines fondamentaux uniquement
- Évaluation minimale ou report

### 6.2 Adaptation de la Profondeur

**Principe :**
Selon le niveau de stress, adapter la profondeur de l'évaluation pour obtenir des informations essentielles malgré le stress.

**Niveau 0-1 :**
- Profondeur normale
- Questions détaillées
- Réponses approfondies attendues

**Niveau 2 :**
- Profondeur légèrement réduite
- Questions moins détaillées
- Réponses suffisantes attendues

**Niveau 3 :**
- Profondeur fortement réduite
- Questions très simples
- Réponses essentielles attendues

**Niveau 4 :**
- Profondeur très réduite
- Questions très basiques
- Réponses minimales attendues ou report

### 6.3 Adaptation des Critères d'Évaluation

**Principe :**
Selon le niveau de stress, adapter les critères d'évaluation pour compenser le stress et obtenir une évaluation juste.

**Niveau 0-1 :**
- Critères normaux
- Évaluation selon le plan
- Pas d'ajustement

**Niveau 2 :**
- Critères légèrement ajustés
- Évaluation avec compensation légère
- Ajustement mineur

**Niveau 3 :**
- Critères fortement ajustés
- Évaluation avec compensation forte
- Ajustement majeur

**Niveau 4 :**
- Critères très ajustés
- Évaluation avec compensation très forte
- Ajustement maximal ou report

## 7. Algorithme d'Adaptation

### 7.1 Détection et Classification

**Étape 1 — Détecter le niveau de stress :**
- Analyser les signaux linguistiques et de contenu
- Calculer le score de stress
- Classer le niveau (0-4)

**Étape 2 — Sélectionner le protocole d'adaptation :**
- Sélectionner le protocole selon le niveau
- Charger les règles d'adaptation correspondantes

### 7.2 Adaptation Dynamique

**Étape 3 — Adapter le plan d'entretien :**
- Modifier les questions selon le niveau
- Adapter le rythme selon le niveau
- Ajuster les objectifs selon le niveau

**Étape 4 — Appliquer les adaptations :**
- Appliquer les modifications en temps réel
- Surveiller l'effet des adaptations
- Ajuster si nécessaire

### 7.3 Réévaluation Continue

**Étape 5 — Réévaluer le niveau de stress :**
- Recalculer le niveau de stress après chaque réponse
- Ajuster les adaptations si le niveau change
- Passer au protocole supérieur ou inférieur si nécessaire

**Étape 6 — Documenter les adaptations :**
- Enregistrer les adaptations appliquées
- Documenter l'effet des adaptations
- Utiliser les données pour l'apprentissage

## 10. Stockage et Gestion

### 10.1 Schéma SQL

```sql
CREATE TABLE interview_plan_adaptation (
  id VARCHAR(36) PRIMARY KEY,
  candidate_id VARCHAR(36) NOT NULL,
  interview_id VARCHAR(36) NOT NULL,
  
  stress_level INT NOT NULL,
  
  original_plan JSON NOT NULL,
  adapted_plan JSON NOT NULL,
  adaptations_applied JSON NOT NULL,
  persona_adaptation JSON NOT NULL,
  effectiveness JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_interview_plan_adaptation_candidate ON interview_plan_adaptation(candidate_id);
CREATE INDEX idx_interview_plan_adaptation_interview ON interview_plan_adaptation(interview_id);
CREATE INDEX idx_interview_plan_adaptation_stress_level ON interview_plan_adaptation(stress_level);

CREATE TABLE adaptation_rules (
  id VARCHAR(36) PRIMARY KEY,
  
  level_rules JSON NOT NULL,
  question_adaptation JSON NOT NULL,
  rhythm_adaptation JSON NOT NULL,
  objective_adaptation JSON NOT NULL,
  adaptation_algorithm JSON NOT NULL,
  persona_adaptation JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
```

## 13. Conclusion

Les règles d'adaptation du plan d'entretien sous stress structurent les modifications du plan d'entretien selon le niveau de stress détecté. Le niveau 0-1 maintient le plan normal, le niveau 2 adapte subtilement (simplification des questions, augmentation du temps de réponse), le niveau 3 adapte significativement (forte simplification, changement d'ordre, pauses), et le niveau 4 suspend le plan (intervention forte, report). Les adaptations couvrent les questions, le rythme, et les objectifs.

**Points clés :**
- 5 niveaux d'adaptation (0 à 4)
- Adaptation des questions (simplification, type, ordre)
- Adaptation du rythme (débit, temps de réponse, pauses)
- Adaptation des objectifs (couverture, profondeur, critères)
- Algorithme d'adaptation dynamique
- Réévaluation continue du niveau de stress
- Adaptation par persona (4 personas)
- Structure de données TypeScript
- Stockage et gestion SQL
- API endpoints pour la gestion
- Métriques d'adaptation et d'efficacité
