**Version:** 1.0

**Auteur:** Trajectoire Team

---

## 1. Objectif

Définir le template de briefing recruteur (1 page) pour MVP-034 Interview Orchestrator. Ce briefing est produit par le moteur avant l'entretien et permet au recruteur de se préparer en 5 minutes avec les informations essentielles sur le candidat, le poste, et les points clés à surveiller.

---

## 2. Principe Fondateur

Le briefing recruteur doit être concis, pertinent, et immédiatement actionnable. Le recruteur doit pouvoir le lire en 5 minutes avant d'entrer en salle et savoir exactement quoi chercher, quoi demander, et quels signaux surveiller.

---

## 3. Structure du Briefing

### 3.1 En-tête

```
┌─────────────────────────────────────────────────────────────┐
│ BRIEFING ENTRETIEN                                        │
│ Candidat : [Prénom Nom]                                   │
│ Poste    : [Intitulé du poste]                            │
│ Durée    : [X] minutes                                    │
│ Date     : [Date/Heure]                                  │
└─────────────────────────────────────────────────────────────┘
```

---

### 3.2 Profil en 3 Mots

```
┌─────────────────────────────────────────────────────────────┐
│ EN 3 MOTS : [mot 1] / [mot 2] / [mot 3]                  │
└─────────────────────────────────────────────────────────────┘
```

**Exemples :**
- "Technique / Curieux / Résilient"
- "Leader / Visionnaire / Exigeant"
- "Créatif / Structuré / Collaboratif"

---

### 3.3 Points Clés

```
┌─────────────────────────────────────────────────────────────┐
│ FORCE PRINCIPALE : [1 ligne]                                │
│                                                             │
│ VIGILANCE PRINCIPALE : [1 ligne]                            │
│                                                             │
│ ZONE D'OMBRE CRITIQUE : [1 ligne]                           │
└─────────────────────────────────────────────────────────────┘
```

**Exemples :**
- Force principale : "Expertise technique solide en Python avec 5 ans d'expérience"
- Vigilance principale : "Tendance à surcharger les équipes, risque de burn-out"
- Zone d'ombre critique : "Motivations réelles pour quitter l'entreprise actuelle"

---

### 3.4 Question N°1 à Ne Pas Manquer

```
┌─────────────────────────────────────────────────────────────┐
│ QUESTION N°1 À NE PAS MANQUER :                            │
│ [Question spécifique au candidat]                          │
└─────────────────────────────────────────────────────────────┘
```

**Exemples :**
- "Vous avez mentionné une expérience chez X. Parlez-moi de la décision qui vous a amené à quitter cette entreprise."
- "Votre CV montre une progression rapide. Comment gérez-vous la pression associée ?"
- "Vous avez travaillé dans 3 secteurs différents. Qu'est-ce qui vous a motivé à changer ?"

---

### 3.5 Critères de Décision

```
┌─────────────────────────────────────────────────────────────┐
│ CE QUI FERAIT DIRE OUI :                                   │
│ • [Critère 1]                                              │
│ • [Critère 2]                                              │
│ • [Critère 3]                                              │
│                                                             │
│ CE QUI FERAIT DIRE NON :                                   │
│ • [Signal éliminatoire 1]                                  │
│ • [Signal éliminatoire 2]                                  │
│ • [Signal éliminatoire 3]                                  │
└─────────────────────────────────────────────────────────────┘
```

**Exemples :**
- Ce qui ferait dire OUI :
  - Démonstration de leadership dans au moins 2 situations
  - Alignement clair avec les valeurs de l'entreprise
  - Potentiel d'évolution à 3 ans

- Ce qui ferait dire NON :
  - Incohérence dans le parcours sans explication
  - Attitude défensive face aux questions difficiles
  - Motivation uniquement financière

---

### 3.6 Signaux à Surveiller

```
┌─────────────────────────────────────────────────────────────┐
│ SIGNAUX POSITIFS :                                        │
│ • [Signal 1] → [Indicateur]                               │
│ • [Signal 2] → [Indicateur]                               │
│                                                             │
│ SIGNAUX DE VIGILANCE :                                    │
│ • [Signal 1] → [Indicateur]                               │
│ • [Signal 2] → [Indicateur]                               │
└─────────────────────────────────────────────────────────────┘
```

**Exemples :**
- Signaux positifs :
  - Pose des questions pertinentes sur l'équipe → Intelligence relationnelle
  - Admet ses erreurs → Humilité et capacité d'apprentissage

- Signaux de vigilance :
  - Évite les réponses directes → Manque de transparence
  - Blame systématiquement les autres → Manque de responsabilité

---

### 3.7 Adaptations Recommandées

```
┌─────────────────────────────────────────────────────────────┐
│ SI LE CANDIDAT EST TRÈS À L'AISE :                        │
│ • Augmenter le niveau de challenge                         │
│ • Explorer davantage les zones d'ombre                       │

│ SI LE CANDIDAT EST STRESSÉ :                               │

│ • Commencer par des questions plus simples                  │
│ • Créer plus de cadre de confiance                         │

```

## 5. Structure de Données (TypeScript)

```typescript
interface RecruiterBriefing {
  briefingId: string;
  interviewId: string;
  
  header: {
    candidateName: string;
    jobTitle: string;
    duration: number;
    date: Date;
  };
  
  threeWords: {
    word1: string;
    word2: string;
    word3: string;
  };
  
  keyPoints: {
    mainStrength: string;
    mainVigilance: string;
    criticalShadowZone: string;
  };
  
  mustAskQuestion: {
    question: string;
    rationale: string;
  };
  
  decisionCriteria: {
    yes: string[];
    no: string[];
  };
  
  signalsToWatch: {
    positive: {
      signal: string;
      indicator: string;
    }[];
    vigilance: {
      signal: string;
      indicator: string;
    }[];
  };
  
  recommendedAdaptations: {
    ifVeryComfortable: string[];
    ifStressed: string[];
  };
  
  quickNotes: {
    overallImpression?: number;
    oneWordSummary?: string;
    whatILiked?: string;
    whatQuestionsMe?: string;
  };
  
  metadata: {
    generatedAt: Date;
    generatedBy: string;
    version: string;
  };
}
```

## 6. Stockage et Gestion

### 6.1 Schéma SQL

```sql
CREATE TABLE recruiter_briefing (
  id VARCHAR(36) PRIMARY KEY,
  interview_id VARCHAR(36) NOT NULL,
  
  header JSON NOT NULL,
  three_words JSON NOT NULL,
  key_points JSON NOT NULL,
  must_ask_question JSON NOT NULL,
  decision_criteria JSON NOT NULL,
  signals_to_watch JSON NOT NULL,
  recommended_adaptations JSON NOT NULL,
  quick_notes JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  
  FOREIGN KEY (interview_id) REFERENCES interview(id)
);

CREATE INDEX idx_recruiter_briefing_interview ON recruiter_briefing(interview_id);
```

## 9. Conclusion

Le template de briefing recruteur (1 page) permet au recruteur de se préparer en 5 minutes avant l'entretien avec les informations essentielles sur le candidat, le poste, et les points clés à surveiller. Le briefing est concis, pertinent, et immédiatement actionnable.

**Points clés :**
- Format 1 page facile à lire
- Profil en 3 mots pour mémorisation rapide
- Points clés (force, vigilance, zone d'ombre)
- Question N°1 à ne pas manquer
- Critères de décision clairs
- Signaux à surveiller (positifs, vigilance)
- Adaptations recommandées par profil
- Notes rapides post-entretien
- Structure de données TypeScript
- Stockage et gestion SQL
- API endpoints pour la gestion
- Métriques d'utilisation et de qualité
