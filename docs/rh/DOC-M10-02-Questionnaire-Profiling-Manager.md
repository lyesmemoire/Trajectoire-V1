---

## 1. Objectif

Définir le questionnaire de profiling manager pour le MVP-META-10 Manager Compatibility Engine. Ce document structure les 20 questions qui permettent de construire le profil manager en 5 dimensions.

---

## 2. Principe Fondateur

Le questionnaire est rempli par le manager avant le recrutement. Il est conçu pour révéler son style de management, ses attentes, et ses préférences sur les 5 dimensions fondamentales. Les réponses sont utilisées pour construire le profil manager et analyser la compatibilité avec les candidats.

---

## 3. Questionnaire (20 Questions)

### DIMENSION 1 — STYLE DE MANAGEMENT (4 questions)

**Question 1 :**
"Quand vous devez prendre une décision importante pour votre équipe, quelle est votre approche habituelle ?"
- A) Je prends la décision seul après analyse
- B) Je consulte l'équipe avant de décider
- C) Je fixe les objectifs et laisse l'équipe décider comment les atteindre
- D) Je pose des questions pour guider l'équipe vers la décision
- E) Je laisse l'équipe s'auto-organiser

**Question 2 :**
"Comment déléguez-vous le travail à votre équipe ?"
- A) Je donne des instructions précises et vérifie l'exécution
- B) Je délègue mais reste impliqué dans le processus
- C) Je fixe les objectifs et laisse faire avec confiance
- D) Je délègue en développant les compétences de l'équipe
- E) Je délègue sans suivi particulier

**Question 3 :**
"Quelle est votre priorité principale quand vous managez ?"
- A) L'exécution efficace des tâches
- B) La participation de l'équipe aux décisions
- C) L'autonomie de l'équipe
- D) Le développement des compétences
- E) L'auto-organisation de l'équipe

**Question 4 :**
"Comment réagissez-vous quand un membre de l'équipe a une idée différente de la vôtre ?"
- A) Je maintiens ma décision si je suis convaincu
- B) J'écoute et intègre l'avis dans ma décision
- C) Je laisse l'équipe tester l'idée
- D) Je pose des questions pour explorer l'idée
- E) Je laisse l'équipe décider

## 5. Stockage et Gestion

### 5.1 Schéma SQL

```sql
CREATE TABLE manager_questionnaire (
  id VARCHAR(36) PRIMARY KEY,
  manager_id VARCHAR(36) NOT NULL,
  
  responses JSON NOT NULL,
  completed_at TIMESTAMP NOT NULL,
  
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_manager_questionnaire_manager ON manager_questionnaire(manager_id);
```

## 9. Conclusion

Le questionnaire de profiling manager structure les 20 questions qui permettent de construire le profil manager en 5 dimensions. 4 questions par dimension : Style de management (décision, délégation, priorité, réaction idées), Besoin de contrôle (rapports, validation, réunions, autonomie), Style de communication (communication, feedback, réception info, conflits), Tolérance à l'erreur (erreur, échec, innovation, culture), Attentes implicites (disponibilité, équilibre vie pro/perso, télétravail, performance). Chaque question a 5 options de réponse (A à E). Structure de données TypeScript, stockage SQL, API endpoints pour la gestion.

**Points clés :**
- 20 questions structurées
- 4 questions par dimension
- 5 options de réponse par question
- Profil déduit des réponses
- Structure de données TypeScript
- Stockage et gestion SQL
- API endpoints pour la gestion
- Métriques de complétion et de qualité
