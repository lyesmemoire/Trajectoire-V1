## 1. Objectif

Définir les benchmarks de référence par type de poste pour le Correctif 7 Scoring Calibration. Ce document structure les seuils de score pour calibrer correctement le moteur et éviter les surestimations comme le cas Sophie (64/100 du moteur vs 45/100 attendu par un DRH senior).

---

## 2. Principe Fondateur

Pour calibrer correctement, le moteur utilise des benchmarks qui définissent les seuils de score pour chaque type de poste. Ces benchmarks intègrent aussi la calibration par rapport au marché (profil courant vs profil rare).

## 3. Benchmarks Généraux

### 3.1 Seuils de Score

| Score | Classification | Recommandation |
|-------|---------------|----------------|
| < 40 | Candidature clairement insuffisante pour ce poste | Ne pas recommander |
| 40-54 | Candidature insuffisante mais potentiel identifié | Poste d'une marche en dessous |
| 55-64 | Candidature à risque | Second entretien approfondi avant décision |
| 65-74 | Candidature acceptable avec réserves | Recommander avec conditions |
| 75-84 | Bonne candidature | Recommander |
| 85-94 | Très bonne candidature | Recommander fortement |
| 95+ | Candidature exceptionnelle | Recommander immédiatement et sécuriser rapidement |

### 3.2 Interprétation des Seuils

**Score < 40 : Candidature clairement insuffisante**
- Le candidat ne correspond pas aux exigences du poste
- Risque élevé d'échec dans le poste
- Recommandation : Ne pas recommander

**Score 40-54 : Candidature insuffisante mais potentiel identifié**
- Le candidat n'est pas prêt pour CE poste MAINTENANT
- Potentiel d'évolution identifié
- Recommandation : Poste d'une marche en dessous

**Score 55-64 : Candidature à risque**
- Le candidat présente des risques significatifs
- Nécessité d'un second entretien approfondi
- Recommandation : Second entretien approfondi avant décision

**Score 65-74 : Candidature acceptable avec réserves**
- Le candidat correspond aux exigences minimales
- Réserves identifiées
- Recommandation : Recommander avec conditions

**Score 75-84 : Bonne candidature**
- Le candidat correspond bien aux exigences du poste
- Recommandation : Recommander

**Score 85-94 : Très bonne candidature**
- Le candidat correspond très bien aux exigences du poste
- Recommandation : Recommander fortement

**Score 95+ : Candidature exceptionnelle**
- Le candidat correspond exceptionnellement bien aux exigences du poste
- Recommandation : Recommander immédiatement et sécuriser rapidement

**Contexte :**

**Justification :**
Standards élevés pour les postes DRH en raison des responsabilités juridiques et stratégiques. Les lacunes critiques (méconnaissance du droit du travail, incapacité à gérer les relations sociales) sont particulièrement pénalisantes.

Sophie a obtenu 64/100 du moteur ancien. Avec le nouveau système et les ajustements (lacunes critiques × 0.60, pénalités de silence −10), son score serait 24/100, ce qui correspond à "Candidature clairement insuffisante" pour un poste DRH.

## 5. Calibration par Rapport au Marché

### 5.1 Principe

Le score intègre aussi la rareté du profil :
- Profil courant sur le marché : Standards élevés maintenus
- Profil rare sur le marché : Standards ajustés à la réalité du marché
- Le moteur signale l'ajustement et sa raison

### 5.2 Classification des Profils

**Profil courant :**
- Candidats avec compétences et expérience courantes sur le marché
- Offre > Demande
- Standards élevés maintenus

**Profil rare :**
- Candidats avec compétences et expérience rares sur le marché
- Demande > Offre
- Standards ajustés à la réalité du marché

### 5.3 Ajustement des Benchmarks

**Pour les profils rares :**
- Réduction de 5 points sur les seuils de score
- Exemple : Seuil "Bonne candidature" passe de 75-84 à 70-79
- Le moteur signale l'ajustement et la raison (rareté du profil)

**Exemple :**
Poste DRH avec profil rare (expert en droit international du travail) :
- Seuil "Bonne candidature" : 70-79 (au lieu de 75-84)
- Seuil "Candidature acceptable" : 60-69 (au lieu de 65-74)
- Signal : "Ajustement de −5 points dû à la rareté du profil"

### 5.4 Détection de la Rareté

**Critères de rareté :**
- Compétences techniques rares
- Expérience dans des contextes spécifiques
- Connaissances spécialisées
- Combinaison de compétences peu courantes

**Processus de détection :**
1. Analyser le profil du candidat
2. Comparer avec les profils disponibles sur le marché
3. Identifier les éléments rares
4. Appliquer l'ajustement si nécessaire
5. Signaler l'ajustement dans le rapport

## 7. Stockage et Gestion

### 7.1 Schéma SQL

```sql
CREATE TABLE benchmark (
  id VARCHAR(36) PRIMARY KEY,
  position_type VARCHAR(50) NOT NULL,
  
  general JSON NOT NULL,
  specific JSON NOT NULL,
  market_adjustment JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_benchmark_position_type ON benchmark(position_type);

CREATE TABLE benchmark_library (
  id VARCHAR(36) PRIMARY KEY,
  
  benchmarks JSON NOT NULL,
  market_calibration JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 10. Conclusion

Les benchmarks de référence par type de poste structurent les seuils de score pour calibrer correctement le moteur. Benchmarks généraux : < 40 (insuffisante), 40-54 (insuffisante mais potentiel), 55-64 (à risque), 65-74 (acceptable avec réserves), 75-84 (bonne), 85-94 (très bonne), 95+ (exceptionnelle). Benchmarks spécifiques par type de poste : DRH (seuils plus élevés), Manager RH / Responsable Paie (standards élevés), Assistant RH / Chargé de Recrutement (standards plus accessibles), Ingénieur / Développeur (standards élevés sur compétences techniques), Commercial / Account Manager (standards élevés sur soft skills), Manager / Team Lead (standards élevés sur management). Calibration par rapport au marché : profil courant (standards élevés maintenus), profil rare (ajustement de −5 points, signalé dans le rapport). Détection de la rareté basée sur compétences techniques rares, expérience dans des contextes spécifiques, connaissances spécialisées. Structure de données TypeScript, stockage SQL, API endpoints pour la gestion.

- Benchmarks généraux avec 7 classifications

- Calibration par rapport au marché
