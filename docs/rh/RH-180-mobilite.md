# RH-180 — Mobilité

## Identité

RH-180 EST LE DOCUMENT MÉTIER DÉFINISSANT LA MOBILITÉ RH.

RH-180 EST LA SOURCE OFFICIELLE DE CONNAISSANCE POUR LA MOBILITÉ.

RH-180 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LA MOBILITÉ.

RH-180 EST LA RÉFÉRENCE NORMATIVE POUR TOUTE MOBILITÉ.

## Définitions

### Mobilité

LA MOBILITÉ EST LE PROCESSUS DE CHANGEMENT DE POSTE OU DE FONCTION D'UN SALARIÉ.

LA MOBILITÉ EST UN PROCESSUS STRUCTURÉ.

LA MOBILITÉ EST UN PROCESSUS DOCUMENTÉ.

LA MOBILITÉ EST UN PROCESSUS VOLONTAIRE OU IMPOSÉ.

LA MOBILITÉ EST SOUMISE AU DROIT DU TRAVAIL.

LA MOBILITÉ EST SOUMISE AUX CONVENTIONS COLLECTIVES.

LA MOBILITÉ EST SOUMISE AUX POLITIQUES INTERNES.

### Mobilité interne

LA MOBILITÉ INTERNE EST LE CHANGEMENT DE POSTE AU SEIN DE L'ORGANISATION.

LA MOBILITÉ INTERNE EST VOLONTAIRE.

LA MOBILITÉ INTERNE EST IMPOSÉE SOUS CONDITIONS.

LA MOBILITÉ INTERNE EST DOCUMENTÉE.

LA MOBILITÉ INTERNE EST TRAÇABLE.

### Mobilité externe

LA MOBILITÉ EXTERNE EST LE CHANGEMENT D'ORGANISATION.

LA MOBILITÉ EXTERNE EST VOLONTAIRE.

LA MOBILITÉ EXTERNE EST IMPOSÉE SOUS CONDITIONS.

LA MOBILITÉ EXTERNE EST DOCUMENTÉE.

LA MOBILITÉ EXTERNE EST TRAÇABLE.
