## 1. Objectif

Définir la cible de volume de patterns par phase de déploiement pour MVP-029 Institutional Memory Engine. Ce document définit les objectifs de volume de patterns pour atteindre les niveaux minimum viable, opérationnel, et expert, ainsi que la stratégie pour atteindre ces objectifs.

---

## 2. Principe Fondateur

La mémoire institutionnelle se construit progressivement. Le volume de patterns augmente avec le temps et l'utilisation du système. Les objectifs de volume sont définis par phase de déploiement pour assurer une progression réaliste et mesurable.

---

## 9. Stockage et Gestion

### 9.1 Schéma SQL

```sql
CREATE TABLE volume_target (
  id VARCHAR(36) PRIMARY KEY,
  phase VARCHAR(50) NOT NULL CHECK (phase IN ('minimum_viable', 'operational', 'expert')),
  
  total_patterns INT NOT NULL,
  success_patterns INT NOT NULL,
  institutional_errors INT NOT NULL,
  
  contextual_coverage JSON NOT NULL,
  quality_targets JSON NOT NULL,
  timeline JSON NOT NULL,
  monthly_targets JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_volume_target_phase ON volume_target(phase);

CREATE TABLE deployment_plan (
  id VARCHAR(36) PRIMARY KEY,
  
  phases JSON NOT NULL,
  
  current_phase VARCHAR(50) NOT NULL,
  current_volume INT NOT NULL,
  progress DECIMAL(5, 2) NOT NULL,
  
  next_milestone JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
