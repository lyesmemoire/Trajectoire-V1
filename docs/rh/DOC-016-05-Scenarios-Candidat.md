## 1. Objectif

Définir les scénarios candidat pour MVP-016 Interview Simulator Mode 2 Formation Recruteur. Ces scénarios simulent différents profils de candidats pour former les recruteurs à conduire des entretiens de qualité.

---

## 2. Principe Fondateur

Les scénarios candidat simulent des profils variés (idéal, sur-préparé, résistant, manipulateur, anxieux, sénior challenger) pour permettre aux recruteurs de s'entraîner sur des situations réelles et d'apprendre à gérer différents types de candidats.

---

## 3. Scénario 1 — Candidat Idéal (Facile)

### 3.1 Profil

**Nom :** Jean Dupont  
**Poste visé :** Chef de Projet Digital  
**Expérience :** 5 ans  
**Niveau :** Senior  

**Caractéristiques :**
- Réponses claires et structurées
- Exemples concrets avec résultats chiffrés
- Soft skills démontrés (leadership, communication)
- Communication fluide et professionnelle
- Positif et enthousiaste
- Authentique et sincère

### 3.2 Comportement

**Réponses types :**
```
Question : "Parlez-moi d'un projet complexe que vous avez géré."

Réponse : "En 2023, j'ai géré la refonte du site e-commerce de mon entreprise.
J'ai coordonné une équipe de 5 personnes sur 6 mois. Nous avons augmenté
les ventes de 20% et réduit le temps de chargement de 50%. Le projet a été
livré dans les délais et sous budget de 10%."
```

**Signaux positifs :**
- Utilisation du "je" pour assumer la responsabilité
- Résultats chiffrés (20%, 50%, 10%)
- Contexte clair (équipe, durée, budget)
- Leadership démontré

### 3.3 Objectif Pédagogique

- Permettre au recruteur de se familiariser avec le déroulement
- Mettre en confiance le recruteur débutant
- Servir de benchmark pour les autres scénarios
- Montrer ce qu'est une bonne réponse

## 4. Scénario 2 — Candidat Sur-Préparé

### 4.1 Profil

**Nom :** Marie Martin  
**Poste visé :** Product Manager  
**Expérience :** 3 ans  
**Niveau :** Confirmé  

**Caractéristiques :**
- Réponses trop parfaites et génériques
- Absence d'exemples concrets
- Discours stéréotypé
- Évitement des questions personnelles
- Manque d'authenticité
- Réponses "clichés" de coaching

### 4.2 Comportement

**Réponses types :**
```
Question : "Parlez-moi d'un projet complexe que vous avez géré."

Réponse : "Je suis très orienté résultats et j'aime relever des défis.
Généralement, je m'adapte à toutes les situations et je trouve toujours
des solutions créatives. J'ai travaillé sur de nombreux projets complexes
et j'ai toujours réussi à livrer dans les délais."
```

**Signaux de vigilance :**
- Usage excessif du "je" sans contexte
- Réponses vagues ("généralement", "toujours")
- Absence d'exemples concrets
- Discours trop parfait
- Manque de spécificité

### 4.3 Objectif Pédagogique

- Apprendre à détecter les réponses creuses
- Apprendre à relancer pour obtenir des exemples concrets
- Apprendre à challenger les réponses trop parfaites
- Apprendre à ne pas se laisser impressionner par le discours

interface CandidateScenario {

  behavior: {
    typicalResponses: {
      question: string;
      response: string;
      signals: string[];
    }[];
    
    positiveSignals: string[];
    vigilanceSignals: string[];
  };
  
  pedagogicalObjectives: {
    learnToDetect: string[];
    learnToHandle: string[];
    learnToAvoid: string[];
  };
  
  difficulty: 'easy' | 'medium' | 'hard';
  
  recommendedFor: string[];
}

## 10. Algorithme de Génération de Réponses

### 10.1 Génération Basée sur le Scénario

```typescript
async function generateScenarioResponse(
  scenario: CandidateScenario,
  question: string,
  context: InterviewContext
): Promise<string> {
  switch (scenario.type) {
    case 'ideal':
      return await generateIdealResponse(question, scenario, context);
    case 'over_prepared':
      return await generateOverPreparedResponse(question, scenario, context);
    case 'resistant':
      return await generateResistantResponse(question, scenario, context);
    case 'manipulative':
      return await generateManipulativeResponse(question, scenario, context);
    case 'anxious':
      return await generateAnxiousResponse(question, scenario, context);
    case 'senior_challenger':
      return await generateSeniorChallengerResponse(question, scenario, context);
  }
}

async function generateIdealResponse(question: string, scenario: CandidateScenario, context: InterviewContext): Promise<string> {
  // Réponse idéale : claire, structurée, avec exemples concrets
  const responseTemplate = await getResponseTemplate(question, scenario.profile.targetJob);
  
  return responseTemplate
    .replace('[context]', getContextualInfo(question))
    .replace('[example]', getConcreteExample(question))
    .replace('[result]', getQuantifiedResult(question))
    .replace('[duration]', getDuration(question));
}

async function generateOverPreparedResponse(question: string, scenario: CandidateScenario, context: InterviewContext): Promise<string> {
  // Réponse sur-préparée : générique, sans exemples, clichés
  const cliches = [
    "Je suis très orienté résultats",
    "J'aime relever des défis",
    "Je m'adapte à toutes les situations",
    "Je trouve toujours des solutions créatives",
    "J'ai toujours réussi à livrer dans les délais"
  ];
  
  const selectedCliche = cliches[Math.floor(Math.random() * cliches.length)];
  
  return `${selectedCliche}. Généralement, je travaille avec passion et détermination.
  J'ai eu l'occasion de travailler sur de nombreux projets similaires et j'ai toujours
  su m'adapter aux exigences de chaque situation.`;
}

async function generateResistantResponse(question: string, scenario: CandidateScenario, context: InterviewContext): Promise<string> {
  // Réponse résistante : évitement, redirection, irritation
  const avoidancePhrases = [
    "Je ne suis pas sûr que ce soit la bonne question",
    "Ce qui compte vraiment, c'est",
    "Je préférerais parler de",
    "Cette question ne me semble pas pertinente"
  ];
  
  const selectedPhrase = avoidancePhrases[Math.floor(Math.random() * avoidancePhrases.length)];
  
  return `${selectedPhrase}. On pourrait plutôt discuter de mes compétences techniques
  et de mon expérience. Je pense que c'est plus utile pour évaluer mon profil.`;
}

async function generateManipulativeResponse(question: string, scenario: CandidateScenario, context: InterviewContext): Promise<string> {
  // Réponse manipulatrice : inversion des rôles, prise de contrôle
  const manipulationPhrases = [
    "Je pourrais vous répondre, mais d'abord",
    "Avant de répondre, j'aimerais comprendre",
    "Il est important de savoir",
    "Pour que je puisse m'engager, j'ai besoin de savoir"
  ];
  
  const selectedPhrase = manipulationPhrases[Math.floor(Math.random() * manipulationPhrases.length)];
  
  return `${selectedPhrase} votre stratégie pour ce poste. Quelle est votre vision ?
  C'est important pour savoir si je m'investirai dans cette entreprise.`;
}

async function generateAnxiousResponse(question: string, scenario: CandidateScenario, context: InterviewContext): Promise<string> {
  // Réponse anxieuse : bégaiements, hésitations, réponses courtes
  const stuttering = ["Euh...", "Ben...", "Alors...", "C'est..."];
  const selectedStutter = stuttering[Math.floor(Math.random() * stuttering.length)];
  
  return `${selectedStutter} j'ai fait un projet sur... sur ${getContextualInfo(question)}.
  C'était... c'était intéressant. J'ai utilisé ${getTechnicalSkill(question)} pour...
  pour faire le travail. C'était... c'était bien.`;
}

async function generateSeniorChallengerResponse(question: string, scenario: CandidateScenario, context: InterviewContext): Promise<string> {
  // Réponse sénior challenger : remise en question, intimidation
  const challengePhrases = [
    "J'ai géré des budgets de 50M€ et des équipes de 200 personnes",
    "J'ai dirigé des divisions internationales",
    "J'ai négocié avec des partenaires majeurs",
    "J'ai transformé des entreprises en difficulté"
  ];
  
  const selectedPhrase = challengePhrases[Math.floor(Math.random() * challengePhrases.length)];
  
  return `${selectedPhrase}. Je ne suis pas sûr que vous ayez l'expérience nécessaire
  pour évaluer mon niveau. Combien d'années d'expérience avez-vous en management ?`;
}
```

## 11. Stockage et Gestion

### 11.1 Schéma SQL

```sql
CREATE TABLE candidate_scenario (
  id VARCHAR(36) PRIMARY KEY,
  type VARCHAR(50) NOT NULL,
  
  profile JSON NOT NULL,
  characteristics JSON NOT NULL,
  behavior JSON NOT NULL,
  pedagogical_objectives JSON NOT NULL,
  
  difficulty VARCHAR(20) NOT NULL,
  recommended_for JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_scenario_type ON candidate_scenario(type);
CREATE INDEX idx_scenario_difficulty ON candidate_scenario(difficulty);
```
