# RH-900 — Use Cases

## Identité

RH-900 EST LE CATALOGUE OFFICIEL DES CAS D'USAGE RH.

RH-900 DÉCRIT LES CAS MÉTIER DU MOTEUR COGNITIF RH.

RH-900 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LES SCÉNARIOS RH.

RH-900 EST LA RÉFÉRENCE POUR TOUS LES CAS D'USAGE RH.

## Cas d'usage 1 à 10

### UC-001 : Un manager veut recruter

**Contexte :** Un manager a un besoin de recrutement pour son équipe.

**Objectif :** Identifier les étapes du processus de recrutement et les contraintes associées.

**Connaissances mobilisées :** RH-100 Recrutement, RH-130 Poste, RH-140 Compétence, RH-110 Contrat.

**Raisonnement attendu :** Le moteur identifie le besoin, consulte la fiche de poste, vérifie les compétences requises, et décrit le processus de recrutement conformément au droit du travail.

**Résultat attendu :** Description structurée du processus de recrutement avec les étapes, les contraintes légales et conventionnelles, et les documents requis.

### UC-002 : Comparer deux CV

**Contexte :** Un manager doit comparer deux candidats pour un poste.

**Objectif :** Comparer les compétences, qualifications et expériences des deux candidats par rapport au poste.

**Connaissances mobilisées :** RH-100 Recrutement, RH-140 Compétence, RH-130 Poste, RH-002 Vocabulaire RH.

**Raisonnement attendu :** Le moteur analyse les compétences de chaque candidat, les compare aux compétences requises par le poste, et identifie les écarts.

**Résultat attendu :** Tableau comparatif des deux candidats avec les points forts, les points faibles, et une recommandation basée sur les critères objectifs.

### UC-003 : Créer une fiche de poste

**Contexte :** Un manager doit créer une nouvelle fiche de poste.

**Objectif :** Définir les éléments obligatoires d'une fiche de poste conformément aux normes RH.

**Connaissances mobilisées :** RH-130 Poste, RH-140 Compétence, RH-002 Vocabulaire RH, RH-005 Référentiel RH.

**Raisonnement attendu :** Le moteur identifie les éléments obligatoires (intitulé, responsabilités, compétences requises, qualifications, conditions de travail, rémunération) et vérifie la conformité avec la convention collective.

**Résultat attendu :** Structure de fiche de poste complète avec tous les éléments obligatoires et les contraintes à respecter.

### UC-004 : Détecter un manque de compétence

**Contexte :** Un manager identifie un écart entre les compétences d'un salarié et les compétences requises par son poste.

**Résultat attendu :** Rapport d'écart de compétences avec les formations recommandées pour combler les manques.

### UC-005 : Préparer un entretien annuel
