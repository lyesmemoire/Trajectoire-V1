## 1. Objectif

Définir la Synthèse Entretien pour MVP-013 Interview Intelligence. Cette synthèse générée automatiquement après chaque entretien compile les notes, les cotations, les signaux détectés, et formule une recommandation structurée pour le recruteur.

---

## 2. Principe Fondateur

La Synthèse Entretien n'est pas un simple résumé. Elle compile toutes les données de l'entretien (notes, cotations, signaux, réponses) pour générer une recommandation structurée avec des points forts, des points faibles, des zones d'ombre, et une décision finale justifiée.

## 5. Génération de la Synthèse

### 5.1 Processus de Génération

```typescript
async function generateInterviewSummary(interviewId: string): Promise<InterviewSummary> {
  // Étape 1 : Récupération des données de l'entretien
  const interview = await getInterview(interviewId);
  const ratings = await getRatings(interviewId);
  const signalDetections = await getSignalDetections(interviewId);
  const responses = await getResponses(interviewId);
  const recruiterNotes = await getRecruiterNotes(interviewId);
  
  // Étape 2 : Génération du résumé exécutif
  const executiveSummary = await generateExecutiveSummary(ratings, signalDetections);
  
  // Étape 3 : Extraction des points forts
  const strengths = await extractStrengths(responses, signalDetections);
  
  // Étape 4 : Extraction des points faibles
  const weaknesses = await extractWeaknesses(responses, signalDetections);
  
  // Étape 5 : Compilation des signaux détectés
  const detectedSignals = await compileSignals(signalDetections);
  
  // Étape 6 : Compilation des cotations par critère
  const criteriaRatings = await compileCriteriaRatings(ratings);
  
  // Étape 7 : Sélection des réponses clés
  const keyResponses = await selectKeyResponses(responses);
  
  // Étape 8 : Génération de la recommandation finale
  const finalRecommendation = await generateFinalRecommendation(executiveSummary, criteriaRatings, detectedSignals);
  
  // Construction de la synthèse
  const summary: InterviewSummary = {
    summaryId: generateSummaryId(),
    interviewId,
    candidateId: interview.candidateId,
    jobId: interview.jobId,
    recruiterId: interview.recruiterId,
    interviewDate: interview.startedAt,
    duration: interview.duration,
    generatedAt: new Date(),
    
    executiveSummary,
    strengths,
    weaknesses,
    detectedSignals,
    criteriaRatings,
    keyResponses,
    finalRecommendation,
    recruiterNotes
  };
  
  // Sauvegarde de la synthèse
  await saveSummary(summary);
  
  return summary;
}
```

### 5.2 Génération du Résumé Exécutif

```typescript
async function generateExecutiveSummary(ratings: Rating[], signalDetections: SignalDetection[]): Promise<InterviewSummary['executiveSummary']> {
  // Calcul du score global
  const globalScore = await calculateGlobalScore(ratings);
  
  // Détermination de la recommandation
  const recommendation = await determineRecommendation(globalScore, signalDetections);
  
  // Extraction des points clés
  const keyPoints = await extractKeyPoints(ratings, signalDetections);
  
  return {
    globalScore,
    recommendation,
    keyPoints
  };
}

async function determineRecommendation(globalScore: number, signalDetections: SignalDetection[]): Promise<'strong_recommend' | 'moderate_recommend' | 'not_recommend'> {
  // Compte des signaux de risque
  const riskSignals = signalDetections.filter(d => d.severity === 'high').length;
  
  // Si score élevé et peu de signaux de risque
  if (globalScore >= 4.0 && riskSignals === 0) {
    return 'strong_recommend';
  }
  
  // Si score moyen et signaux de risque modérés
  if (globalScore >= 3.5 && riskSignals <= 1) {
    return 'moderate_recommend';
  }
  
  // Si score faible ou signaux de risque élevés
  if (globalScore < 3.5 || riskSignals >= 2) {
    return 'not_recommend';
  }
  
  return 'moderate_recommend';
}
```

### 5.3 Extraction des Points Forts

```typescript
async function extractStrengths(responses: CandidateResponse[], signalDetections: SignalDetection[]): Promise<InterviewSummary['strengths']> {
  const strengths: InterviewSummary['strengths'] = {
    technical: [],
    experience: [],
    behavioral: [],
    leadership: [],
    cultureFit: []
  };
  
  // Extraction des signaux positifs
  for (const detection of signalDetections) {
    for (const signal of detection.positiveSignals.detected) {
      if (signal.includes('concret') || signal.includes('chiffré')) {
        strengths.technical.push(signal);
      }
      if (signal.includes('leadership') || signal.includes('initiative')) {
        strengths.leadership.push(signal);
      }
      if (signal.includes('collaboration') || signal.includes('équipe')) {
        strengths.behavioral.push(signal);
      }
      if (signal.includes('culture') || signal.includes('valeurs')) {
        strengths.cultureFit.push(signal);
      }
    }
  }
  
  // Extraction des réponses positives
  for (const response of responses) {
    if (response.analysis.clarity > 0.7) {
      strengths.behavioral.push('Communication claire et structurée');
    }
    if (response.analysis.specificity > 0.7) {
      strengths.technical.push('Réponses spécifiques et détaillées');
    }
  }
  
  return strengths;
}
```

### 5.4 Extraction des Points Faibles

```typescript
async function extractWeaknesses(responses: CandidateResponse[], signalDetections: SignalDetection[]): Promise<InterviewSummary['weaknesses']> {
  const weaknesses: InterviewSummary['weaknesses'] = {
    technical: [],
    experience: [],
    behavioral: [],
    leadership: [],
    cultureFit: []
  };
  
  // Extraction des signaux de vigilance
  for (const detection of signalDetections) {
    for (const signal of detection.vigilanceSignals.detected) {
      if (signal.includes('vague') || signal.includes('quantifier')) {
        weaknesses.technical.push(signal);
      }
      if (signal.includes('incohérence') || signal.includes('CV')) {
        weaknesses.experience.push(signal);
      }
      if (signal.includes('critique') || signal.includes('victimaire')) {
        weaknesses.behavioral.push(signal);
      }
      if (signal.includes('culture') || signal.includes('valeurs')) {
        weaknesses.cultureFit.push(signal);
      }
    }
  }
  
  // Extraction des réponses faibles
  for (const response of responses) {
    if (response.analysis.clarity < 0.5) {
      weaknesses.behavioral.push('Communication vague et peu structurée');
    }
    if (response.analysis.specificity < 0.5) {
      weaknesses.technical.push('Réponses générales sans détails');
    }
  }
  
  return weaknesses;
}
```

### 5.5 Compilation des Signaux

```typescript
async function compileSignals(signalDetections: SignalDetection[]): Promise<InterviewSummary['detectedSignals']> {
  const detectedSignals: InterviewSummary['detectedSignals'] = {
    positive: [],
    vigilance: [],
    risk: []
  };
  
  for (const detection of signalDetections) {
    // Signaux positifs
    for (const signal of detection.positiveSignals.detected) {
      if (!detectedSignals.positive.includes(signal)) {
        detectedSignals.positive.push(signal);
      }
    }
    
    // Signaux de vigilance
    for (const signal of detection.vigilanceSignals.detected) {
      if (!detectedSignals.vigilance.includes(signal)) {
        detectedSignals.vigilance.push(signal);
      }
    }
    
    // Signaux de risque
    if (detection.severity === 'high') {
      for (const signal of detection.vigilanceSignals.detected) {
        if (!detectedSignals.risk.includes(signal)) {
          detectedSignals.risk.push(signal);
        }
      }
    }
  }
  
  return detectedSignals;
}
```

### 5.6 Compilation des Cotations

```typescript
async function compileCriteriaRatings(ratings: Rating[]): Promise<InterviewSummary['criteriaRatings']> {
  const criteriaRatings: InterviewSummary['criteriaRatings'] = [];
  
  for (const rating of ratings) {
    const criterion = await getCriterion(rating.criterionId);
    
    criteriaRatings.push({
      criterionName: criterion.name,
      rating: rating.rating,
      threshold: criterion.decisionThreshold,
      status: rating.rating >= criterion.decisionThreshold ? 'above_threshold' : 'below_threshold',
      justification: rating.justification || ''
    });
  }
  
  return criteriaRatings;
}
```

### 5.7 Sélection des Réponses Clés

```typescript
async function selectKeyResponses(responses: CandidateResponse[]): Promise<InterviewSummary['keyResponses']> {
  const keyResponses: InterviewSummary['keyResponses'] = [];
  
  // Sélection des réponses aux questions incontournables
  const mustAskResponses = responses.filter(r => r.question.type === 'must_ask');
  
  for (const response of mustAskResponses) {
    keyResponses.push({
      question: response.question.question,
      responseSummary: await summarizeResponse(response.transcription),
      analysis: response.analysis.summary
    });
  }
  
  // Sélection des réponses aux questions de déstabilisation
  const destabilizationResponses = responses.filter(r => r.question.type === 'destabilizer');
  
  for (const response of destabilizationResponses) {
    keyResponses.push({
      question: response.question.question,
      responseSummary: await summarizeResponse(response.transcription),
      analysis: response.analysis.summary
    });
  }
  
  return keyResponses;
}

async function summarizeResponse(transcription: string): Promise<string> {
  // Résumé automatique de la réponse
  const sentences = transcription.split('. ');
  const summary = sentences.slice(0, 3).join('. ');
  
  return summary + (sentences.length > 3 ? '...' : '.');
}
```

### 5.8 Génération de la Recommandation Finale

```typescript
async function generateFinalRecommendation(
  executiveSummary: InterviewSummary['executiveSummary'],
  criteriaRatings: InterviewSummary['criteriaRatings'],
  detectedSignals: InterviewSummary['detectedSignals']
): Promise<InterviewSummary['finalRecommendation']> {
  const decision = executiveSummary.recommendation;
  
  let justification = '';
  let conditions: string[] = [];
  const nextSteps: string[] = [];
  
  if (decision === 'strong_recommend') {
    justification = `Le candidat obtient un score global de ${executiveSummary.globalScore}/5, au-dessus du seuil de recommandation. Les points forts incluent ${executiveSummary.keyPoints.join(', ')}. Aucun signal de risque majeur détecté.`;
    nextSteps.push('Proposer une offre');
    nextSteps.push('Planifier l\'onboarding');
  } else if (decision === 'moderate_recommend') {
    justification = `Le candidat obtient un score global de ${executiveSummary.globalScore}/5, légèrement au-dessus du seuil. Les points forts incluent ${executiveSummary.keyPoints.slice(0, 2).join(', ')}. Certains signaux de vigilance détectés : ${detectedSignals.vigilance.slice(0, 2).join(', ')}.`;
    conditions.push('Vérifier les références');
    conditions.push('Entretien complémentaire avec le futur manager');
    nextSteps.push('Vérifier les références');
    nextSteps.push('Planifier un entretien complémentaire');
  } else {
    justification = `Le candidat obtient un score global de ${executiveSummary.globalScore}/5, en dessous du seuil de recommandation. Les points faibles incluent ${detectedSignals.vigilance.slice(0, 2).join(', ')}. Signaux de risque détectés : ${detectedSignals.risk.join(', ')}.`;
    nextSteps.push('Informer le candidat du rejet');
    nextSteps.push('Archiver le dossier');
  }
  
  return {
    decision,
    justification,
    conditions: conditions.length > 0 ? conditions : undefined,
    nextSteps
  };
}
```

## 9. Conclusion

La Synthèse Entretien compile toutes les données de l'entretien pour générer une recommandation structurée avec des points forts, des points faibles, des zones d'ombre, et une décision finale justifiée. Elle n'est pas un simple résumé mais une analyse complète de l'entretien.

**Points clés :**
- Résumé exécutif (score global, recommandation, points clés)
- Points forts par catégorie (technique, expérience, comportement, leadership, culture fit)
- Points faibles par catégorie (technique, expérience, comportement, leadership, culture fit)
- Signaux détectés (positifs, vigilance, risque)
- Cotations par critère (note, seuil, statut, justification)
- Réponses clés (questions incontournables, questions de déstabilisation)
- Recommandation finale (décision, justification, conditions, étapes suivantes)
- Notes du recruteur
