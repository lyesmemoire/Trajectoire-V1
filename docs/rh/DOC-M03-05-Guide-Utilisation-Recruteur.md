## 1. Objectif

Fournir un guide d'utilisation pratique pour le recruteur sur le MVP-META-03 Comparative Intelligence Engine. Ce document explique comment utiliser le tableau comparatif, les analyses comparatives, et la recommandation finale pour prendre des décisions éclairées.

---

## 2. Principe Fondateur

Le moteur comparative intelligence aide le recruteur à prendre des décisions basées sur des données comparatives, pas seulement sur des scores absolus. Le recruteur peut voir le tableau comparatif en temps réel, consulter les 4 analyses, et suivre la recommandation finale.

---

## 3. Accès au Tableau Comparatif

### 3.1 Où trouver le tableau comparatif

**Emplacement :**
- Espace Recruteur → Recrutement en cours → Tableau comparatif
- Accessible dès qu'au moins un candidat a été évalué

### 3.2 Lecture du tableau comparatif

**Comprendre les colonnes :**
- **Candidat** : Nom du candidat
- **Tech** : Compétences techniques (0-5)
- **Expér.** : Expérience professionnelle (0-5)
- **Soft** : Soft skills (0-5)
- **Fit** : Fit culturel (0-5)
- **Maturité** : Maturité professionnelle (0-5)
- **Potent.** : Potentiel d'évolution (0-5)

**Comprendre la ligne "Meilleur sur ce critère" :**
- Indique le candidat avec le score le plus élevé pour chaque dimension
- Utile pour identifier les forces spécifiques de chaque candidat

---

## 4. Utilisation des 4 Analyses Comparatives

### 4.1 Analyse 1 : Candidat le plus équilibré

**Quand l'utiliser :**
- Pour identifier le candidat le plus polyvalent
- Pour éviter les profils brillants mais lacunaires

**Comment l'interpréter :**
- Écart-type faible = profil équilibré
- Écart-type élevé = profil spécialisé avec des forces et faiblesses marquées

**Exemple d'utilisation :**
- Si vous cherchez un profil polyvalent pour un poste généraliste, privilégiez le candidat le plus équilibré
- Si vous cherchez un expert sur une dimension spécifique, l'équilibre est moins important

### 4.2 Analyse 2 : Candidat le plus fort sur le critère différenciateur

**Quand l'utiliser :**
- Pour identifier le candidat le meilleur sur la dimension critique du poste

**Comment l'interpréter :**
- Le critère différenciateur est défini par le poste (ex: Relations sociales pour DRH)
- Le candidat avec le score le plus élevé sur ce critère est mis en avant

**Exemple d'utilisation :**
- Pour un DRH, le critère différenciateur est les Relations sociales
- Le candidat avec le score le plus élevé en Soft skills est recommandé

### 4.3 Analyse 3 : Candidat à meilleur ROI

**Quand l'utiliser :**
- Pour optimiser le budget recrutement
- Pour identifier les candidats avec le meilleur rapport qualité/prix

**Comment l'interpréter :**
- ROI salarial : Score global / Attentes salariales
- ROI disponibilité : Score global / Délai de disponibilité
- ROI combiné : Moyenne des deux ROI

**Exemple d'utilisation :**
- Si le budget est contraint, privilégiez le candidat avec le meilleur ROI salarial
- Si l'urgence est critique, privilégiez le candidat avec le meilleur ROI disponibilité

### 4.4 Analyse 4 : Profils complémentaires

**Quand l'utiliser :**
- Si plusieurs postes sont ouverts simultanément
- Pour optimiser la composition de l'équipe globale

**Comment l'interpréter :**
- Le moteur identifie la combinaison de candidats qui maximise le score de l'équipe
- Prend en compte l'équilibre et la diversité de l'équipe

**Exemple d'utilisation :**
- Si vous recrutez un DRH et un Manager RH, le moteur suggère la combinaison optimale
- Prenez en compte la complémentarité des profils pour une équipe équilibrée

## 5. Utilisation de la Recommandation Comparative Finale

### 5.1 Comprendre la recommandation principale

**La recommandation principale :**
- Candidat recommandé avec score global
- Raison principale basée sur les 4 analyses
- Analyse détaillée (candidat le plus équilibré, meilleur sur critère différenciateur, meilleur ROI)

**Comment l'utiliser :**
- La recommandation est une suggestion, pas une obligation
- Utilisez-la comme point de départ pour votre décision
- Prenez en compte les risques acceptés et les opportunités manquées

### 5.2 Comprendre "Pourquoi pas les autres"

**Pour chaque candidat non recommandé :**
- Meilleur sur quelle dimension
- Insuffisant sur quelle dimension critique
- Score global

**Comment l'utiliser :**
- Comprendre les faiblesses de chaque candidat
- Identifier si une faiblesse est rédhibitoire ou acceptable
- Comparer les candidats sur des critères spécifiques

### 5.3 Comprendre les risques acceptés

**Risques acceptés en choisissant le candidat recommandé :**
- Faiblesse du candidat
- Plan de mitigation proposé

**Comment l'utiliser :**
- Évaluez si vous êtes prêt à accepter ce risque
- Utilisez le plan de mitigation comme base pour l'onboarding
- Adaptez le plan de mitigation selon vos contraintes

### 5.4 Comprendre l'opportunité manquée

**Opportunité manquée en ne choisissant pas un autre candidat :**
- Dimension sur laquelle l'autre candidat est meilleur
- Plan préventif si cette dimension devient critique

**Comment l'utiliser :**
- Anticipez les besoins futurs de l'équipe
- Utilisez le plan préventif pour combler la lacune à terme
- Évaluez si l'opportunité manquée est critique

### 5.5 Comprendre la qualité du lot global

**Qualité du lot :**
- Supérieur / Standard / Inférieur au marché
- Moyenne des scores globaux
- Écart-type des scores globaux

**Recommandation :**
- Décider maintenant si le lot est de qualité suffisante
- Élargir la recherche si le lot est de qualité insuffisante

**Comment l'utiliser :**
- Si le lot est inférieur, élargissez la recherche
- Si le lot est standard, décidez selon vos contraintes
- Si le lot est supérieur, décidez rapidement pour ne pas perdre les candidats

## 6. Bonnes Pratiques

### 6.1 Avant le recrutement

**Définir les critères différenciateurs :**
- Pour chaque poste, définissez la dimension critique
- Assurez-vous que le critère est aligné avec les besoins de l'entreprise

**Définir les contraintes budgétaires :**
- Définissez le budget maximum
- Définissez le délai maximum de disponibilité

### 6.2 Pendant le recrutement

**Suivre le tableau comparatif en temps réel :**
- Consultez le tableau après chaque entretien
- Observez l'évolution du lot de candidats

**Utiliser les analyses comparatives :**
- Consultez les 4 analyses régulièrement
- Adaptez votre stratégie selon les résultats

### 6.3 Après le recrutement

**Documenter la décision :**
- Expliquez pourquoi vous avez suivi ou non la recommandation
- Documentez les risques acceptés et les plans de mitigation

**Feedback sur le moteur :**
- Indiquez si la recommandation était pertinente
- Signalez les cas où le moteur s'est trompé

## 7. Cas d'Usage

### 7.1 Cas 1 : Budget contraint

**Situation :**
- Budget limité à 50K€
- 3 candidats évalués

**Action :**
- Consultez l'analyse ROI
- Identifiez le candidat avec le meilleur ROI salarial
- Évaluez si le candidat est acceptable malgré un score global inférieur

### 7.2 Cas 2 : Urgence critique

**Situation :**
- Poste à pourvoir dans les 15 jours
- 2 candidats disponibles immédiatement, 1 candidat disponible dans 2 mois

**Action :**
- Consultez l'analyse ROI disponibilité
- Identifiez le candidat avec le meilleur ROI disponibilité
- Évaluez si le candidat est acceptable malgré un score global inférieur

### 7.3 Cas 3 : Profil polyvalent recherché

**Situation :**
- Poste généraliste nécessitant un profil équilibré
- 3 candidats avec des profils très différents

**Action :**
- Consultez l'analyse candidat le plus équilibré
- Identifiez le candidat avec l'écart-type le plus faible
- Évaluez si le candidat est acceptable malgré un score global inférieur

### 7.4 Cas 4 : Expertise spécifique recherchée

**Situation :**
- Poste nécessitant une expertise spécifique (ex: Relations sociales pour DRH)
- 3 candidats avec des forces différentes

**Action :**
- Consultez l'analyse meilleur sur critère différenciateur
- Identifiez le candidat avec le score le plus élevé sur le critère critique
- Évaluez si le candidat est acceptable malgré des faiblesses sur d'autres dimensions

## 8. FAQ

### 8.1 Le moteur remplace-t-il le recruteur ?

**Non.** Le moteur est un outil d'aide à la décision. Le recruteur reste le décideur final.

### 8.2 Que faire si je ne suis pas la recommandation ?

**Documentez votre décision.** Expliquez pourquoi vous avez choisi un autre candidat. Ce feedback aide à améliorer le moteur.

### 8.3 Le tableau comparatif est-il mis à jour automatiquement ?

**Oui.** Le tableau est mis à jour automatiquement après chaque entretien terminé.

### 8.4 Puis-je modifier les scores ?

**Oui.** Si vous estimez qu'un score est incorrect, vous pouvez le modifier. Le tableau et les analyses seront régénérés automatiquement.

### 8.5 Que faire si le lot est de qualité insuffisante ?

**Élargissez la recherche.** Le moteur recommande d'élargir la recherche si le lot est inférieur au marché.
