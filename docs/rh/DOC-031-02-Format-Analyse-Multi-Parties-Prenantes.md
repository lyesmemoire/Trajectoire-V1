**Version:** 1.0  
**Date:** 2026-08-03  
**Statut:** Draft  
**Auteur:** Trajectoire Team

---

## 1. Objectif

Définir le format d'analyse multi-parties prenantes pour MVP-031 Ethical Compass Engine. Ce format structure l'analyse de l'impact de chaque décision importante sur toutes les parties prenantes : le candidat retenu, les candidats refusés, l'équipe, l'entreprise, et la société dans son ensemble.

---

## 2. Principe Fondateur

Pour chaque décision importante, le moteur analyse l'impact sur chaque partie prenante. Cette analyse permet d'identifier les parties lésées, les risques potentiels, et les opportunités d'amélioration. Le bilan éthique global synthétise l'impact global de la décision et propose des ajustements pour atténuer les impacts négatifs.

---

## 3. Format d'Analyse

### 3.1 Structure Générale

```
ANALYSE MULTI-PARTIES PRENANTES

DÉCISION CONSIDÉRÉE :
  [Description de la décision]

IMPACT SUR LE CANDIDAT RETENU :
  Court terme : [analyse]
  Long terme  : [analyse]
  Risques pour lui : [liste]

IMPACT SUR LES CANDIDATS REFUSÉS :
  Traitement reçu : [équitable / à améliorer]
  Feedback reçu   : [utile / insuffisant]
  Dignité préservée : [oui / non / partiellement]

IMPACT SUR L'ÉQUIPE :
  Dynamique attendue : [analyse]
  Risques de friction : [liste]
  Opportunités : [liste]

IMPACT SUR L'ENTREPRISE :
  Court terme : [analyse]
  Long terme  : [analyse]
  Risques : [liste]

IMPACT SUR LA SOCIÉTÉ :
  Contribution à l'équité : [analyse]
  Risque de discrimination systémique : [analyse]

BILAN ÉTHIQUE GLOBAL :
  Cette décision est-elle juste pour toutes les parties prenantes ?
  Quelle partie prenante est lésée ?
  Comment atténuer cet impact ?
```

---

### 3.2 Section 1 — Décision Considérée

**Contenu :**
Description claire et concise de la décision analysée.

**Format :**
```
DÉCISION CONSIDÉRÉE :
  [Description de la décision]
  Contexte : [contexte]
  Date : [date]
  Décideur : [nom]
```

**Exemple :**
```
DÉCISION CONSIDÉRÉE :
  Recrutement de Jean Dupont pour le poste de Head of Product
  Contexte : Fintech / Scale-up
  Date : 2026-08-03
  Décideur : Marie Martin (HR Director)
```

---

### 3.3 Section 2 — Impact sur le Candidat Retenu

**Contenu :**
Analyse de l'impact de la décision sur le candidat retenu.

**Format :**
```
IMPACT SUR LE CANDIDAT RETENU :
  Court terme :
    [Analyse de l'impact à court terme]
  Long terme :
    [Analyse de l'impact à long terme]
  Risques pour lui :
    - [Risque 1]
    - [Risque 2]
    - [Risque 3]
  Bénéfices pour lui :
    - [Bénéfice 1]
    - [Bénéfice 2]
```

**Exemple :**
```
IMPACT SUR LE CANDIDAT RETENU :
  Court terme :
    Intégration dans une équipe en croissance
    Opportunité de leadership sur un produit innovant
    Salaire compétitif
  Long terme :
    Opportunité de croissance vers CTO
    Développement de compétences en scaling
    Réseau professionnel élargi
  Risques pour lui :
    - Pression liée à la croissance rapide
    - Incertitude sur l'évolution du poste
    - Charge de travail élevée
  Bénéfices pour lui :
    - Opportunité de carrière significative
    - Environnement stimulant
    - Participation à la croissance de l'entreprise
```

---

### 3.4 Section 3 — Impact sur les Candidats Refusés

**Contenu :**
Analyse de l'impact de la décision sur les candidats refusés.

**Format :**
```
IMPACT SUR LES CANDIDATS REFUSÉS :
  Traitement reçu :
    [Équitable / À améliorer]
    Justification : [explication]
  Feedback reçu :
    [Utile / Insuffisant / Absent]
    Contenu : [description]
  Dignité préservée :
    [Oui / Non / Partiellement]
    Justification : [explication]
  Risques pour eux :
    - [Risque 1]
    - [Risque 2]
```

**Exemple :**
```
IMPACT SUR LES CANDIDATS REFUSÉS :
  Traitement reçu :
    Équitable
    Justification : Processus standardisé, critères clairs
  Feedback reçu :
    Utile
    Contenu : Feedback détaillé sur les points forts et axes d'amélioration
  Dignité préservée :
    Oui
    Justification : Communication respectueuse et transparente
  Risques pour eux :
    - Frustration liée au refus
    - Perte de temps dans le processus
    - Impact sur la confiance en soi
```

---

### 3.5 Section 4 — Impact sur l'Équipe

**Contenu :**
Analyse de l'impact de la décision sur l'équipe qui accueille.

**Format :**
```
IMPACT SUR L'ÉQUIPE :
  Dynamique attendue :
    [Analyse de la dynamique attendue]
  Risques de friction :
    - [Risque 1]
    - [Risque 2]
  Opportunités :
    - [Opportunité 1]
    - [Opportunité 2]
  Besoins d'accompagnement :
    - [Besoin 1]
    - [Besoin 2]
```

**Exemple :**
```
IMPACT SUR L'ÉQUIPE :
  Dynamique attendue :
    Intégration d'un profil senior dans une équipe junior
    Apport de nouvelles perspectives
    Renforcement du leadership
  Risques de friction :
    - Résistance au changement de style de management
    - Différences de culture de travail
    - Tensions liées à la hiérarchie
  Opportunités :
    - Mentorat pour les membres juniors
    - Amélioration des processus
    - Enrichissement des compétences
  Besoins d'accompagnement :
    - Session de présentation du nouveau membre
    - Clarification des rôles et responsabilités
    - Suivi régulier de l'intégration
```

**Contenu :**
Analyse de l'impact de la décision sur la société dans son ensemble.

**Format :**
```
IMPACT SUR LA SOCIÉTÉ :
  Contribution à l'équité :
    [Analyse de la contribution à l'équité]

    [Analyse du risque de discrimination systémique]
  Contribution à la diversité :
    [Analyse de la contribution à la diversité]

**Exemple :**

    Candidat issu de la diversité (genre)

  Impact sur l'emploi :
    Création d'emploi qualifié
    Contribution à l'économie locale
```

---

### 3.8 Section 7 — Bilan Éthique Global

**Contenu :**
Synthèse de l'impact global de la décision et recommandations d'ajustement.

**Format :**
```
BILAN ÉTHIQUE GLOBAL :
  Cette décision est-elle juste pour toutes les parties prenantes ?
    [Oui / Non / Partiellement]
    Justification : [explication]
  
  Quelle partie prenante est lésée ?
    [Partie prenante]
    Niveau d'impact : [faible / moyen / élevé]
  
  Comment atténuer cet impact ?
    - [Action 1]
    - [Action 2]
    - [Action 3]
  
  Recommandation finale :
    [Recommandation]
    Justification : [explication]
```

**Exemple :**
```
BILAN ÉTHIQUE GLOBAL :
  Cette décision est-elle juste pour toutes les parties prenantes ?
    Partiellement
    Justification : La décision est globalement juste mais les candidats refusés pourraient bénéficier d'un feedback plus détaillé
  
  Quelle partie prenante est lésée ?
    Candidats refusés
    Niveau d'impact : faible
  
  Comment atténuer cet impact ?
    - Améliorer la qualité du feedback
    - Proposer des ressources de développement
    - Maintenir le contact pour de futures opportunités
  
  Recommandation finale :
    Confirmer la décision avec ajustements mineurs
    Justification : La décision est globalement juste et les ajustements proposés amélioreront l'expérience des candidats refusés
```

## 5. Algorithme d'Analyse Multi-Parties Prenantes

### 5.1 Processus Global

```typescript
async function analyzeStakeholders(decision: Decision): Promise<StakeholderAnalysis> {
  // 1. Analyse de l'impact sur le candidat retenu
  const impactOnHiredCandidate = await analyzeImpactOnHiredCandidate(decision);
  
  // 2. Analyse de l'impact sur les candidats refusés
  const impactOnRejectedCandidates = await analyzeImpactOnRejectedCandidates(decision);
  
  // 3. Analyse de l'impact sur l'équipe
  const impactOnTeam = await analyzeImpactOnTeam(decision);
  
  // 4. Analyse de l'impact sur l'entreprise
  const impactOnCompany = await analyzeImpactOnCompany(decision);
  
  // 5. Analyse de l'impact sur la société
  const impactOnSociety = await analyzeImpactOnSociety(decision);
  
  // 6. Bilan éthique global
  const globalEthicalBalance = await analyzeGlobalEthicalBalance(
    impactOnHiredCandidate,
    impactOnRejectedCandidates,
    impactOnTeam,
    impactOnCompany,
    impactOnSociety
  );
  
  // 7. Construction de l'analyse
  const analysis: StakeholderAnalysis = {
    analysisId: generateAnalysisId(),
    decisionId: decision.decisionId,
    analyzedAt: new Date(),
    decision: {
      description: decision.description,
      context: decision.context,
      date: decision.date,
      decisionMaker: decision.decisionMaker
    },
    impactOnHiredCandidate,
    impactOnRejectedCandidates,
    impactOnTeam,
    impactOnCompany,
    impactOnSociety,
    globalEthicalBalance,
    metadata: {
      createdBy: 'MVP-031 Ethical Compass Engine',
      version: '1.0'
    }
  };
  
  return analysis;
}
```

## 6. Stockage et Gestion

### 6.1 Schéma SQL

```sql
CREATE TABLE stakeholder_analysis (
  id VARCHAR(36) PRIMARY KEY,
  decision_id VARCHAR(36) NOT NULL,
  analyzed_at TIMESTAMP NOT NULL,
  
  decision JSON NOT NULL,
  impact_on_hired_candidate JSON NOT NULL,
  impact_on_rejected_candidates JSON NOT NULL,
  impact_on_team JSON NOT NULL,
  impact_on_company JSON NOT NULL,
  impact_on_society JSON NOT NULL,
  global_ethical_balance JSON NOT NULL,
  metadata JSON NOT NULL,
  
  FOREIGN KEY (decision_id) REFERENCES decision(id)
);

CREATE INDEX idx_stakeholder_analysis_decision ON stakeholder_analysis(decision_id);
CREATE INDEX idx_stakeholder_analysis_date ON stakeholder_analysis(analyzed_at);
```

## 9. Conclusion

Le format d'analyse multi-parties prenantes structure l'analyse de l'impact de chaque décision importante sur toutes les parties prenantes. Les 7 sections (décision considérée, impact sur le candidat retenu, impact sur les candidats refusés, impact sur l'équipe, impact sur l'entreprise, impact sur la société, bilan éthique global) permettent d'identifier les parties lésées, les risques potentiels, et les opportunités d'amélioration.

**Points clés :**
- 7 sections structurées
- 5 parties prenantes analysées
- Analyse court terme et long terme
- Identification des risques et bénéfices
- Bilan éthique global
- Recommandations d'atténuation
- Algorithme d'analyse structuré
- Stockage et gestion des analyses
- API endpoints pour la gestion
- Métriques de qualité et d'impact
