## 1. Objectif

Définir le Brief Entretien Expert pour MVP-013 Interview Intelligence. Ce brief généré automatiquement avant chaque entretien fournit au recruteur une préparation chirurgicale personnalisée pour le candidat et le poste.

---

## 2. Principe Fondateur

Le Brief Entretien Expert transforme un entretien amateur en entretien de niveau grand cabinet mondial. Il analyse le CV et le poste pour générer une préparation personnalisée avec des questions spécifiques, des hypothèses à vérifier, et des signaux à surveiller.

## 5. Génération du Brief Entretien

### 5.1 Processus de Génération

```typescript
async function generateInterviewBrief(candidateId: string, jobId: string, recruiterId: string): Promise<InterviewBrief> {
  // Étape 1 : Analyse du CV
  const cvAnalysis = await analyzeCV(candidateId);
  
  // Étape 2 : Analyse du poste
  const jobAnalysis = await analyzeJob(jobId);
  
  // Étape 3 : Génération du profil en 3 minutes
  const profileSummary = await generateProfileSummary(cvAnalysis, jobAnalysis);
  
  // Étape 4 : Génération des hypothèses à vérifier
  const hypothesesToVerify = await generateHypotheses(cvAnalysis, jobAnalysis);
  
  // Étape 5 : Détection des signaux positifs
  const positiveSignals = await detectPositiveSignals(cvAnalysis);
  
  // Étape 6 : Détection des signaux de vigilance
  const vigilanceSignals = await detectVigilanceSignals(cvAnalysis);
  
  // Étape 7 : Génération des 5 questions incontournables
  const mustAskQuestions = await generateMustAskQuestions(cvAnalysis, jobAnalysis);
  
  // Étape 8 : Génération des 3 questions de déstabilisation
  const destabilizationQuestions = await generateDestabilizationQuestions(cvAnalysis, jobAnalysis);
  
  // Étape 9 : Génération de la grille de cotation personnalisée
  const personalizedScoringGrid = await generatePersonalizedScoringGrid(jobAnalysis);
  
  // Construction du brief
  const brief: InterviewBrief = {
    briefId: generateBriefId(),
    candidateId,
    jobId,
    recruiterId,
    interviewDate: await getInterviewDate(candidateId, jobId),
    generatedAt: new Date(),
    
    profileSummary,
    hypothesesToVerify,
    positiveSignals,
    vigilanceSignals,
    mustAskQuestions,
    destabilizationQuestions,
    personalizedScoringGrid
  };
  
  // Sauvegarde du brief
  await saveBrief(brief);
  
  return brief;
}
```

### 5.2 Analyse du Profil

```typescript
async function generateProfileSummary(cvAnalysis: CVAnalysis, jobAnalysis: JobAnalysis): Promise<InterviewBrief['profileSummary']> {
  // Résumé du parcours en 5 lignes
  const summary = await generateSummary(cvAnalysis);
  
  // Détection du type de profil
  const profileType = await detectProfileType(cvAnalysis);
  
  // Détection du stade de carrière
  const careerStage = await detectCareerStage(cvAnalysis);
  
  // Calcul de la confiance
  const confidence = await calculateConfidence(cvAnalysis, jobAnalysis);
  
  return {
    summary,
    profileType,
    careerStage,
    confidence
  };
}

async function detectProfileType(cvAnalysis: CVAnalysis): Promise<InterviewBrief['profileSummary']['profileType']> {
  const signals = {
    specialist: cvAnalysis.skills.length > 10 && cvAnalysis.skills.length < 20,
    generalist: cvAnalysis.skills.length >= 20,
    manager: cvAnalysis.managementExperience.length > 2,
    technicalExpert: cvAnalysis.technicalSkills.length > 15,
    entrepreneur: cvAnalysis.entrepreneurialExperience.length > 0,
    executive: cvAnalysis.executiveExperience.length > 0
  };
  
  // Trouver le type dominant
  const dominantType = Object.entries(signals)
    .filter(([_, value]) => value)
    .sort((a, b) => b[1] - a[1])[0];
  
  return dominantType ? dominantType[0] as any : 'generalist';
}

async function detectCareerStage(cvAnalysis: CVAnalysis): Promise<InterviewBrief['profileSummary']['careerStage']> {
  const yearsOfExperience = cvAnalysis.yearsOfExperience;
  
  if (yearsOfExperience < 3) return 'junior';
  if (yearsOfExperience < 7) return 'intermediate';
  if (yearsOfExperience < 15) return 'confirmed';
  if (yearsOfExperience < 20) return 'senior';
  return 'expert';
}
```

### 5.3 Génération des Hypothèses

```typescript
async function generateHypotheses(cvAnalysis: CVAnalysis, jobAnalysis: JobAnalysis): Promise<InterviewBrief['hypothesesToVerify']> {
  const cvSaysButNeedsConfirmation: string[] = [];
  const cvDoesntSayAndNeedsDigging: string[] = [];
  const inconsistenciesOrBlindSpots: string[] = [];
  const gapsInCareerToExplain: string[] = [];
  
  // Ce que le CV dit mais à confirmer
  for (const skill of cvAnalysis.skills) {
    if (skill.level === 'claimed') {
      cvSaysButNeedsConfirmation.push(
        `Compétence ${skill.name} revendiquée mais non démontrée par l'expérience`
      );
    }
  }
  
  // Ce que le CV ne dit pas et à creuser
  const missingSkills = jobAnalysis.requiredSkills.filter(
    skill => !cvAnalysis.skills.some(cvSkill => cvSkill.name === skill.name)
  );
  
  for (const missingSkill of missingSkills) {
    cvDoesntSayAndNeedsDigging.push(
      `Compétence requise ${missingSkill.name} non mentionnée dans le CV`
    );
  }
  
  // Incohérences ou zones d'ombre
  if (cvAnalysis.hasInconsistencies) {
    for (const inconsistency of cvAnalysis.inconsistencies) {
      inconsistenciesOrBlindSpots.push(inconsistency.description);
    }
  }
  
  // Trous dans le parcours
  for (const gap of cvAnalysis.careerGaps) {
    gapsInCareerToExplain.push(
      `Période de ${gap.duration} mois sans activité (${gap.startDate} - ${gap.endDate})`
    );
  }
  
  return {
    cvSaysButNeedsConfirmation,
    cvDoesntSayAndNeedsDigging,
    inconsistenciesOrBlindSpots,
    gapsInCareerToExplain
  };
}
```

### 5.4 Détection des Signaux Positifs

```typescript
async function detectPositiveSignals(cvAnalysis: CVAnalysis): Promise<InterviewBrief['positiveSignals']> {
  const whatPleadesForCandidate: string[] = [];
  const potentialMarkers: string[] = [];
  const rapidLearningSignals: string[] = [];
  const leadershipOrInitiativeProofs: string[] = [];
  
  // Ce qui plaide pour ce candidat
  if (cvAnalysis.hasQuantifiableAchievements) {
    whatPleadesForCandidate.push(
      'Résultats chiffrés démontrés dans plusieurs expériences'
    );
  }
  
  if (cvAnalysis.hasCareerProgression) {
    whatPleadesForCandidate.push(
      'Progression de carrière cohérente et ascendante'
    );
  }
  
  // Marqueurs de potentiel
  if (cvAnalysis.hasDiverseExperience) {
    potentialMarkers.push(
      'Diversité des expériences indiquant une capacité d\'adaptation'
    );
  }
  
  if (cvAnalysis.hasInternationalExperience) {
    potentialMarkers.push(
      'Expérience internationale indiquant une ouverture d\'esprit'
    );
  }
  
  // Signaux d'apprentissage rapide
  if (cvAnalysis.hasSkillProgression) {
    rapidLearningSignals.push(
      'Progression rapide des compétences techniques'
    );
  }
  
  if (cvAnalysis.hasCertifications) {
    rapidLearningSignals.push(
      'Certifications obtenues indiquant une capacité d\'apprentissage'
    );
  }
  
  // Preuves de leadership ou d'initiative
  for (const experience of cvAnalysis.managementExperience) {
    if (experience.teamSize > 5) {
      leadershipOrInitiativeProofs.push(
        `Management d'équipe de ${experience.teamSize} personnes`
      );
    }
  }
  
  for (const initiative of cvAnalysis.initiatives) {
    leadershipOrInitiativeProofs.push(
      `Initiative : ${initiative.description}`
    );
  }
  
  return {
    whatPleadesForCandidate,
    potentialMarkers,
    rapidLearningSignals,
    leadershipOrInitiativeProofs
  };
}
```

### 5.5 Détection des Signaux de Vigilance

```typescript
async function detectVigilanceSignals(cvAnalysis: CVAnalysis): Promise<InterviewBrief['vigilanceSignals']> {
  const whatNeedsAttention: string[] = [];
  const riskPatterns = {
    excessiveMobility: false,
    prolongedStagnation: false,
    jobRegressions: false,
    fuzzyZones: false
  };
  const patternDetails: string[] = [];
  
  // Mobilité excessive
  if (cvAnalysis.jobChanges.length > 5 && cvAnalysis.yearsOfExperience < 10) {
    riskPatterns.excessiveMobility = true;
    patternDetails.push(
      `${cvAnalysis.jobChanges.length} changements de poste en ${cvAnalysis.yearsOfExperience} ans`
    );
    whatNeedsAttention.push(
      'Mobilité excessive pouvant indiquer un manque de stabilité'
    );
  }
  
  // Stagnation prolongée
  for (const experience of cvAnalysis.experiences) {
    if (experience.duration > 5 && !experience.hasProgression) {
      riskPatterns.prolongedStagnation = true;
      patternDetails.push(
        `Stagnation de ${experience.duration} ans chez ${experience.company}`
      );
      whatNeedsAttention.push(
        'Stagnation prolongée pouvant indiquer un manque d\'ambition'
      );
    }
  }
  
  // Régressions de poste
  for (const regression of cvAnalysis.jobRegressions) {
    riskPatterns.jobRegressions = true;
    patternDetails.push(
      `Régression de poste : ${regression.from} → ${regression.to} (${regression.date})`
    );
    whatNeedsAttention.push(
      'Régression de poste nécessitant une explication'
    );
  }
  
  // Zones de flou
  for (const fuzzyZone of cvAnalysis.fuzzyZones) {
    riskPatterns.fuzzyZones = true;
    patternDetails.push(
      `Zone de flou sur : ${fuzzyZone.description}`
    );
    whatNeedsAttention.push(
      'Zone de flou sur les responsabilités nécessitant clarification'
    );
  }
  
  return {
    whatNeedsAttention,
    riskPatterns,
    patternDetails
  };
}
```

### 5.6 Génération des Questions Incontournables

```typescript
async function generateMustAskQuestions(cvAnalysis: CVAnalysis, jobAnalysis: JobAnalysis): Promise<InterviewBrief['mustAskQuestions']> {
  const mustAskQuestions: InterviewBrief['mustAskQuestions'] = [];
  
  // Question 1 : Basée sur une compétence critique manquante
  const missingCriticalSkill = jobAnalysis.criticalSkills.find(
    skill => !cvAnalysis.skills.some(cvSkill => cvSkill.name === skill.name)
  );
  
  if (missingCriticalSkill) {
    mustAskQuestions.push({
      question: `Votre CV ne mentionne pas d'expérience avec ${missingCriticalSkill.name}. Comment avez-vous acquis cette compétence et pouvez-vous me donner un exemple concret de son utilisation ?`,
      objective: `Vérifier la compétence critique ${missingCriticalSkill.name}`,
      signalSought: 'Compétence réelle vs revendiquée',
      followUpIfEvasive: 'Pouvez-vous me donner un exemple précis d\'un projet où vous avez utilisé cette compétence ?'
    });
  }
  
  // Question 2 : Basée sur une incohérence détectée
  if (cvAnalysis.inconsistencies.length > 0) {
    const inconsistency = cvAnalysis.inconsistencies[0];
    mustAskQuestions.push({
      question: `J'ai noté une incohérence dans votre parcours : ${inconsistency.description}. Pouvez-vous m'expliquer ?`,
      objective: 'Clarifier l\'incohérence',
      signalSought: 'Honnêteté et cohérence',
      followUpIfEvasive: 'Pouvez-vous me donner plus de détails sur cette période ?'
    });
  }
  
  // Question 3 : Basée sur un trou dans le parcours
  if (cvAnalysis.careerGaps.length > 0) {
    const gap = cvAnalysis.careerGaps[0];
    mustAskQuestions.push({
      question: `Vous avez une période de ${gap.duration} mois sans activité entre ${gap.startDate} et ${gap.endDate}. Qu'avez-vous fait pendant cette période ?`,
      objective: 'Comprendre le trou dans le parcours',
      signalSought: 'Proactivité et résilience',
      followUpIfEvasive: 'Quelles compétences avez-vous développées pendant cette période ?'
    });
  }
  
  // Question 4 : Basée sur une compétence clé du poste
  const keySkill = jobAnalysis.keySkills[0];
  mustAskQuestions.push({
    question: `Ce poste nécessite une expertise forte en ${keySkill.name}. Pouvez-vous me décrire un projet complexe où vous avez utilisé cette compétence ?`,
    objective: `Évaluer l'expertise en ${keySkill.name}`,
    signalSought: 'Niveau d\'expertise réel',
    followUpIfEvasive: 'Quels défis avez-vous rencontrés et comment les avez-vous surmontés ?'
  });
  
  // Question 5 : Basée sur la motivation
  mustAskQuestions.push({
    question: `Pourquoi ce poste en particulier et pourquoi maintenant ?`,
    objective: 'Comprendre la motivation',
    signalSought: 'Motivation et alignement',
    followUpIfEvasive: 'Qu'est-ce qui vous attire dans cette entreprise ?'
  });
  
  return mustAskQuestions;
}
```

```typescript
async function generateDestabilizationQuestions(cvAnalysis: CVAnalysis, jobAnalysis: JobAnalysis): Promise<InterviewBrief['destabilizationQuestions']> {
  const destabilizationQuestions: InterviewBrief['destabilizationQuestions'] = [];
  
  // Question 1 : Basée sur un échec
  destabilizationQuestions.push({
    question: `Parlez-moi d'un échec professionnel majeur. Qu'avez-vous appris de cette expérience ?`,
    calibration: 'medium',
    objective: 'Tester la capacité à reconnaître ses échecs et à apprendre',
    followUpIfEvasive: 'Quelles mesures avez-vous prises pour éviter que cela ne se reproduise ?'
  });
  
  // Question 2 : Basée sur un conflit
  destabilizationQuestions.push({
    question: `Décrivez un conflit professionnel difficile que vous avez eu. Comment l'avez-vous géré ?`,
    calibration: 'medium',
    objective: 'Tester la gestion des conflits et l\'intelligence émotionnelle',
    followUpIfEvasive: 'Quelle aurait été une meilleure approche selon vous ?'
  });
  
  // Question 3 : Basée sur une critique
  destabilizationQuestions.push({
    question: `Si je contactais vos anciens collègues ou managers, quel serait le point négatif principal qu'ils mentionneraient sur vous ?`,
    calibration: 'high',
    objective: 'Tester la conscience de soi et l\'honnêteté',
    followUpIfEvasive: 'Comment travaillez-vous sur ce point ?'
  });
  
  return destabilizationQuestions;
}
```

### 5.8 Génération de la Grille de Cotation

```typescript
async function generatePersonalizedScoringGrid(jobAnalysis: JobAnalysis): Promise<InterviewBrief['personalizedScoringGrid']> {
  const criteria: InterviewBrief['personalizedScoringGrid']['criteria'] = [];
  
  // Critère 1 : Compétences techniques
  criteria.push({
    name: 'Compétences techniques',
    weight: jobAnalysis.technicalWeight,
    scale: '1-5 (1=Insuffisant, 5=Excellent)',
    decisionThreshold: 3
  });
  
  // Critère 2 : Expérience
  criteria.push({
    name: 'Expérience',
    weight: jobAnalysis.experienceWeight,
    scale: '1-5 (1=Insuffisant, 5=Excellent)',
    decisionThreshold: 3
  });
  
  // Critère 3 : Leadership
  if (jobAnalysis.requiresLeadership) {
    criteria.push({
      name: 'Leadership',
      weight: jobAnalysis.leadershipWeight,
      scale: '1-5 (1=Insuffisant, 5=Excellent)',
      decisionThreshold: 3
    });
  }
  
  // Critère 4 : Culture fit
  criteria.push({
    name: 'Culture fit',
    weight: jobAnalysis.cultureFitWeight,
    scale: '1-5 (1=Insuffisant, 5=Excellent)',
    decisionThreshold: 3
  });
  
  // Critère 5 : Communication
  criteria.push({
    name: 'Communication',
    weight: jobAnalysis.communicationWeight,
    scale: '1-5 (1=Insuffisant, 5=Excellent)',
    decisionThreshold: 3
  });
  
  // Formule du score global
  const formula = criteria.map(c => `${c.weight}% × ${c.name}`).join(' + ');
  
  return {
    criteria,
    globalScore: {
      formula,
      decisionThreshold: 3.5
    }
  };
}
```

## 9. Conclusion

Le Brief Entretien Expert transforme un entretien amateur en entretien de niveau grand cabinet mondial. Il fournit une préparation chirurgicale personnalisée avec des questions spécifiques, des hypothèses à vérifier, et des signaux à surveiller.

**Points clés :**
- Profil en 3 minutes (résumé, type, stade de carrière)
- Hypothèses à vérifier (CV dit, CV ne dit pas, incohérences, trous)
- Signaux positifs détectés (ce qui plaide, potentiel, apprentissage, leadership)
- Signaux de vigilance détectés (patterns à risque, mobilité, stagnation, régressions)
- 5 questions incontournables (spécifiques au candidat et au poste)
- 3 questions de déstabilisation ciblées (calibrées, pas agressives)
- Grille de cotation personnalisée (critères pondérés, échelle, seuils)
