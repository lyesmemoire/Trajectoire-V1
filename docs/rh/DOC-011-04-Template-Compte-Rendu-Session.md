## 1. Objectif

Définir le template de compte-rendu de session hebdomadaire pour les semaines 3-6 du programme beta MVP-011. Ce template standardise la collecte et la documentation du feedback des recruteurs.

## 4. Instructions de Remplissage

### 4.1 Pendant la Session

- Prendre des notes en temps réel
- Demander des clarifications si nécessaire
- Documenter les exemples concrets
- Noter les émotions et réactions du recruteur

### 4.2 Immédiatement Après la Session

- Compléter le template dans les 24 heures
- Envoyer le compte-rendu au beta pour validation
- Envoyer le compte-rendu à l'équipe produit
- Envoyer le compte-rendu à l'équipe technique si nécessaire

### 4.3 Validation par le Beta

- Le beta a 48 heures pour valider ou demander des révisions
- En cas de demande de révision, réviser dans les 24 heures
- Une fois validé, le compte-rendu est finalisé

## 5. Stockage et Gestion

### 5.1 Stockage

Les comptes-rendus sont stockés dans :

- **Google Drive** : Dossier partagé avec l'équipe
- **Notion** : Base de données structurée
- **Git** : Version control (format markdown)

### 5.2 Nom de Fichier

Format : `CR-BETA-[BETA-ID]-S[X]-[YYYY-MM-DD].md`

Exemple : `CR-BETA-BG001-S3-2026-10-15.md`

### 5.3 Schéma SQL (Optionnel)

```sql
CREATE TABLE weekly_session_reports (
  id VARCHAR(36) PRIMARY KEY,
  session_id VARCHAR(36) UNIQUE NOT NULL,
  beta_id VARCHAR(36) NOT NULL,
  week_number INT NOT NULL,
  session_date TIMESTAMP NOT NULL,
  
  checkin JSON NOT NULL,
  what_worked JSON NOT NULL,
  what_didnt_work JSON NOT NULL,
  whats_missing JSON NOT NULL,
  what_should_change JSON NOT NULL,
  action_plan JSON NOT NULL,
  overall_sentiment JSON NOT NULL,
  next_steps JSON NOT NULL,
  signature JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_session_beta ON weekly_session_reports(beta_id);
CREATE INDEX idx_session_week ON weekly_session_reports(week_number);
CREATE INDEX idx_session_date ON weekly_session_reports(session_date);
```
