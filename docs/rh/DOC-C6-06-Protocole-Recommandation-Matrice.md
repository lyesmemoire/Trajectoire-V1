## 1. Objectif

Définir le protocole de recommandation selon la matrice Potentiel / Maturité pour le Correctif 6 Maturity vs Potential. Ce document structure le processus de formulation de recommandations de recrutement basées sur la combinaison des scores de Maturité et de Potentiel.

---

## 2. Principe Fondateur

La recommandation de recrutement doit être formulée en combinant systématiquement les scores de Maturité (ce que le candidat sait faire MAINTENANT) et de Potentiel (ce que le candidat peut DEVENIR). Le protocole garantit que ces deux dimensions fondamentalement différentes ne sont jamais confondues.

---

## 3. Processus de Recommandation

### 3.1 Étape 1 — Calcul des Scores

**Action :**
Calculer le score de Maturité et le score de Potentiel.

**Maturité :**
- Évaluer les 4 critères (expériences, compétences, connaissances, réseau)
- Appliquer la pondération (30%, 30%, 20%, 20%)
- Calculer le score final (1-5)

**Potentiel :**
- Évaluer les 5 critères (apprentissage, réflexivité, curiosité, leadership, trajectoire)
- Appliquer la pondération (25%, 20%, 20%, 20%, 15%)
- Calculer le score final (1-5)

**Validation :**
- Vérifier la cohérence des scores
- Valider les justifications
- Consigner les observations

### 3.2 Étape 2 — Classification des Scores

**Action :**
Classer les scores selon les catégories de la matrice.

**Classification de la Maturité :**
- Si score ≥ 4 : Maturité Élevée
- Si score = 3 : Maturité Moyenne
- Si score ≤ 2 : Maturité Faible

**Classification du Potentiel :**
- Si score ≤ 2 : Potentiel Faible
- Si score = 3 : Potentiel Moyen
- Si score ≥ 4 : Potentiel Élevé

**Résultat :**
Combinaison (Maturité, Potentiel) → Cellule de la matrice

### 3.3 Étape 3 — Application de la Matrice

**Action :**
Appliquer la matrice de décision pour formuler la recommandation.

**9 combinaisons possibles :**
1. Maturité Élevée + Potentiel Faible
2. Maturité Élevée + Potentiel Moyen
3. Maturité Élevée + Potentiel Élevé
4. Maturité Moyenne + Potentiel Faible
5. Maturité Moyenne + Potentiel Moyen
6. Maturité Moyenne + Potentiel Élevé
7. Maturité Faible + Potentiel Faible
8. Maturité Faible + Potentiel Moyen
9. Maturité Faible + Potentiel Élevé

**Recommandation par cellule :**
Voir DOC-C6-03 pour les recommandations détaillées.

### 3.4 Étape 4 — Formulation de la Recommandation

**Action :**
Formuler la recommandation avec justification et détails.

**Structure de la recommandation :**
- Type de recommandation
- Action recommandée
- Justification
- Détails de mise en œuvre
- Adaptation par persona

### 3.5 Étape 5 — Validation de la Recommandation

**Action :**
Valider la recommandation avec le recruteur.

**Critères de validation :**
- Cohérence avec le contexte du poste
- Cohérence avec les besoins de l'entreprise
- Cohérence avec le budget
- Cohérence avec les contraintes temporelles

## 4. Recommandations Détaillées

### 4.1 Maturité Élevée + Potentiel Faible

**Type de recommandation :**
RECRUIT_FOR_THIS_POSITION

**Action :**
Recruter pour CE poste.

**Justification :**
Excellent pour les 3-5 prochaines années. Risque de plafonnement ensuite.

**Détails de mise en œuvre :**
- Recruter immédiatement pour le poste
- Anticiper la succession à 3-5 ans
- Prévoir un plan de transition
- Suivi régulier de l'évolution

**Adaptation par persona :**
- Senior : Recruter avec plan de succession
- Executive : Recruter avec anticipation de la transition
- Startup : Recruter avec suivi rapproché
- Technical : Recruter avec plan de montée en compétences

## 6. Adaptation par Persona

### 6.1 Persona Senior

**Approche :**
- Tolérance plus élevée pour la maturité moyenne
- Focus sur le potentiel pour les postes senior
- Recommandation plus flexible pour les candidats à fort potentiel

**Ajustements spécifiques :**
- Maturité Moyenne + Potentiel Élevé : Recruter avec plan de développement (pas forcément accéléré)
- Maturité Faible + Potentiel Élevé : Considérer pour le poste avec accompagnement renforcé

### 6.2 Persona Executive

**Approche :**
- Exigence élevée sur la maturité
- Tolérance minimale pour la maturité faible
- Focus sur le potentiel pour les rôles stratégiques

**Ajustements spécifiques :**
- Maturité Moyenne + Potentiel Faible : Ne pas recruter (exigence plus élevée)
- Maturité Faible + Potentiel Élevé : Ne pas recruter pour poste executive (exigence stricte)

### 6.3 Persona Startup

**Approche :**
- Tolérance pour la maturité faible si potentiel élevé
- Focus sur la capacité d'apprentissage
- Recommandation plus flexible pour les profils agiles

**Ajustements spécifiques :**
- Maturité Faible + Potentiel Élevé : Recruter avec plan de développement accéléré (tolérance pour l'agilité)
- Maturité Moyenne + Potentiel Faible : Recruter avec réserves (tolérance pour l'adaptabilité)

### 6.4 Persona Technical

**Approche :**
- Exigence élevée sur la maturité technique
- Tolérance pour la maturité faible si potentiel technique élevé
- Focus sur la capacité d'apprentissage technique

**Ajustements spécifiques :**
- Maturité Faible + Potentiel Élevé : Recruter avec plan de développement technique accéléré
- Maturité Moyenne + Potentiel Faible : Recruter avec réserves techniques

## 8. Stockage et Gestion

### 8.1 Schéma SQL

```sql
CREATE TABLE recommendation (
  id VARCHAR(36) PRIMARY KEY,
  candidate_id VARCHAR(36) NOT NULL,
  position_id VARCHAR(36) NOT NULL,
  interview_id VARCHAR(36) NOT NULL,
  
  recommended_at TIMESTAMP NOT NULL,
  
  scores JSON NOT NULL,
  matrix_cell JSON NOT NULL,
  recommendation JSON NOT NULL,
  persona VARCHAR(20) NOT NULL,
  validation JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_recommendation_candidate ON recommendation(candidate_id);
CREATE INDEX idx_recommendation_position ON recommendation(position_id);
CREATE INDEX idx_recommendation_interview ON recommendation(interview_id);

CREATE TABLE recommendation_protocol (
  id VARCHAR(36) PRIMARY KEY,
  
  process JSON NOT NULL,
  detailed_recommendations JSON NOT NULL,
  communication JSON NOT NULL,
  persona_adaptation JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 11. Conclusion

Le protocole de recommandation selon la matrice structure le processus de formulation de recommandations de recrutement en 5 étapes : calcul des scores (Maturité et Potentiel), classification des scores, application de la matrice, formulation de la recommandation, validation de la recommandation. 9 recommandations détaillées correspondant aux 9 cellules de la matrice, avec justification, détails de mise en œuvre, et adaptation par persona. Communication structurée avec rapport écrit et présentation orale optionnelle. Adaptation par persona (Senior : tolérance pour maturité moyenne, Executive : exigence élevée sur maturité, Startup : tolérance pour maturité faible si potentiel élevé, Technical : exigence sur maturité technique). Structure de données TypeScript, stockage SQL, API endpoints pour la gestion.

**Points clés :**
- Processus en 5 étapes
- 9 recommandations détaillées
- Communication structurée
- Adaptation par persona
- Validation de la recommandation
- Structure de données TypeScript
- Stockage et gestion SQL
- API endpoints pour la gestion
- Métriques de distribution et de qualité
