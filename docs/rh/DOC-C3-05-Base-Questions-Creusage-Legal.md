# DOC-C3-05 : Base de Questions de Creusage Légal (50 Questions)

**Version:** 1.0  
**Date:** 2026-08-04  
**Statut:** Draft  
**Auteur:** Trajectoire Team

---

## 1. Objectif

Définir la base de 50 questions de creusage légal pour le Correctif 3 Legal Knowledge Validation. Ce document structure les questions de creusage par domaine légal et cas type, avec les éléments ciblés et les critères d'évaluation des réponses.

---

## 2. Principe Fondateur

Lorsqu'une lacune critique est détectée, le moteur pose une question de creusage ciblée pour vérifier si le candidat connaît réellement l'élément manquant. Les 50 questions de creusage sont organisées par domaine légal et cas type, avec des variantes selon le niveau de responsabilité.

## 8. Algorithme de Sélection des Questions

### 8.1 Sélection par Élément Manquant

**Règle :**
- Sélectionner la question correspondant à l'élément critique manquant
- Si plusieurs éléments critiques manquants, prioriser le plus critique

### 8.2 Sélection par Niveau de Responsabilité

**Niveau Junior :**
- Questions formulées de manière plus simple
- Focus sur les éléments de base

**Niveau Senior :**
- Questions standard
- Focus sur tous les éléments

**Niveau Executive :**
- Questions plus complexes
- Focus sur les éléments critiques et les implications

### 8.3 Sélection par Domaine

**Priorité :**
- Domaine 1 (contrats) : priorité haute pour DRH
- Domaine 2 (collectif) : priorité haute pour DRH
- Domaine 3 (temps) : priorité moyenne
- Domaine 4 (formation) : priorité moyenne
- Domaine 5 (santé) : priorité haute

## 10. Stockage et Gestion

### 10.1 Schéma SQL

```sql
CREATE TABLE legal_drilling_question (
  id VARCHAR(36) PRIMARY KEY,
  
  domain VARCHAR(50) NOT NULL,
  case_type VARCHAR(50) NOT NULL,
  
  question TEXT NOT NULL,
  
  targeted_element JSON NOT NULL,
  evaluation_criteria JSON NOT NULL,
  level_variants JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_legal_drilling_domain ON legal_drilling_question(domain);
CREATE INDEX idx_legal_drilling_case_type ON legal_drilling_question(case_type);

CREATE TABLE legal_drilling_question_library (
  id VARCHAR(36) PRIMARY KEY,
  
  domain1 JSON NOT NULL,
  domain2 JSON NOT NULL,
  domain3 JSON NOT NULL,
  domain4 JSON NOT NULL,
  domain5 JSON NOT NULL,
  selection_algorithm JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```

## 13. Conclusion

La base de 50 questions de creusage légal couvre les 5 domaines du niveau DRH. Domaine 1 (contrats et relations individuelles) : 15 questions (licenciement salarié protégé, rupture conventionnelle, modification substantielle, inaptitude, autres). Domaine 2 (relations collectives) : 10 questions (PSE, élection CSE, grève, négociation d'accord). Domaine 3 (temps de travail et rémunération) : 10 questions (heures supplémentaires, forfait jours, égalité salariale, participation). Domaine 4 (formation et développement) : 5 questions (CPF, plan de formation, Pro-A). Domaine 5 (santé et sécurité) : 10 questions (harcèlement, accident du travail, document unique, maladie professionnelle, obligation générale de sécurité). Chaque question cible un élément spécifique avec des critères d'évaluation (correct, partiel, incorrect). Des variantes existent selon le niveau (junior, senior, executive). L'algorithme de sélection priorise les éléments critiques manquants et adapte selon le niveau et le domaine.
