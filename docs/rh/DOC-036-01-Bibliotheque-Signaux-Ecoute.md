## 1. Objectif

Définir la bibliothèque de signaux d'écoute pour MVP-036 Active Listening Engine. Cette bibliothèque contient 100 formulations verbales que le moteur envoie en temps réel pendant que le candidat parle pour créer la sensation d'être vraiment entendu, distinguant un entretien d'un interrogatoire.

---

## 2. Principe Fondateur

La différence la plus perceptible entre un humain et une machine dans un entretien est l'écoute active. L'humain hoche la tête, dit "je vois" ou "intéressant", reformule ce qui vient d'être dit, et se souvient de ce qui a été dit il y a 20 minutes. Le moteur doit reproduire ces signaux d'écoute espacés naturellement : ni trop fréquents (robotique), ni absents (machine froide).

## 7. Règle d'Or

**Espacement naturel :**
- Ces signaux sont espacés naturellement
- Pas trop fréquents (robotique)
- Pas absents (machine froide)
- Calibrés comme un humain attentif

**Fréquence recommandée :**
- 1 signal tous les 15-30 secondes de parole du candidat
- Variable selon la longueur et la complexité de la réponse
- Plus fréquent pour les réponses longues (1 tous les 15 secondes)
- Moins fréquent pour les réponses courtes (1 tous les 30 secondes)

**Timing recommandé :**
- Insérer le signal pendant une pause naturelle du candidat
- Ne pas interrompre le candidat
- Ne pas couper le candidat
- Attendre une pause naturelle

## 11. Stockage et Gestion

### 11.1 Schéma SQL

```sql
CREATE TABLE listening_signal (
  id VARCHAR(36) PRIMARY KEY,
  category VARCHAR(50) NOT NULL,
  
  text TEXT NOT NULL,
  context TEXT NOT NULL,
  
  persona JSON,
  response_length VARCHAR(20),
  frequency VARCHAR(20),
  
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_listening_signal_category ON listening_signal(category);
CREATE INDEX idx_listening_signal_persona ON listening_signal((persona->>'$.persona'));
CREATE INDEX idx_listening_signal_length ON listening_signal(response_length);

CREATE TABLE listening_signal_library (
  id VARCHAR(36) PRIMARY KEY,
  
  categories JSON NOT NULL,
  golden_rule JSON NOT NULL,
  context_adaptation JSON NOT NULL,
  persona_adaptation JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
