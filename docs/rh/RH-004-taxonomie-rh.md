# RH-004 — Taxonomie RH

## Identité

RH-004 EST LE DOCUMENT DE TAXONOMIE RH.

RH-004 EST LA SOURCE OFFICIELLE DE CLASSIFICATION RH.

RH-004 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LA TAXONOMIE RH.

RH-004 EST LA RÉFÉRENCE NORMATIVE POUR TOUTE CLASSIFICATION RH.

## Principes de la taxonomie

### Classification

LA TAXONOMIE RH EST UN SYSTÈME DE CLASSIFICATION.

LES ÉLÉMENTS RH SONT CLASSÉS PAR CATÉGORIES.

LES ÉLÉMENTS RH SONT CLASSÉS PAR SOUS-CATÉGORIES.

LES ÉLÉMENTS RH SONT CLASSÉS PAR NIVEAUX.

LA CLASSIFICATION EST DOCUMENTÉE.

LA CLASSIFICATION EST TRAÇABLE.

### Hiérarchie

LA TAXONOMIE RH EST HIÉRARCHIQUE.

LES CATÉGORIES RH SONT ORGANISÉES EN NIVEAUX.

LES SOUS-CATÉGORIES RH SONT RATTACHÉES AUX CATÉGORIES.

LA HIÉRARCHIE EST DOCUMENTÉE.

LA HIÉRARCHIE EST TRAÇABLE.

### Exhaustivité

LA TAXONOMIE RH EST EXHAUSTIVE.

TOUS LES ÉLÉMENTS RH SONT CLASSÉS.

AUCUN ÉLÉMENT RH N'EST SANS CLASSIFICATION.

L'EXHAUSTIVITÉ EST GARANTIE PAR LE SYSTÈME.

### Exclusivité

LA TAXONOMIE RH EST EXCLUSIVE.

CHAQUE ÉLÉMENT RH APPARTIENT À UNE SEULE CATÉGORIE PRINCIPALE.

CHAQUE ÉLÉMENT RH PEUT APPARTENIR À PLUSIEURS SOUS-CATÉGORIES.

L'EXCLUSIVITÉ EST GARANTIE PAR LE SYSTÈME.
