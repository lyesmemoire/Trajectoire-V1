## 1. Objectif

Définir le template de briefing automatique par type d'intervenant pour le MVP-META-06 Collaborative Decision Engine. Ce document structure le briefing généré automatiquement pour chaque intervenant avant l'entretien.

---

## 2. Principe Fondateur

Chaque intervenant reçoit un briefing personnalisé qui précise ce qu'il doit évaluer, ce que les autres évaluent, ses questions spécifiques, les signaux à surveiller, et ses critères de décision.

---

## 3. Template pour Intervenant RH

### 3.1 En-tête

```markdown
# BRIEFING — INTERVENANT RH

Candidat : [Nom]
Poste : [Intitulé]
Date de l'entretien : [Date]
```

### 3.2 Ce que vous évaluez

- Culture fit
- Soft skills
- Motivations
- Conformité légale

### 3.3 Ce que les autres évaluent

- Manager direct : Compétences métier, Adéquation équipe, Style de travail
- Expert technique : Profondeur technique, Connaissances spécifiques
- Direction : Vision, Leadership, Potentiel long terme, Représentation externe

### 3.4 Vos 3 questions spécifiques

1. Quelles valeurs de l'entreprise rejoignent le plus vos convictions personnelles ?
2. Comment décririez-vous votre style de travail en équipe ?
3. Qu'est-ce qui vous motive dans ce poste spécifique ?

### 3.5 Signaux à surveiller

- **Culture fit positif :** Alignement avec les valeurs, enthousiasme pour la culture
- **Culture fit négatif :** Désaccord avec les valeurs, réticence culturelle
- **Soft skills positif :** Communication claire, écoute active, empathie
- **Soft skills négatif :** Communication confuse, manque d'écoute, égocentrisme
- **Motivations positives :** Intérêt pour l'entreprise, projet de carrière cohérent
- **Motivations négatives :** Intérêt uniquement salarial, projet de carrière flou

### 3.6 Critères de décision pour vous

- **Score de culture fit :** 0-5 (≥ 4 recommandé)
- **Score de soft skills :** 0-5 (≥ 4 recommandé)
- **Score de motivations :** 0-5 (≥ 4 recommandé)
- **Conformité légale :** Oui/Non (Oui requis)

## 8. Stockage et Gestion

### 8.1 Schéma SQL

```sql
CREATE TABLE briefing_template (
  id VARCHAR(36) PRIMARY KEY,
  role VARCHAR(20) NOT NULL,
  
  evaluates JSON NOT NULL,
  others_evaluate JSON NOT NULL,
  specific_questions JSON NOT NULL,
  signals_to_watch JSON NOT NULL,
  decision_criteria JSON NOT NULL,
  
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_briefing_template_role ON briefing_template(role);

CREATE TABLE intervenant_briefing (
  id VARCHAR(36) PRIMARY KEY,
  recruitment_id VARCHAR(36) NOT NULL,
  candidate_id VARCHAR(36) NOT NULL,
  
  intervenant_id VARCHAR(36) NOT NULL,
  intervenant_role VARCHAR(20) NOT NULL,
  
  candidate_name VARCHAR(100) NOT NULL,
  position_title VARCHAR(100) NOT NULL,
  interview_date TIMESTAMP NOT NULL,
  
  evaluates JSON NOT NULL,
  others_evaluate JSON NOT NULL,
  specific_questions JSON NOT NULL,
  signals_to_watch JSON NOT NULL,
  decision_criteria JSON NOT NULL,
  
  generated_at TIMESTAMP NOT NULL,
  
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_intervenant_briefing_recruitment ON intervenant_briefing(recruitment_id);
CREATE INDEX idx_intervenant_briefing_candidate ON intervenant_briefing(candidate_id);
CREATE INDEX idx_intervenant_briefing_intervenant ON intervenant_briefing(intervenant_id);
```
