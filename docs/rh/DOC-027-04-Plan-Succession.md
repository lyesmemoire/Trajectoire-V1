## 1. Objectif

Définir le système de plan de succession pour MVP-027 Internal Mobility & Succession Planning. Ce système génère un plan de succession pour chaque poste clé (successeurs identifiés N+1/N+2, niveau de préparation de chaque successeur, plan de développement pour chaque successeur, délai avant succession possible, risque si le titulaire part demain).

---

## 2. Principe Fondateur

Pour chaque poste clé, le système identifie les successeurs potentiels (N+1 / N+2), évalue le niveau de préparation de chaque successeur, génère un plan de développement pour chaque successeur, estime le délai avant succession possible, et évalue le risque si le titulaire part demain. Le système permet à l'entreprise de préparer la succession pour les postes critiques et de minimiser l'impact en cas de départ inattendu.

---

## 3. Identification des Successeurs

### 3.1 Successeurs N+1

**Description :**
Successeurs directs (rapports directs du titulaire).

**Critères de sélection :**
- Performance ≥ 7/10
- Potentiel ≥ 7/10
- Compétences alignées avec le poste
- Aspirations de carrière alignées avec le poste
- Disponibilité pour la mobilité

**Types de successeurs :**
- Successeur principal
- Successeur secondaire
- Successeur de secours

---

### 3.2 Successeurs N+2

**Description :**
Successeurs indirects (rapports directs des rapports directs du titulaire).

**Critères de sélection :**
- Performance ≥ 6/10
- Potentiel ≥ 7/10
- Compétences partiellement alignées avec le poste
- Aspirations de carrière alignées avec le poste
- Disponibilité pour la mobilité

**Types de successeurs :**
- Successeur potentiel
- Successeur en développement
- Successeur à long terme

---

## 4. Niveau de Préparation des Successeurs

### 4.1 Prêt (Ready)

**Description :**
Successeur prêt à prendre le poste immédiatement.

**Critères :**
- Compétences complètes pour le poste
- Performance ≥ 8/10
- Potentiel ≥ 8/10
- Expérience similaire
- Disponibilité immédiate

**Actions :**
- Préparation de la transition
- Communication avec le successeur
- Plan de transition détaillé
- Support pendant la transition

---

### 4.2 Besoin de Développement (Needs Development)

**Description :**
Successeur qui a besoin de développement avant de prendre le poste.

**Critères :**
- Compétences partiellement alignées avec le poste
- Performance ≥ 7/10
- Potentiel ≥ 7/10
- Expérience limitée
- Disponibilité différée

**Actions :**
- Plan de développement ciblé
- Formation pour combler les écarts
- Mentoring par le titulaire
- Projets spéciaux pour développer l'expérience
- Suivi régulier de la progression

---

### 4.3 Pas Prêt (Not Ready)

**Description :**
Successeur qui n'est pas prêt à prendre le poste.

**Critères :**
- Compétences non alignées avec le poste
- Performance ≤ 6/10
- Potentiel ≤ 6/10
- Expérience insuffisante
- Disponibilité limitée

**Actions :**
- Plan de développement à long terme
- Formation significative
- Réorientation vers un autre poste
- Réévaluation régulière
- Identification d'autres successeurs

## 7. Risque si le Titulaire Part Demain

### 7.1 Faible (Low)

**Description :**
Risque faible si le titulaire part demain.

**Critères :**
- Successeur principal prêt
- Successeur secondaire prêt
- Plan de transition en place
- Impact minimal sur l'organisation

**Actions :**
- Maintenir le plan de succession
- Suivi régulier de la préparation
- Communication avec les successeurs

---

### 7.2 Moyen (Medium)

**Description :**
Risque moyen si le titulaire part demain.

**Critères :**
- Successeur principal besoin de développement
- Successeur secondaire prêt
- Plan de transition partiel
- Impact modéré sur l'organisation

**Actions :**
- Accélérer le développement du successeur principal
- Préparer le successeur secondaire
- Plan de transition d'urgence

---

### 7.3 Élevé (High)

**Description :**
Risque élevé si le titulaire part demain.

**Critères :**
- Successeur principal pas prêt
- Successeur secondaire pas prêt
- Plan de transition inexistant
- Impact significatif sur l'organisation

**Actions :**
- Identifier des successeurs d'urgence
- Plan de transition d'urgence
- Recrutement externe si nécessaire
- Communication avec les parties prenantes

---

### 7.4 Critique (Critical)

**Description :**
Risque critique si le titulaire part demain.

**Critères :**
- Aucun successeur identifié
- Plan de succession inexistant
- Impact critique sur l'organisation
- Risque opérationnel élevé

**Actions :**
- Identification immédiate de successeurs
- Plan de succession d'urgence
- Recrutement externe immédiat
- Communication avec la direction

## 8. Algorithme de Génération du Plan de Succession

### 8.1 Processus Global

```typescript
async function generateSuccessionPlan(jobId: string): Promise<SuccessionPlan> {
  // 1. Récupération du poste
  const job = await getJob(jobId);
  
  // 2. Récupération du titulaire actuel
  const incumbent = await getIncumbent(jobId);
  
  // 3. Identification des successeurs potentiels N+1
  const n1Successors = await identifyN1Successors(job, incumbent);
  
  // 4. Identification des successeurs potentiels N+2
  const n2Successors = await identifyN2Successors(job, incumbent);
  
  // 5. Évaluation du niveau de préparation de chaque successeur
  const evaluatedSuccessors = await Promise.all(
    [...n1Successors, ...n2Successors].map(successor => evaluateSuccessorReadiness(successor, job))
  );
  
  // 6. Génération du plan de développement pour chaque successeur
  const successorsWithDevelopmentPlan = await Promise.all(
    evaluatedSuccessors.map(successor => generateDevelopmentPlan(successor, job))
  );
  
  // 7. Estimation du délai avant succession possible
  const successorsWithTimeToSuccession = await Promise.all(
    successorsWithDevelopmentPlan.map(successor => estimateTimeToSuccession(successor))
  );
  
  // 8. Évaluation du risque si le titulaire part demain
  const riskIfDepartureTomorrow = await evaluateRiskIfDepartureTomorrow(successorsWithTimeToSuccession);
  
  // 9. Construction du plan de succession
  const successionPlan: SuccessionPlan = {
    successionId: generateSuccessionId(),
    jobId,
    analyzedAt: new Date(),
    
    successors: successorsWithTimeToSuccession,
    
    riskIfDepartureTomorrow
  };
  
  // 10. Sauvegarde du plan de succession
  await saveSuccessionPlan(successionPlan);
  
  return successionPlan;
}
```

### 8.2 Identification des Successeurs N+1

```typescript
async function identifyN1Successors(job: Job, incumbent: Employee): Promise<Employee[]> {
  // Récupération des rapports directs du titulaire
  const directReports = await getDirectReports(incumbent.employeeId);
  
  // Filtrage des candidats potentiels
  const potentialSuccessors = directReports.filter(employee => {
    return employee.performance >= 7 && 
           employee.potential >= 7 && 
           employee.mobilityAvailability;
  });
  
  // Classement par score de matching
  const rankedSuccessors = await Promise.all(
    potentialSuccessors.map(employee => calculateMatchingScore(employee, job))
  );
  
  return rankedSuccessors.sort((a, b) => b.matchingScore - a.matchingScore);
}
```

### 8.4 Évaluation du Niveau de Préparation

```typescript
async function evaluateSuccessorReadiness(successor: Employee, job: Job): Promise<{
  employeeId: string;
  employeeName: string;
  currentRole: string;
  
  level: 'N+1' | 'N+2';
  readinessLevel: 'ready' | 'needs_development' | 'not_ready';
}> {
  // Évaluation des compétences
  const skillAlignment = await evaluateSkillAlignment(successor, job);
  
  // Évaluation de la performance
  const performanceScore = successor.performance;
  
  // Évaluation du potentiel
  const potentialScore = successor.potential;
  
  // Détermination du niveau de préparation
  let readinessLevel: 'ready' | 'needs_development' | 'not_ready';
  
  if (skillAlignment >= 0.8 && performanceScore >= 8 && potentialScore >= 8) {
    readinessLevel = 'ready';
  } else if (skillAlignment >= 0.6 && performanceScore >= 7 && potentialScore >= 7) {
    readinessLevel = 'needs_development';
  } else {
    readinessLevel = 'not_ready';
  }
  
  return {
    employeeId: successor.employeeId,
    employeeName: successor.name,
    currentRole: successor.currentRole,
    
    level: successor.level,
    readinessLevel
  };
}
```

### 8.5 Génération du Plan de Développement

```typescript
async function generateDevelopmentPlan(successor: any, job: Job): Promise<{
  employeeId: string;
  employeeName: string;
  currentRole: string;
  
  level: 'N+1' | 'N+2';
  readinessLevel: 'ready' | 'needs_development' | 'not_ready';
  developmentPlan: string[];
}> {
  const developmentPlan: string[] = [];
  
  // Si le successeur a besoin de développement
  if (successor.readinessLevel === 'needs_development' || successor.readinessLevel === 'not_ready') {
    // Évaluation des écarts de compétences
    const skillGaps = await evaluateSkillGaps(successor, job);
    
    // Génération d'actions de développement
    for (const skillGap of skillGaps) {
      const action = await generateDevelopmentAction(skillGap);
      developmentPlan.push(action);
    }
    
    // Ajout de mentoring
    developmentPlan.push('Mentoring par le titulaire');
    
    // Ajout de projets spéciaux
    developmentPlan.push('Projets spéciaux pour développer l\'expérience');
  }
  
  return {
    employeeId: successor.employeeId,
    employeeName: successor.employeeName,
    currentRole: successor.currentRole,
    
    level: successor.level,
    readinessLevel: successor.readinessLevel,
    developmentPlan
  };
}
```

### 8.6 Estimation du Délai avant Succession

```typescript
async function estimateTimeToSuccession(successor: any): Promise<{
  employeeId: string;
  employeeName: string;
  currentRole: string;
  
  level: 'N+1' | 'N+2';
  readinessLevel: 'ready' | 'needs_development' | 'not_ready';
  developmentPlan: string[];
  estimatedTimeToSuccession: string;
}> {
  let estimatedTimeToSuccession: string;
  
  // Selon le niveau de préparation
  switch (successor.readinessLevel) {
    case 'ready':
      estimatedTimeToSuccession = '0-3 mois';
      break;
    case 'needs_development':
      estimatedTimeToSuccession = '3-6 mois';
      break;
    case 'not_ready':
      estimatedTimeToSuccession = '> 12 mois';
      break;
  }
  
  return {
    employeeId: successor.employeeId,
    employeeName: successor.employeeName,
    currentRole: successor.currentRole,
    
    level: successor.level,
    readinessLevel: successor.readinessLevel,
    developmentPlan: successor.developmentPlan,
    estimatedTimeToSuccession
  };
}
```

### 8.7 Évaluation du Risque si le Titulaire Part Demain

```typescript
async function evaluateRiskIfDepartureTomorrow(successors: any[]): Promise<'low' | 'medium' | 'high' | 'critical'> {
  // Recherche d'un successeur prêt
  const readySuccessor = successors.find(s => s.readinessLevel === 'ready');
  
  // Si un successeur est prêt
  if (readySuccessor) {
    return 'low';
  }
  
  // Recherche d'un successeur besoin de développement
  const needsDevelopmentSuccessor = successors.find(s => s.readinessLevel === 'needs_development');
  
  // Si un successeur a besoin de développement
  if (needsDevelopmentSuccessor) {
    return 'medium';
  }
  
  // Recherche d'un successeur pas prêt
  const notReadySuccessor = successors.find(s => s.readinessLevel === 'not_ready');
  
  // Si un successeur n'est pas prêt
  if (notReadySuccessor) {
    return 'high';
  }
  
  // Si aucun successeur
  return 'critical';
}
```

## 10. Stockage et Gestion

### 10.1 Schéma SQL

```sql
CREATE TABLE succession_plan (
  id VARCHAR(36) PRIMARY KEY,
  job_id VARCHAR(36) NOT NULL,
  analyzed_at TIMESTAMP NOT NULL,
  
  successors JSON NOT NULL,
  overall_risk_if_departure_tomorrow VARCHAR(20) NOT NULL CHECK (overall_risk_if_departure_tomorrow IN ('low', 'medium', 'high', 'critical')),
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  
  FOREIGN KEY (job_id) REFERENCES jobs(id)
);

CREATE INDEX idx_succession_plan_job ON succession_plan(job_id);
CREATE INDEX idx_succession_plan_date ON succession_plan(analyzed_at);
CREATE INDEX idx_succession_plan_risk ON succession_plan(overall_risk_if_departure_tomorrow);
```
