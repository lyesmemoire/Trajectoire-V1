## 1. Objectif

Définir le score de Maturité pour le poste (ce que le candidat sait faire MAINTENANT) pour le Correctif 6 Maturity vs Potential. Ce document structure la définition de la maturité, les critères évalués, et l'échelle de 5 niveaux.

---

## 2. Principe Fondateur

La maturité pour le poste mesure la capacité immédiate du candidat à exercer les responsabilités du poste sans période d'apprentissage majeure. Un candidat à fort potentiel mais faible maturité pour CE poste est une mauvaise recommandation aujourd'hui.

---

## 3. Définition de la Maturité

**Définition :**
Capacité immédiate à exercer les responsabilités du poste sans période d'apprentissage majeure.

**Distinction fondamentale :**
- Maturité : Ce que le candidat sait faire MAINTENANT
- Potentiel : Ce que le candidat peut DEVENIR

**Importance :**
Un candidat à fort potentiel mais faible maturité pour CE poste est une mauvaise recommandation aujourd'hui. Il peut être un excellent investissement futur, mais pas un recrutement immédiat.

---

## 4. Critères Évalués

### 4.1 Expériences Directement Transférables

**Question clé :**
A-t-il déjà fait exactement ça ?

**Sous-critères :**
- A-t-il déjà exercé des responsabilités similaires ?
- Dans un contexte comparable (taille, secteur, complexité) ?
- Avec des résultats mesurables ?
- Avec une autonomie comparable ?

**Évaluation :**
- Expérience identique : score maximal
- Expérience proche : score élevé
- Expérience partielle : score moyen
- Expérience éloignée : score faible
- Aucune expérience : score minimal

### 4.2 Compétences Immédiatement Opérationnelles

**Question clé :**
Peut-il prendre ce poste demain et être efficace dans les 30 premiers jours ?

**Sous-critères :**
- Compétences techniques maîtrisées
- Compétences relationnelles opérationnelles
- Capacité à prendre des décisions
- Capacité à gérer les urgences

**Évaluation :**
- Toutes compétences opérationnelles : score maximal
- Compétences majeures opérationnelles : score élevé
- Compétences partiellement opérationnelles : score moyen
- Compétences limitées : score faible
- Compétences non opérationnelles : score minimal

### 4.3 Connaissances Spécifiques au Poste

**Question clé :**
Maîtrise des outils, processus, cadre légal nécessaires maintenant.

**Sous-critères :**
- Outils métier maîtrisés
- Processus connus
- Cadre légal maîtrisé
- Culture d'entreprise comprise

**Évaluation :**
- Toutes connaissances maîtrisées : score maximal
- Connaissances majeures maîtrisées : score élevé
- Connaissances partiellement maîtrisées : score moyen
- Connaissances limitées : score faible
- Connaissances non maîtrisées : score minimal

### 4.4 Réseau et Positionnement

**Question clé :**
A-t-il les relations nécessaires pour être crédible dans ce rôle ?

**Sous-critères :**
- Réseau professionnel pertinent
- Positionnement dans l'écosystème
- Crédibilité auprès des parties prenantes
- Capacité à mobiliser des ressources

**Évaluation :**
- Réseau complet et pertinent : score maximal
- Réseau partiel mais pertinent : score élevé
- Réseau limité : score moyen
- Réseau très limité : score faible
- Aucun réseau pertinent : score minimal

## 5. Échelle de Maturité (5 Niveaux)

### 5.1 Niveau 5/5 — Maturité Immédiate

**Description :**
Peut exercer immédiatement sans période d'apprentissage.

**Critères :**
- Expériences directement transférables : identiques
- Compétences immédiatement opérationnelles : toutes
- Connaissances spécifiques : toutes maîtrisées
- Réseau et positionnement : complet et pertinent

**Horizon d'autonomie :**
- Immédiat (0 jour)

**Recommandation :**
- Recruter immédiatement pour le poste
- Pas de période d'intégration majeure
- Peut être opérationnel dès le premier jour

### 5.2 Niveau 4/5 — Maturité Élevée

**Description :**
Peut exercer avec quelques semaines d'adaptation.

**Critères :**
- Expériences directement transférables : proches
- Compétences immédiatement opérationnelles : majeures
- Connaissances spécifiques : majeures maîtrisées
- Réseau et positionnement : partiel mais pertinent

**Horizon d'autonomie :**
- 2 à 4 semaines

**Recommandation :**
- Recruter pour le poste
- Période d'intégration courte (2-4 semaines)
- Autonomie rapide

### 5.3 Niveau 3/5 — Maturité Moyenne

**Description :**
Peut exercer avec 3 mois d'accompagnement.

**Critères :**
- Expériences directement transférables : partielles
- Compétences immédiatement opérationnelles : partielles
- Connaissances spécifiques : partiellement maîtrisées
- Réseau et positionnement : limité

**Horizon d'autonomie :**
- 3 mois

**Recommandation :**
- Recruter avec plan de développement
- Période d'intégration moyenne (3 mois)
- Accompagnement nécessaire

### 5.4 Niveau 2/5 — Maturité Faible

**Description :**
Peut exercer avec 6-12 mois de montée en compétence.

**Critères :**
- Expériences directement transférables : éloignées
- Compétences immédiatement opérationnelles : limitées
- Connaissances spécifiques : limitées
- Réseau et positionnement : très limité

**Horizon d'autonomie :**
- 6 à 12 mois

**Recommandation :**
- Recruter avec réserves
- Plan de développement intensif
- Période d'intégration longue (6-12 mois)

### 5.5 Niveau 1/5 — Maturité Insuffisante

**Description :**
Pas encore prêt pour ce poste. Horizon : 2-3 ans minimum.

**Critères :**
- Expériences directement transférables : aucune
- Compétences immédiatement opérationnelles : non opérationnelles
- Connaissances spécifiques : non maîtrisées
- Réseau et positionnement : aucun réseau pertinent

**Horizon d'autonomie :**
- 2 à 3 ans minimum

**Recommandation :**
- Ne pas recruter pour CE poste MAINTENANT
- Considérer pour un poste d'une marche en dessous
- Plan de développement sur 2 ans
- Revisite dans 18-24 mois

## 6. Algorithme de Calcul du Score de Maturité

### 6.1 Pondération des Critères

| Critère | Pondération |
|---------|-------------|
| Expériences directement transférables | 30% |
| Compétences immédiatement opérationnelles | 30% |
| Connaissances spécifiques au poste | 20% |
| Réseau et positionnement | 20% |

### 6.2 Calcul par Critère

**Expériences directement transférables (30%) :**
- Identiques : 5/5
- Proches : 4/5
- Partielles : 3/5
- Éloignées : 2/5
- Aucunes : 1/5

**Compétences immédiatement opérationnelles (30%) :**
- Toutes : 5/5
- Majeures : 4/5
- Partielles : 3/5
- Limitées : 2/5
- Non opérationnelles : 1/5

**Connaissances spécifiques au poste (20%) :**
- Toutes maîtrisées : 5/5
- Majeures maîtrisées : 4/5
- Partiellement maîtrisées : 3/5
- Limitées : 2/5
- Non maîtrisées : 1/5

**Réseau et positionnement (20%) :**
- Complet et pertinent : 5/5
- Partiel mais pertinent : 4/5
- Limité : 3/5
- Très limité : 2/5
- Aucun réseau pertinent : 1/5

### 6.3 Calcul du Score Final

**Formule :**
Score = (Expériences × 0.30) + (Compétences × 0.30) + (Connaissances × 0.20) + (Réseau × 0.20)

**Arrondi :**
Arrondir à l'entier le plus proche (0.5 arrondi à l'entier supérieur)

**Exemple :**
- Expériences : 4/5
- Compétences : 3/5
- Connaissances : 3/5
- Réseau : 2/5

Score = (4 × 0.30) + (3 × 0.30) + (3 × 0.20) + (2 × 0.20)
Score = 1.2 + 0.9 + 0.6 + 0.4
Score = 3.1 → 3/5

## 7. Adaptation par Persona

### 7.1 Persona Senior

**Approche :**
- Focus sur l'expérience transférable
- Tolérance pour les lacunes de réseau
- Exigence sur les compétences opérationnelles

**Pondération ajustée :**
- Expériences : 35%
- Compétences : 30%
- Connaissances : 20%
- Réseau : 15%

### 7.2 Persona Executive

**Approche :**
- Focus sur le réseau et positionnement
- Exigence sur les compétences opérationnelles
- Tolérance pour les lacunes de connaissances spécifiques

**Pondération ajustée :**
- Expériences : 25%
- Compétences : 35%
- Connaissances : 15%
- Réseau : 25%

### 7.3 Persona Startup

**Approche :**
- Focus sur les compétences opérationnelles
- Tolérance pour les lacunes de réseau
- Exigence sur la capacité d'adaptation

**Pondération ajustée :**
- Expériences : 25%
- Compétences : 40%
- Connaissances : 20%
- Réseau : 15%

### 7.4 Persona Technical

**Approche :**
- Focus sur les connaissances spécifiques
- Exigence sur les compétences techniques
- Tolérance pour les lacunes de réseau

**Pondération ajustée :**
- Expériences : 25%
- Compétences : 30%
- Connaissances : 35%
- Réseau : 10%

## 9. Stockage et Gestion

### 9.1 Schéma SQL

```sql
CREATE TABLE maturity_score (
  id VARCHAR(36) PRIMARY KEY,
  candidate_id VARCHAR(36) NOT NULL,
  position_id VARCHAR(36) NOT NULL,
  interview_id VARCHAR(36) NOT NULL,
  
  scored_at TIMESTAMP NOT NULL,
  
  criteria JSON NOT NULL,
  final_score JSON NOT NULL,
  persona VARCHAR(20) NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_maturity_score_candidate ON maturity_score(candidate_id);
CREATE INDEX idx_maturity_score_position ON maturity_score(position_id);
CREATE INDEX idx_maturity_score_interview ON maturity_score(interview_id);

CREATE TABLE maturity_scale (
  id VARCHAR(36) PRIMARY KEY,
  
  definition JSON NOT NULL,
  criteria JSON NOT NULL,
  scale JSON NOT NULL,

  persona_adaptation JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
```

## 12. Conclusion

Le score de Maturité mesure la capacité immédiate du candidat à exercer les responsabilités du poste. 4 critères évalués : expériences directement transférables (30%), compétences immédiatement opérationnelles (30%), connaissances spécifiques au poste (20%), réseau et positionnement (20%). Échelle 5 niveaux : 5/5 (immédiat), 4/5 (2-4 semaines), 3/5 (3 mois), 2/5 (6-12 mois), 1/5 (2-3 ans minimum). Algorithme de calcul avec pondération. Adaptation par persona (Senior, Executive, Startup, Technical) avec pondérations ajustées. Distinction fondamentale : Maturité = ce que le candidat sait faire MAINTENANT, Potentiel = ce que le candidat peut DEVENIR.

**Points clés :**
- Définition de la maturité
- 4 critères évalués avec pondération
- Échelle 5 niveaux avec horizon d'autonomie
- Algorithme de calcul
- Adaptation par persona
- Structure de données TypeScript
- Stockage et gestion SQL
- API endpoints pour la gestion
- Métriques de distribution et de qualité
