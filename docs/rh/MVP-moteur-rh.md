# MVP du Moteur RH

## Identité

CE DOCUMENT DÉFINIT LE MVP DU MOTEUR RH.

LE MVP EST LA VERSION MINIMALE VIABLE DU MOTEUR COGNITIF RH.

LE MVP EST FONDÉ SUR L'ARCHITECTURE EXISTANTE.

LE MVP EST FONDÉ SUR LA CONNAISSANCE RH CRÉÉE.

LE MVP EST UTILISÉ POUR RÉPONDRE AUX QUESTIONS RH.

## Objectif du MVP

L'OBJECTIF DU MVP EST D'ÊTRE CAPABLE DE RÉPONDRE CORRECTEMENT À UN DRH.

LE MVP DOIT COMPRENDRE UNE QUESTION RH.

LE MVP DOIT RETROUVER LES CONNAISSANCES.

LE MVP DOIT RAISONNER.

LE MVP DOIT EXPLIQUER.

LE MVP DOIT CITER LES RÈGLES UTILISÉES.

LE MVP DOIT PRODUIRE UNE RÉPONSE ARGUMENTÉE.

## Exemple de scénario

### Scénario : Question sur le congé parental

LE DRH POSE LA QUESTION : "UN SALARIÉ PEUT-IL PRENDRE UN CONGÉ PARENTAL ?"

#### Étape 1 : Analyse de la question

LE MOTEUR IDENTIFIE LE CONCEPT SALARIÉ.

LE MOTEUR IDENTIFIE LE CONCEPT CONGÉ PARENTAL.

LE MOTEUR IDENTIFIE LA RELATION SALARIÉ-CONGÉ.

LE MOTEUR IDENTIFIE L'INTENTION : VÉRIFIER LE DROIT AU CONGÉ PARENTAL.

#### Étape 2 : Récupération des connaissances

LE MOTEUR RÉCUPÈRE RH-120 SALARIÉ.

LE MOTEUR RÉCUPÈRE RH-002 VOCABULAIRE RH.

LE MOTEUR RÉCUPÈRE RH-005 RÉFÉRENTIEL RH.

LE MOTEUR RÉCUPÈRE LES ARTICLES DU CODE DU TRAVAIL SUR LE CONGÉ PARENTAL.

LE MOTEUR RÉCUPÈRE LES CONVENTIONS COLLECTIVES SUR LE CONGÉ PARENTAL.

#### Étape 3 : Raisonnement

LE MOTEUR APPLIQUE LES RÈGLES DU CODE DU TRAVAIL.

LE MOTEUR APPLIQUE LES RÈGLES DES CONVENTIONS COLLECTIVES.

LE MOTEUR APPLIQUE LES RÈGLES DES ACCORDS D'ENTREPRISE.

LE MOTEUR DÉDUIT QUE LE SALARIÉ A DROIT AU CONGÉ PARENTAL SOUS CONDITIONS.

#### Étape 4 : Génération de la réponse

LE MOTEUR GÉNÈRE LA RÉPONSE : "OUI, UN SALARIÉ PEUT PRENDRE UN CONGÉ PARENTAL SOUS CONDITIONS. LE CONGÉ PARENTAL EST PRÉVU PAR LE CODE DU TRAVAIL (ARTICLE L1225-65). LE SALARIÉ DOIT JUSTIFIER D'UNE CERTAINE ANCIENNETÉ. LE CONGÉ PARENTAL EST RÉMUNÉRÉ SOUS CONDITIONS."

#### Étape 5 : Citation des sources
