## 1. Objectif

Définir la bibliothèque des 20 silences révélateurs pour le MVP-META-02 Silence Intelligence Engine. Ce document structure les types de silences qui peuvent révéler des informations importantes sur un candidat.

---

## 2. Principe Fondateur

L'absence est une donnée. Le silence est un signal. Ce qui n'est jamais mentionné révèle ce qui est évité, ignoré ou caché. Chaque silence a des interprétations possibles et une question révélatrice associée.

---

## 3. Bibliothèque des 20 Silences Révélateurs

### 3.1 SILENCE 1 — Sur le Manager

**Observations :**
Candidat qui parle de 4 ans dans une entreprise sans JAMAIS mentionner son manager ou son N+1.

**Interprétations possibles :**
- Relation très difficile ou conflictuelle
- Manager absent ou défaillant
- Travail en totale autonomie (positif ou négatif selon le poste)
- Départ conflictuel probable
- Sujet volontairement évité

**Question révélatrice :**
"Vous ne m'avez pas parlé de votre manager chez [entreprise]. Comment décririez-vous cette relation ?"

**Ce que la réponse révèle :**
- Réponse fluide et positive → Relation normale, sujet non saillant
- Hésitation puis généralités → Relation difficile minimisée
- Critique directe → Conflit ouvert
- Refus de commenter → Signal fort de problème

---

### 3.2 SILENCE 2 — Sur les Collègues

**Observations :**
Candidat qui décrit 5 projets sans mentionner d'autres personnes. Tout est "je" sans "nous".

**Interprétations :**
- Travail en silo volontaire
- Difficulté relationnelle
- Attribution du travail collectif
- Expérience effectivement solitaire

**Question révélatrice :**
"Dans vos projets, avec qui travailliez-vous principalement ? Décrivez-moi une collaboration qui vous a marqué."

**Ce que la réponse révèle :**
- Réponse détaillée sur les collaborations → Capacité relationnelle
- Réponse vague ou évasive → Difficulté relationnelle ou travail en silo
- Insistance sur le travail individuel → Orientation solitaire

---

### 3.3 SILENCE 3 — Sur les Chiffres

**Observations :**
7 ans de carrière. 0 chiffre spontané.

**Interprétations :**
- Postes sans résultats mesurables
- Résultats peu significatifs
- Orientation processus plutôt qu'orientation résultats
- Résultats à cacher

**Question révélatrice :**
"Quel est le résultat dont vous êtes le plus fier ? Chiffrez-le pour moi."

**Ce que la réponse révèle :**
- Réponse chiffrée spontanée → Orientation résultats
- Difficulté à chiffrer → Orientation processus ou résultats peu significatifs
- Refus de chiffrer → Résultats à cacher

---

### 3.4 SILENCE 4 — Sur l'Entreprise Actuelle

**Observations :**
Rien de positif jamais dit sur l'employeur actuel.

**Interprétations :**
- Départ conflictuel probable
- Déception profonde
- Candidature de fuite pas de projet
- Ou simplement : ouverture naturelle

**Question révélatrice :**
"Qu'est-ce que vous appréciez le plus dans votre entreprise actuelle ?"

**Ce que la réponse révèle :**
- Réponse positive → Relation saine avec l'employeur
- Difficulté à trouver du positif → Départ conflictuel probable
- Critiques uniquement → Risque de discours négatif après départ

---

### 3.5 SILENCE 5 — Sur les Échecs

**Observations :**
Candidat qui décrit 10 ans de carrière parfaite. 0 échec mentionné.

**Interprétations :**
- Peur du jugement
- Manque de recul
- Perfectionnisme défensif
- Peu d'expériences difficiles réelles (carrière très protégée)

**Question révélatrice :**
"Dans une carrière de [N] ans, il y a forcément des moments difficiles. Quel est celui dont vous avez le plus appris ?"

**Ce que la réponse révèle :**
- Réponse honnête sur un échec → Capacité de recul et d'apprentissage
- Réponse évasive → Peur du jugement ou manque de recul
- Refus d'admettre un échec → Perfectionnisme défensif

---

### 3.6 SILENCE 6 — Sur l'Avenir

**Observations :**
Candidat qui répond à tout sur le passé et le présent. Jamais sur l'avenir.

**Interprétations :**
- Pas de vision à long terme
- Candidature de fuite pas de projet

- Incertitude sur la décision de postuler

**Question révélatrice :**

**Ce que la réponse révèle :**

- Difficulté à répondre → Candidature de fuite

### 3.7 SILENCE 7 — Sur le Poste Précis

**Observations :**
Candidat qui parle de tout sauf du poste pour lequel il postule. Pas de questions sur les missions. Pas de curiosité sur l'équipe.

**Interprétations :**

- Intérêt pour le titre/salaire pas pour le poste

**Question révélatrice :**
"Qu'est-ce qui vous attire spécifiquement dans CE poste, pas dans le titre ou le niveau, mais dans le contenu quotidien ?"

**Ce que la réponse révèle :**
- Réponse spécifique sur le contenu → Motivation réelle

- Difficulté à répondre → Manque de préparation

## 4. Structure de Données (TypeScript)

```typescript
interface RevealingSilence {
  silenceId: string;
  name: string;
  category: string;
  
  observations: string;
  interpretations: string[];
  
  revealingQuestion: string;
  responseRevelations: {
    positiveResponse: string;
    vagueResponse: string;
    refusalResponse: string;
  };
  
  metadata: {
    version: string;
    createdAt: Date;
    lastUpdated: Date;
  };
}

interface RevealingSilenceLibrary {
  libraryId: string;
  
  silences: RevealingSilence[];
  
  categories: {
    professional: string[];
    personal: string[];
    relational: string[];
    results: string[];
  };
  
  metadata: {
    version: string;
    createdAt: Date;
    lastUpdated: Date;
  };
}
```

## 5. Stockage et Gestion

### 5.1 Schéma SQL

```sql
CREATE TABLE revealing_silence (
  id VARCHAR(36) PRIMARY KEY,
  name VARCHAR(100) NOT NULL,
  category VARCHAR(50) NOT NULL,
  
  observations TEXT NOT NULL,
  interpretations JSON NOT NULL,
  revealing_question TEXT NOT NULL,
  response_revelations JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_revealing_silence_category ON revealing_silence(category);

CREATE TABLE revealing_silence_library (
  id VARCHAR(36) PRIMARY KEY,
  
  silences JSON NOT NULL,
  categories JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
