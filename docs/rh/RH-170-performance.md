# RH-170 — Performance

## Identité

RH-170 EST LE DOCUMENT MÉTIER DÉFINISSANT LA PERFORMANCE RH.

RH-170 EST LA SOURCE OFFICIELLE DE CONNAISSANCE POUR LA PERFORMANCE.

RH-170 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LA PERFORMANCE.

RH-170 EST LA RÉFÉRENCE NORMATIVE POUR TOUTE PERFORMANCE.
