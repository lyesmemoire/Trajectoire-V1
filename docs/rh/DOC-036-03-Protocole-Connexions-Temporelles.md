## 1. Objectif

Définir le protocole de connexions temporelles pour MVP-036 Active Listening Engine. Ce protocole structure comment le moteur se souvient et revient sur ce qui a été dit à différents moments de l'entretien pour créer la sensation d'être vraiment écouté et faire des connexions que le candidat n'a pas faites lui-même.

---

## 2. Principe Fondateur

Le moteur se souvient et revient sur ce qui a été dit. Les connexions temporelles créent chez le candidat la sensation : "Il m'a vraiment écouté. Il n'a pas oublié ce que j'ai dit. Il fait des connexions que je n'avais pas faites moi-même. C'est un entretien intelligent." Les connexions peuvent être immédiates, différées, ou distantes.

---

## 3. Connexion Immédiate

### 3.1 Objectif

Connecter immédiatement un élément mentionné par le candidat pour approfondir ou clarifier.

### 3.2 Structure

**Template :**
```
Vous venez de mentionner X.
Pouvez-vous développer ?
```

### 3.3 Exemples

**Exemple 1 :**
- Candidat : "J'ai travaillé sur un projet de refonte du site web pendant 6 mois. L'équipe était de 5 personnes."
- Connexion immédiate : "Vous venez de mentionner que l'équipe était de 5 personnes. Pouvez-vous développer sur la dynamique de cette équipe ?"

**Exemple 2 :**
- Candidat : "J'ai quitté mon précédent poste parce que je cherchais de nouveaux défis. L'entreprise était stable mais il n'y avait pas d'opportunités d'évolution."
- Connexion immédiate : "Vous venez de mentionner qu'il n'y avait pas d'opportunités d'évolution. Pouvez-vous développer sur ce que vous auriez souhaité avoir comme opportunités ?"

**Exemple 3 :**
- Candidat : "Je suis très motivé par ce poste car il correspond à mes compétences. J'ai de l'expérience en développement web et en gestion de projet."
- Connexion immédiate : "Vous venez de mentionner votre expérience en gestion de projet. Pouvez-vous développer sur un projet spécifique que vous avez géré ?"

### 3.4 Quand Utiliser

- Élément intéressant mentionné par le candidat
- Besoin de clarification immédiate
- Élément clé pour l'évaluation
- Transition naturelle vers un sujet connexe

## 4. Connexion Différée

### 4.1 Objectif

Connecter un élément mentionné il y a quelques minutes avec un élément actuel pour créer une cohérence temporelle.

### 4.2 Structure

**Template :**
```
Il y a quelques minutes
vous parliez de X.
Ce que vous venez de dire
sur Y m'y fait penser.
Comment ces deux éléments
s'articulent-ils pour vous ?
```

### 4.3 Exemples

**Exemple 1 :**
- Candidat (il y a 5 minutes) : "J'aime travailler en équipe."
- Candidat (maintenant) : "Je préfère prendre les décisions seul."
- Connexion différée : "Il y a quelques minutes vous parliez d'aimer travailler en équipe. Ce que vous venez de dire sur préférer prendre les décisions seul m'y fait penser. Comment ces deux éléments s'articulent-ils pour vous ?"

**Exemple 2 :**
- Candidat (il y a 10 minutes) : "Je cherche un poste stable."
- Candidat (maintenant) : "Je veux aussi de nouveaux défis."
- Connexion différée : "Il y a quelques minutes vous parliez de chercher un poste stable. Ce que vous venez de dire sur vouloir aussi de nouveaux défis m'y fait penser. Comment ces deux éléments s'articulent-ils pour vous ?"

**Exemple 3 :**
- Candidat (il y a 8 minutes) : "J'ai de l'expérience en développement web."
- Candidat (maintenant) : "Je veux évoluer vers un rôle plus stratégique."
- Connexion différée : "Il y a quelques minutes vous parliez de votre expérience en développement web. Ce que vous venez de dire sur vouloir évoluer vers un rôle plus stratégique m'y fait penser. Comment ces deux éléments s'articulent-ils pour vous ?"

### 4.4 Quand Utiliser

- Élément mentionné il y a 2-10 minutes
- Connexion pertinente avec l'élément actuel
- Création de cohérence temporelle
- Exploration des tensions ou synergies

---

## 5. Connexion Distante

### 5.1 Objectif

Connecter un élément mentionné en début d'entretien avec un élément actuel pour explorer l'évolution dans la pensée du candidat.

### 5.2 Structure

**Template :**
```
En début d'entretien
vous m'aviez dit X.
Et maintenant vous décrivez Y.
Je voudrais explorer
cette évolution dans votre pensée.
```

### 5.3 Exemples

**Exemple 1 :**
- Candidat (en début d'entretien) : "Je cherche un poste très stable."
- Candidat (maintenant) : "Je suis prêt à prendre des risques pour de nouveaux défis."
- Connexion distante : "En début d'entretien vous m'aviez dit que vous cherchiez un poste très stable. Et maintenant vous décrivez être prêt à prendre des risques pour de nouveaux défis. Je voudrais explorer cette évolution dans votre pensée."

**Exemple 2 :**
- Candidat (en début d'entretien) : "Je préfère travailler seul."
- Candidat (maintenant) : "J'apprécie vraiment le travail en équipe."
- Connexion distante : "En début d'entretien vous m'aviez dit que vous préféreriez travailler seul. Et maintenant vous décrivez apprécier vraiment le travail en équipe. Je voudrais explorer cette évolution dans votre pensée."

**Exemple 3 :**
- Candidat (en début d'entretien) : "Je veux un poste technique."
- Candidat (maintenant) : "Je m'intéresse de plus en plus à la gestion."
- Connexion distante : "En début d'entretien vous m'aviez dit que vous vouliez un poste technique. Et maintenant vous décrivez vous intéresser de plus en plus à la gestion. Je voudrais explorer cette évolution dans votre pensée."

### 5.4 Quand Utiliser

- Élément mentionné en début d'entretien
- Évolution significative dans la pensée du candidat
- Exploration des changements de perspective
- Création d'une cohérence narrative

## 6. Protocole de Sélection du Type de Connexion

### 6.1 Critères de Sélection

**Connexion immédiate :**
- Élément mentionné il y a < 2 minutes
- Élément directement pertinent à la question actuelle
- Besoin de clarification immédiate
- Transition naturelle

**Connexion différée :**
- Élément mentionné il y a 2-10 minutes
- Connexion pertinente mais pas immédiate
- Création de cohérence temporelle
- Exploration des tensions ou synergies

**Connexion distante :**
- Élément mentionné il y a > 10 minutes
- Évolution significative dans la pensée
- Création d'une cohérence narrative
- Exploration des changements de perspective

### 6.2 Algorithme de Sélection

**Étape 1 — Analyser l'historique :**
- Identifier les éléments mentionnés précédemment
- Noter le temps écoulé depuis chaque élément
- Identifier les connexions potentielles

**Étape 2 — Évaluer la pertinence :**
- Évaluer la pertinence de chaque connexion
- Noter la force de la connexion
- Noter la valeur ajoutée de la connexion

**Étape 3 — Sélectionner le type de connexion :**
- Si < 2 minutes et pertinent → Connexion immédiate
- Si 2-10 minutes et pertinent → Connexion différée
- Si > 10 minutes et évolution → Connexion distante

**Étape 4 — Générer la connexion :**
- Utiliser le template du type sélectionné
- Adapter au contenu des éléments
- Inclure les éléments clés identifiés

**Étape 5 — Valider la connexion :**
- Vérifier la cohérence
- Vérifier la pertinence
- Ajuster si nécessaire

  whenToUse: string[];

## 9. Stockage et Gestion

### 9.1 Schéma SQL

```sql
CREATE TABLE temporal_connection (
  id VARCHAR(36) PRIMARY KEY,
  type VARCHAR(20) NOT NULL,
  
  template TEXT NOT NULL,
  description TEXT NOT NULL,
  
  examples JSON NOT NULL,
  selection_criteria JSON NOT NULL,
  persona_adaptation JSON NOT NULL,
  when_to_use JSON NOT NULL,
  
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_temporal_connection_type ON temporal_connection(type);

CREATE TABLE temporal_connection_protocol (
  id VARCHAR(36) PRIMARY KEY,
  
  connection_types JSON NOT NULL,
  selection_protocol JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
