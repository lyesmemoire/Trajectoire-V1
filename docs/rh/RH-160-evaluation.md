# RH-160 — Évaluation

## Identité

RH-160 EST LE DOCUMENT MÉTIER DÉFINISSANT L'ÉVALUATION RH.

RH-160 EST LA SOURCE OFFICIELLE DE CONNAISSANCE POUR L'ÉVALUATION.

RH-160 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE L'ÉVALUATION.

RH-160 EST LA RÉFÉRENCE NORMATIVE POUR TOUTE ÉVALUATION.

## Définitions

### Évaluation

L'ÉVALUATION EST UN PROCESSUS D'ANALYSE DE LA PERFORMANCE D'UN SALARIÉ.

L'ÉVALUATION EST UN PROCESSUS STRUCTURÉ.

L'ÉVALUATION EST UN PROCESSUS DOCUMENTÉ.

L'ÉVALUATION EST UN PROCESSUS PÉRIODIQUE.

L'ÉVALUATION EST UN PROCESSUS BILATÉRAL.

L'ÉVALUATION EST SOUMISE AU DROIT DU TRAVAIL.

L'ÉVALUATION EST SOUMISE AUX CONVENTIONS COLLECTIVES.

L'ÉVALUATION EST SOUMISE AUX POLITIQUES INTERNES.

### Entretien annuel

L'ENTRETIEN ANNUEL EST UN ÉCHANGE ENTRE LE SALARIÉ ET LE MANAGER.

L'ENTRETIEN ANNUEL PERMET DE FAIRE LE BILAN DE L'ANNÉE ÉCOULÉE.

L'ENTRETIEN ANNUEL PERMET DE DÉFINIR LES OBJECTIFS DE L'ANNÉE À VENIR.

L'ENTRETIEN ANNUEL PERMET DE DISCUTER DU DÉVELOPPEMENT PROFESSIONNEL.

L'ENTRETIEN ANNUEL EST DOCUMENTÉ.

L'ENTRETIEN ANNUEL EST OBLIGATOIRE SOUS CONDITIONS.

### Entretien professionnel

L'ENTRETIEN PROFESSIONNEL EST UN ÉCHANGE SUR LE DÉVELOPPEMENT PROFESSIONNEL.

L'ENTRETIEN PROFESSIONNEL PERMET DE DISCUTER DES ASPIRATIONS DU SALARIÉ.

L'ENTRETIEN PROFESSIONNEL PERMET DE DISCUTER DES POSSIBILITÉS D'ÉVOLUTION.

L'ENTRETIEN PROFESSIONNEL PERMET DE DÉFINIR UN PLAN DE DÉVELOPPEMENT.

L'ENTRETIEN PROFESSIONNEL EST DOCUMENTÉ.

L'ENTRETIEN PROFESSIONNEL EST OBLIGATOIRE SOUS CONDITIONS.
