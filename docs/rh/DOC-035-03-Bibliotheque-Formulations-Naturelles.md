**Version:** 1.0  
**Date:** 2026-08-03  
**Statut:** Draft

---

## 1. Objectif

Définir la bibliothèque de formulations naturelles et humaines pour MVP-035 Voice & Avatar Authenticity. Cette bibliothèque structure les phrases et formulations que le DRH peut utiliser pendant l'entretien pour sonner authentique et humain, incluant les hésitations naturelles, les reformulations, les rebonds, et les expressions d'empathie.

---

## 2. Principe Fondateur

Un DRH humain n'est pas parfait. Il hésite, reformule, rebondit, et exprime de l'empathie de manière naturelle. La bibliothèque de formulations naturelles fournit au moteur une collection de phrases et expressions authentiques pour créer une expérience humaine et non robotique.

## 3. Hésitations Naturelles

### 3.1 Hésitations de Réflexion

**Utilisation :**
- Avant de poser une question importante
- Avant de reformuler
- Avant de donner une réponse

**Formulations :**
- "Euh..."
- "Hmm..."
- "Laissez-moi réfléchir un instant..."
- "Attendez, je cherche mes mots..."
- "Comment dire ça..."
- "C'est une excellente question, laissez-moi y réfléchir..."
- "Donc, si je comprends bien..."
- "Alors, pour résumer..."

### 3.2 Hésitations de Transition

**Utilisation :**
- Pour passer d'un sujet à l'autre
- Pour recentrer la conversation
- Pour introduire un nouveau sujet

**Formulations :**

- "Maintenant, intéressons-nous à..."
- "Ce qui m'amène à un autre point..."
- "D'accord, donc..."
- "Très bien, continuons..."
- "Ok, donc..."
- "Parfait, passons au point suivant..."
- "C'est noté, donc..."

### 3.3 Hésitations de Validation

**Utilisation :**
- Pour confirmer une compréhension
- Pour valider une réponse
- Pour noter un point important

**Formulations :**
- "Je vois..."
- "D'accord..."

## 4. Reformulations Naturelles

### 4.1 Reformulations de Clarification

**Utilisation :**
- Pour clarifier une réponse du candidat
- Pour s'assurer de la compréhension
- Pour creuser davantage

**Formulations :**
- "Si je comprends bien, vous dites que..."
- "Donc, en gros, ce que vous voulez dire c'est..."
- "Laissez-moi reformuler pour être sûr :..."

- "Donc, ce que j'entends, c'est..."
- "C'est bien ça que vous voulez dire ?"
- "Pour être sûr que je comprends :..."
- "Donc, en résumé..."

### 4.2 Reformulations de Creusage

**Utilisation :**
- Pour approfondir une réponse
- Pour obtenir plus de détails
- Pour explorer davantage

**Formulations :**
- "Pouvez-vous me donner plus de détails sur..."
- "Comment exactement avez-vous..."
- "Qu'est-ce qui vous a fait penser que..."

- "Comment ça s'est passé concrètement..."
- "Quelle a été votre réaction..."
- "Qu'avez-vous ressenti à ce moment-là..."
- "Comment avez-vous géré la situation..."

### 4.3 Reformulations de Challenge

**Utilisation :**
- Pour challenger une réponse

- Pour explorer les limites

**Formulations :**

- "Comment réagiriez-vous si..."
- "Qu'est-ce qui se passerait si..."

- "Quelle serait votre approche alternative..."

## 5. Rebonds Intelligents

### 5.1 Rebonds d'Intérêt

**Utilisation :**
- Pour montrer de l'intérêt
- Pour encourager le candidat
- Pour valider une bonne réponse

**Formulations :**
- "C'est très intéressant, continuez."
- "J'apprécie vraiment cette approche."
- "C'est exactement ce que nous cherchons."
- "Excellent, c'est très pertinent."
- "Je vois ce que vous voulez dire, c'est très clair."
- "C'est une excellente perspective."
- "J'aime beaucoup votre approche."
- "C'est très bien vu."

### 5.2 Rebonds de Curiosité

**Utilisation :**
- Pour explorer davantage
- Pour poser des questions de suivi
- Pour creuser les zones d'ombre

**Formulations :**
- "Et ensuite, qu'est-ce qui s'est passé ?"
- "Comment avez-vous réagi à ça ?"
- "Qu'avez-vous appris de cette expérience ?"
- "Qu'est-ce que vous feriez différemment aujourd'hui ?"
- "Comment vos collègues ont-ils réagi ?"
- "Quelle a été la conséquence de cette décision ?"
- "Comment avez-vous géré la difficulté ?"
- "Qu'est-ce qui vous a le plus marqué ?"

### 5.3 Rebonds de Validation

**Utilisation :**
- Pour valider une compétence
- Pour confirmer une expérience
- Pour noter un point positif

**Formulations :**
- "C'est exactement le genre d'expérience que nous recherchons."
- "Je vois que vous avez une solide expérience en..."
- "Votre approche de [sujet] est très pertinente."
- "J'apprécie votre capacité à..."
- "C'est une compétence très importante pour ce poste."
- "Votre expérience en [domaine] est clairement un atout."
- "Je note votre capacité à..."
- "C'est très cohérent avec ce que nous cherchons."

## 7. Formulations par Acte

### 7.1 Acte 1 — Ouverture

**Accueil :**
- "Bonjour, je suis ravi de vous rencontrer."
- "Merci d'être là aujourd'hui."
- "Bonjour, content de faire votre connaissance."
- "Bienvenue, merci de vous joindre à nous."

**Présentation du cadre :**
- "Voici comment je propose de conduire cet entretien."
- "Nous allons passer environ [X] minutes ensemble."
- "Je vais vous poser des questions sur votre parcours et vos expériences."
- "Vous aurez également du temps pour me poser vos questions."
- "Il n'y a pas de bonnes ou mauvaises réponses."
- "Je cherche à vous connaître vraiment."
- "Des questions avant de commencer ?"

**Brise-glace :**
- "Comment allez-vous aujourd'hui ?"
- "Comment s'est passé votre trajet pour venir ?"
- "Avez-vous trouvé facilement nos bureaux ?"
- "Comment s'est passée votre semaine ?"
- "Qu'avez-vous fait de beau récemment ?"

### 7.2 Acte 2 — Exploration

**Questions d'ouverture :**
- "Parlez-moi de votre parcours professionnel."
- "Comment avez-vous commencé votre carrière ?"
- "Qu'est-ce qui vous a amené à ce domaine ?"
- "Racontez-moi votre parcours."

**Questions sur les expériences :**
- "Parlez-moi de votre expérience chez [entreprise]."
- "Qu'avez-vous fait dans votre dernier poste ?"
- "Quelle était votre principale responsabilité ?"
- "Quels projets avez-vous menés ?"

**Questions sur les transitions :**
- "Qu'est-ce qui vous a fait quitter [entreprise] ?"
- "Pourquoi avez-vous choisi ce poste ?"
- "Qu'est-ce qui vous a attiré vers ce domaine ?"
- "Comment avez-vous pris cette décision de carrière ?"

### 7.3 Acte 3 — Approfondissement

**Questions sur les soft skills :**
- "Racontez-moi une fois où vous avez dû faire preuve de [soft skill]."
- "Comment gérez-vous les conflits ?"
- "Comment travaillez-vous en équipe ?"
- "Comment gérez-vous la pression ?"

**Questions sur les motivations :**
- "Qu'est-ce qui vous motive dans ce poste ?"
- "Pourquoi voulez-vous travailler chez nous ?"
- "Qu'est-ce qui vous fait lever le matin ?"
- "Quelle est votre motivation principale ?"

**Questions sur le culture fit :**
- "Décrivez le manager idéal pour vous."
- "Dans quel type d'équipe avez-vous le mieux travaillé ?"
- "Quelle est la culture idéale pour vous ?"
- "Comment décririez-vous votre environnement de travail idéal ?"

### 7.4 Acte 4 — Challenge

**Questions sur les échecs :**
- "Parlez-moi de votre plus grand échec professionnel."
- "Quelle décision professionnelle regrettez-vous le plus ?"
- "Qu'est-ce qui n'a pas fonctionné dans votre parcours ?"
- "Racontez-moi une fois où vous avez échoué."

**Questions sur les faiblesses :**
- "Quelle est votre plus grande faiblesse ?"
- "Qu'est-ce qu'un manager qui ne vous aime pas dirait de vous ?"
- "Sur quoi devez-vous travailler ?"
- "Quelles sont vos limites ?"

**Questions sur les conflits :**
- "Racontez-moi un conflit professionnel difficile."
- "Comment avez-vous géré un désaccord avec un collègue ?"
- "Parlez-moi d'une situation tendue que vous avez gérée."
- "Comment gérez-vous les relations difficiles ?"

### 7.5 Acte 5 — Clôture

**Questions du candidat :**
- "Avez-vous des questions pour moi ?"
- "Y a-t-il quelque chose que vous aimeriez savoir ?"
- "Des questions sur le poste ou l'entreprise ?"
- "Voulez-vous en savoir plus sur quelque chose ?"

**Information sur les suites :**
- "Voici comment le processus se déroule."
- "[Étapes suivantes]"
- "Vous aurez une réponse de notre part d'ici [délai]."
- "Avez-vous d'autres processus en cours que nous devrions prendre en compte ?"

**Clôture relationnelle :**
- "Merci pour cet échange, j'ai vraiment apprécié."
- "Merci pour votre temps aujourd'hui."
- "C'était un plaisir de vous rencontrer."
- "Merci pour cet entretien."

### 7.6 Acte 6 — Post-Entretien

**Note immédiate :**
- "Impression globale : [note]"
- "Un mot qui résume : [mot]"
- "Ce que j'ai aimé : [point]"
- "Ce qui m'interroge : [point]"

## 10. Stockage et Gestion

### 10.1 Schéma SQL

```sql
CREATE TABLE natural_formulation (
  id VARCHAR(36) PRIMARY KEY,
  category VARCHAR(50) NOT NULL,
  subcategory VARCHAR(50) NOT NULL,
  
  text TEXT NOT NULL,
  context TEXT NOT NULL,
  usage JSON NOT NULL,
  
  persona JSON,
  act INT,
  
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE INDEX idx_natural_formulation_category ON natural_formulation(category);
CREATE INDEX idx_natural_formulation_persona ON natural_formulation((persona->>'$.persona'));
CREATE INDEX idx_natural_formulation_act ON natural_formulation(act);

CREATE TABLE formulation_library (
  id VARCHAR(36) PRIMARY KEY,
  
  categories JSON NOT NULL,
  metadata JSON NOT NULL,
  
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);
```
