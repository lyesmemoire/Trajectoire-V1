## 1. Objectif

Définir les questionnaires de bilan pour chaque étape de suivi du MVP-META-05 Feedback Intelligence Engine. Ce document structure les questionnaires pour J+15, 30, 90, 180, 365, 730.

---

## 2. Principe Fondateur

Les questionnaires doivent être standardisés, faciles à remplir, et capturer les données essentielles pour valider les prédictions du moteur.

## 13. Conclusion

Le questionnaire de bilan par étape structure les questionnaires pour chaque étape de suivi. Questionnaire J+15 : statut de l'offre, raisons de refus, apprentissage. Questionnaire J+30 : statut du démarrage, premières impressions du manager, comparaison avec prédictions. Questionnaire J+90 : performance vs objectifs, intégration culturelle, relation manager, signaux d'alerte, comparaison avec prédictions. Questionnaire J+180 : performance globale, compétences révélées, lacunes révélées, satisfaction, risque de départ. Questionnaire J+365 : critères de succès, score de succès, comparaison avec prédiction, erreurs identifiées. Questionnaire J+730 : évolution du candidat, validation du potentiel. Structure de données TypeScript, stockage SQL, API endpoints pour la gestion.

**Points clés :**
- 6 questionnaires par étape
- J+15 : signature et apprentissage
- J+30 : premières impressions
- J+90 : bilan 90 jours
- J+180 : bilan 6 mois
- J+365 : bilan 12 mois
- J+730 : bilan 24 mois
- Questions standardisées
- Comparaison avec prédictions
- Structure de données TypeScript
- Stockage et gestion SQL
- API endpoints pour la gestion
- Métriques de qualité et d'utilisation
