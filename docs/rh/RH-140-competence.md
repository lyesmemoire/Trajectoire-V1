# RH-140 — Compétence

## Identité

RH-140 EST LE DOCUMENT MÉTIER DÉFINISSANT LA COMPÉTENCE RH.

RH-140 EST LA SOURCE OFFICIELLE DE CONNAISSANCE POUR LA COMPÉTENCE.

RH-140 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LA COMPÉTENCE.

RH-140 EST LA RÉFÉRENCE NORMATIVE POUR TOUTE COMPÉTENCE.

## Définitions

### Compétence

UNE COMPÉTENCE EST UNE CAPACITÉ À RÉALISER UNE TÂCHE OU UNE ACTIVITÉ DE MANIÈRE EFFICACE.

LA COMPÉTENCE EST UN COMBINAISON DE CONNAISSANCES.

LA COMPÉTENCE EST UN COMBINAISON DE SAVOIR-FAIRE.

LA COMPÉTENCE EST UN COMBINAISON DE SAVOIR-ÊTRE.

LA COMPÉTENCE EST ACQUISE PAR LA FORMATION.

LA COMPÉTENCE EST ACQUISE PAR L'EXPÉRIENCE.

LA COMPÉTENCE EST ACQUISE PAR LA PRATIQUE.

LA CONNAISSANCE EST ÉVALUÉE.

### Savoir-faire

LE SAVOIR-FAIRE EST ÉVALUÉ.
