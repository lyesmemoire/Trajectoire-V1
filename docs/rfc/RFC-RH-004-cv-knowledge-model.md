## Structure du CV

### Concept : CV

LE CV EST UN DOCUMENT PRÉSENTANT LE PROFIL D'UN CANDIDAT.

LE CV INCLUT LES INFORMATIONS PERSONNELLES.

LE CV INCLUT LA FORMATION.

LE CV INCLUT L'EXPÉRIENCE PROFESSIONNELLE.

LE CV INCLUT LES COMPÉTENCES.

LE CV INCLUT LES CERTIFICATIONS.

LE CV INCLUT LES DIPLÔMES.

LE CV INCLUT LES LANGUES.

LE CV INCLUT LES CENTRES D'INTÉRÊT.

LE CV EST DOCUMENTÉ.

LE CV EST TRAÇABLE.

### Concept : Informations personnelles

LES INFORMATIONS PERSONNELLES INCLUENT LE NOM.

LES INFORMATIONS PERSONNELLES INCLUENT LE PRÉNOM.

LES INFORMATIONS PERSONNELLES INCLUENT L'ADRESSE.

LES INFORMATIONS PERSONNELLES INCLUENT LE TÉLÉPHONE.

LES INFORMATIONS PERSONNELLES INCLUENT L'EMAIL.

LES INFORMATIONS PERSONNELLES INCLUENT LA DATE DE NAISSANCE.

LES INFORMATIONS PERSONNELLES INCLUENT LA NATIONALITÉ.

LES INFORMATIONS PERSONNELLES SONT DOCUMENTÉES.

LES INFORMATIONS PERSONNELLES SONT TRAÇABLES.

### Concept : Formation

LA FORMATION EST L'ENSEMBLE DES DIPLÔMES ET CERTIFICATIONS OBTENUS.

LA FORMATION INCLUT LES DIPLÔMES.

LA FORMATION INCLUT LES CERTIFICATIONS.

LA FORMATION INCLUT LES FORMATIONS CONTINUES.

LA FORMATION EST DOCUMENTÉE.

LA FORMATION EST TRAÇABLE.

### Concept : Expérience professionnelle

L'EXPÉRIENCE PROFESSIONNELLE EST L'ENSEMBLE DES POSTES OCCUPÉS.

L'EXPÉRIENCE PROFESSIONNELLE INCLUT LES POSTES.

L'EXPÉRIENCE PROFESSIONNELLE INCLUT LES ENTREPRISES.

L'EXPÉRIENCE PROFESSIONNELLE INCLUT LES DURÉES.

L'EXPÉRIENCE PROFESSIONNELLE INCLUT LES RESPONSABILITÉS.

L'EXPÉRIENCE PROFESSIONNELLE INCLUT LES RÉALISATIONS.

L'EXPÉRIENCE PROFESSIONNELLE EST DOCUMENTÉE.

L'EXPÉRIENCE PROFESSIONNELLE EST TRAÇABLE.

### Concept : Compétences

LES COMPÉTENCES SONT L'ENSEMBLE DES CAPACITÉS DU CANDIDAT.

LES COMPÉTENCES INCLUENT LES HARD SKILLS.

LES COMPÉTENCES INCLUENT LES SOFT SKILLS.

LES COMPÉTENCES INCLUENT LES COMPÉTENCES FONCTIONNELLES.

LES COMPÉTENCES INCLUENT LES COMPÉTENCES COMPORTEMENTALES.

LES COMPÉTENCES SONT DOCUMENTÉES.

LES COMPÉTENCES SONT TRAÇABLES.

### Concept : Certifications

LES CERTIFICATIONS SONT L'ENSEMBLE DES CERTIFICATIONS OBTENUES.

LES CERTIFICATIONS INCLUENT LE NOM DE LA CERTIFICATION.

LES CERTIFICATIONS INCLUENT L'ORGANISME CERTIFICATEUR.

LES CERTIFICATIONS INCLUENT LA DATE D'OBTENTION.

LES CERTIFICATIONS INCLUENT LA DATE D'EXPIRATION.

LES CERTIFICATIONS SONT DOCUMENTÉES.

LES CERTIFICATIONS SONT TRAÇABLES.

### Concept : Diplômes

LES DIPLÔMES SONT L'ENSEMBLE DES DIPLÔMES OBTENUS.

LES DIPLÔMES INCLUENT LE NOM DU DIPLÔME.

LES DIPLÔMES INCLUENT L'ÉTABLISSEMENT.

LES DIPLÔMES INCLUENT L'ANNÉE D'OBTENTION.

LES DIPLÔMES INCLUENT LE NIVEAU.

LES DIPLÔMES SONT DOCUMENTÉS.

LES DIPLÔMES SONT TRAÇABLES.

### Concept : Langues

LES LANGUES INCLUENT LE NOM DE LA LANGUE.

LES LANGUES INCLUENT LE NIVEAU.

LES LANGUES SONT DOCUMENTÉES.

LES LANGUES SONT TRAÇABLES.

### Concept : Centres d'intérêt

LES CENTRES D'INTÉRÊT SONT LES INTÉRÊTS PERSONNELS DU CANDIDAT.

LES CENTRES D'INTÉRÊT INCLUENT LES ACTIVITÉS.
