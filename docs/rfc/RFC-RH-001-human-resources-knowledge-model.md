# RFC-RH-001 — Human Resources Knowledge Model

## Identité

RFC-RH-001 EST LA RFC FONDATRICE DU DOMAINE MÉTIER RH.

RFC-RH-001 DÉFINIT LE MODÈLE DE CONNAISSANCE RH.

RFC-RH-001 EST CONFORME À ADR-001 À ADR-014.

RFC-RH-001 EST CONFORME À RFC-001 À RFC-073.

RFC-RH-001 EST CONFORME À RFC-ARCHITECTURE-BASELINE-V1.

RFC-RH-001 A POUR OBJECTIF DE DÉFINIR LE MODÈLE MÉTIER RH DE MANIÈRE NORMATIVE.

## Définitions normatives des concepts RH

### Concept : Salarié

LE SALARIÉ EST UNE PERSONNE PHYSIQUE LIÉE À L'ORGANISATION PAR UN CONTRAT DE TRAVAIL.

LE SALARIÉ EST SOUMIS AU DROIT DU TRAVAIL.

LE SALARIÉ EST SOUMIS AUX CONVENTIONS COLLECTIVES.

LE SALARIÉ EST SOUMIS AUX ACCORDS D'ENTREPRISE.

LE SALARIÉ EST SOUMIS AU RÈGLEMENT INTÉRIEUR.

LE SALARIÉ REÇOIT UNE RÉMUNÉRATION EN ÉCHANGE DE SON TRAVAIL.

LE SALARIÉ EST IDENTIFIÉ PAR UN NUMÉRO UNIQUE.

LE SALARIÉ EST CLASSÉ DANS UNE CATÉGORIE PROFESSIONNELLE.

LE SALARIÉ EST CLASSÉ DANS UN NIVEAU HIÉRARCHIQUE.

LE SALARIÉ EST RATTACHÉ À UN DÉPARTEMENT.

LE SALARIÉ EST RATTACHÉ À UN ÉTABLISSEMENT.

LE SALARIÉ EST RATTACHÉ À UN MANAGER.

LE SALARIÉ POSSEDE DES COMPÉTENCES.

LE SALARIÉ POSSEDE DES QUALIFICATIONS.

LE SALARIÉ EST ÉVALUÉ RÉGULIÈREMENT.

LE SALARIÉ EST FORMÉ RÉGULIÈREMENT.

LE SALARIÉ EST MOBILE DANS L'ORGANISATION.

LE SALARIÉ EST DOCUMENTÉ DANS UN DOSSIER EMPLOYÉ.

### Concept : Candidat

LE CANDIDAT EST UNE PERSONNE PHYSIQUE QUI POSTULE À UN POSTE.

LE CANDIDAT EST DANS LE PROCESSUS DE RECRUTEMENT.

LE CANDIDAT EST ÉVALUÉ SUR SES COMPÉTENCES.

LE CANDIDAT EST ÉVALUÉ SUR SES QUALIFICATIONS.

LE CANDIDAT EST ÉVALUÉ SUR SON EXPÉRIENCE.

LE CANDIDAT EST SÉLECTIONNÉ OU REJETÉ.

LE CANDIDAT EST DOCUMENTÉ DANS UN DOSSIER CANDIDAT.

LE CANDIDAT EST PROTÉGÉ PAR LE DROIT DU TRAVAIL.

LE CANDIDAT EST PROTÉGÉ PAR LE RGPD.

### Concept : Collaborateur

LE COLLABORATEUR EST UN TERME GÉNÉRIQUE DÉSIGNANT LES PERSONNES QUI CONTRIBUENT À L'ACTIVITÉ DE L'ORGANISATION.

LE COLLABORATEUR INCLUT LES SALARIÉS.

LE COLLABORATEUR INCLUT LES INTÉRIMAIRES.

LE COLLABORATEUR INCLUT LES CONSULTANTS.

LE COLLABORATEUR INCLUT LES STAGIAIRES.

LE COLLABORATEUR EST DOCUMENTÉ DANS LE SYSTÈME RH.

### Concept : Manager

LE MANAGER EST UN SALARIÉ QUI A UNE RESPONSABILITÉ HIÉRARCHIQUE.

LE MANAGER GÈRE UNE ÉQUIPE.

LE MANAGER GÈRE DES SALARIÉS.

LE MANAGER EST RESPONSABLE DE LA PERFORMANCE DE SON ÉQUIPE.

LE MANAGER EST RESPONSABLE DU DÉVELOPPEMENT DE SON ÉQUIPE.

LE MANAGER EST RESPONSABLE DES ENTRETIENS DE SON ÉQUIPE.

LE MANAGER EST RESPONSABLE DES OBJECTIFS DE SON ÉQUIPE.

LE MANAGER EST FORMÉ AU MANAGEMENT.

LE MANAGER EST ÉVALUÉ SUR SA CAPACITÉ DE MANAGEMENT.

### Concept : Équipe

L'ÉQUIPE EST UN GROUPE DE SALARIÉS QUI TRAVAILLENT ENSEMBLE.

L'ÉQUIPE EST DIRIGÉE PAR UN MANAGER.

L'ÉQUIPE A DES OBJECTIFS COMMUNS.

L'ÉQUIPE A DES RESPONSABILITÉS COMMUNES.

L'ÉQUIPE EST RATTACHÉE À UN DÉPARTEMENT.

L'ÉQUIPE EST DOCUMENTÉE DANS L'ORGANISATION.

### Concept : Département

LE DÉPARTEMENT EST UNE UNITÉ ORGANISATIONNELLE DE L'ORGANISATION.

LE DÉPARTEMENT EST DIRIGÉ PAR UN DIRECTEUR.

LE DÉPARTEMENT A DES RESPONSABILITÉS.

LE DÉPARTEMENT A DES OBJECTIFS.

LE DÉPARTEMENT A UN BUDGET.

LE DÉPARTEMENT EST RATTACHÉ À UN ÉTABLISSEMENT.

LE DÉPARTEMENT EST RATTACHÉ À UNE DIRECTION.

LE DÉPARTEMENT EST DOCUMENTÉ DANS L'ORGANISATION.

### Concept : Établissement

L'ÉTABLISSEMENT EST UNE UNITÉ GÉOGRAPHIQUE DE L'ORGANISATION.

L'ÉTABLISSEMENT EST DIRIGÉ PAR UN DIRECTEUR.

L'ÉTABLISSEMENT A DES RESPONSABILITÉS.

L'ÉTABLISSEMENT A DES OBJECTIFS.

L'ÉTABLISSEMENT A UN BUDGET.

L'ÉTABLISSEMENT EST RATTACHÉ À UNE SOCIÉTÉ.

L'ÉTABLISSEMENT EST DOCUMENTÉ DANS L'ORGANISATION.

### Concept : Société

LA SOCIÉTÉ EST UNE ENTITÉ JURIDIQUE DE L'ORGANISATION.

LA SOCIÉTÉ A DES RESPONSABILITÉS.

LA SOCIÉTÉ A DES OBJECTIFS.

LA SOCIÉTÉ A UN BUDGET.

LA SOCIÉTÉ EST RATTACHÉE À UN GROUPE SI APPLICABLE.

LA SOCIÉTÉ EST DOCUMENTÉE DANS L'ORGANISATION.

### Concept : Poste

LE POSTE EST UNE FONCTION SPÉCIFIQUE AU SEIN DE L'ORGANISATION.

LE POSTE EST DÉFINI PAR UNE FICHE DE POSTE.

LE POSTE PEUT ÊTRE VACANT.

LE POSTE EST DOCUMENTÉ DANS L'ORGANISATION.

### Concept : Emploi

L'EMPLOI EST UN TERME GÉNÉRIQUE DÉSIGNANT UN POSTE OU UNE FONCTION.

L'EMPLOI EST UTILISÉ POUR DÉCRIRE LE MARCHÉ DU TRAVAIL.

LA FONCTION EST UN TERME GÉNÉRIQUE DÉSIGNANT UN RÔLE OU UNE ACTIVITÉ.

LA FONCTION EST UTILISÉE POUR DÉCRIRE LES TÂCHES.

LA FONCTION EST UTILISÉE POUR DÉCRIRE LES MISSIONS.

### Concept : Mission

LA MISSION EST UN ENSEMBLE DE TÂCHES ET DE RESPONSABILITÉS.

### Concept : Compétence

LA COMPÉTENCE EST UNE CAPACITÉ À RÉALISER UNE TÂCHE OU UNE ACTIVITÉ DE MANIÈRE EFFICACE.

LA COMPÉTENCE EST UN COMBINAISON DE CONNAISSANCES.

LA COMPÉTENCE EST ACQUISE PAR L'EXPÉRIENCE.

LA COMPÉTENCE EST ACQUISE PAR LA PRATIQUE.

LA COMPÉTENCE EST ÉVALUÉE RÉGULIÈREMENT.

### Concept : Savoir

LE SAVOIR EST L'ENSEMBLE DES CONNAISSANCES THÉORIQUES.

LE SAVOIR EST ACQUIS PAR L'ÉTUDE.

LE SAVOIR EST ACQUIS PAR LA RECHERCHE.

LE SAVOIR EST ÉVALUÉ.

### Concept : Savoir-faire

LE SAVOIR-FAIRE EST L'ENSEMBLE DES CAPACITÉS PRATIQUES.

LE SAVOIR-FAIRE EST ÉVALUÉ.

### Concept : Savoir-être

LE SAVOIR-ÊTRE EST L'ENSEMBLE DES ATTITUDES ET COMPORTEMENTS.

LE SAVOIR-ÊTRE EST ACQUIS PAR LA PRATIQUE.

LE SAVOIR-ÊTRE EST ACQUIS PAR LE DÉVELOPPEMENT PERSONNEL.

LE SAVOIR-ÊTRE EST OBSERVABLE.

LE SAVOIR-ÊTRE EST ÉVALUÉ.

### Concept : Qualification

LA QUALIFICATION EST UN ENSEMBLE DE CRITÈRES REQUIS POUR UN POSTE.

### Concept : Diplôme

LE DIPLÔME EST UNE RECONNAISSANCE OFFICIELLE D'UN NIVEAU D'ÉTUDES.

### Concept : Mobilité

LA MOBILITÉ EST CONFORME AU DROIT DU TRAVAIL.

### Concept : Carrière
