## Ontologie des postes

### Concept : Poste

LE POSTE EST UNE FONCTION SPÉCIFIQUE AU SEIN DE L'ORGANISATION.

LE POSTE EST DÉFINI PAR UNE FICHE DE POSTE.

LE POSTE EST DÉFINI PAR DES RESPONSABILITÉS.

LE POSTE EST DÉFINI PAR DES COMPÉTENCES REQUISES.

LE POSTE EST DÉFINI PAR DES CONDITIONS DE TRAVAIL.

LE POSTE EST DÉFINI PAR UNE RÉMUNÉRATION.

LE POSTE EST CLASSÉ DANS UNE FAMILLE DE POSTES.

LE POSTE EST CLASSÉ DANS UN NIVEAU DE POSTE.

LE POSTE EST RATTACHÉ À UN DÉPARTEMENT.

LE POSTE EST RATTACHÉ À UN MANAGER.

LE POSTE PEUT ÊTRE OCCUPÉ PAR UN SALARIÉ.

LE POSTE PEUT ÊTRE VACANT.

LE POSTE EST DOCUMENTÉ.

LE POSTE EST TRAÇABLE.

### Concept : Famille de postes

LA FAMILLE DE POSTES EST UN GROUPEMENT DE POSTES SIMILAIRES.

LA FAMILLE DE POSTES EST DÉFINIE PAR UN DOMAINE.

LA FAMILLE DE POSTES EST DÉFINIE PAR UNE THÉMATIQUE.

LA FAMILLE DE POSTES CONTIENT DES POSTES LIÉS.

LA FAMILLE DE POSTES EST DOCUMENTÉE.

LA FAMILLE DE POSTES EST TRAÇABLE.

### Concept : Domaine de poste

LE DOMAINE DE POSTE EST UN SECTEUR D'ACTIVITÉ.

LE DOMAINE DE POSTE EST DÉFINI PAR UNE ACTIVITÉ PRINCIPALE.

LE DOMAINE DE POSTE EST DOCUMENTÉ.

LE DOMAINE DE POSTE EST TRAÇABLE.

### Concept : Niveau de poste

LE NIVEAU DE POSTE EST UNE CLASSIFICATION HIÉRARCHIQUE.

LE NIVEAU DE POSTE EST DÉFINI PAR UNE ÉCHELLE.

L'ÉCHELLE INCLUT LE NIVEAU JUNIOR.

L'ÉCHELLE INCLUT LE NIVEAU CONFIRMÉ.

L'ÉCHELLE INCLUT LE NIVEAU SENIOR.

L'ÉCHELLE INCLUT LE NIVEAU LEAD.

L'ÉCHELLE INCLUT LE NIVEAU EXPERT.

L'ÉCHELLE INCLUT LE NIVEAU ARCHITECTE.

LE NIVEAU DE POSTE EST DOCUMENTÉ.

LE NIVEAU DE POSTE EST TRAÇABLE.

### Concept : Responsabilité

LA RESPONSABILITÉ EST UNE TÂCHE OU UNE MISSION ASSIGNÉE AU POSTE.

LA RESPONSABILITÉ EST DÉFINIE DANS LA FICHE DE POSTE.

LA RESPONSABILITÉ EST DOCUMENTÉE.

LA RESPONSABILITÉ EST TRAÇABLE.

### Concept : Condition de travail

LA CONDITION DE TRAVAIL EST UN ÉLÉMENT DÉFINISSANT LE CONTEXTE DE TRAVAIL.

LA CONDITION DE TRAVAIL INCLUT LE LIEU DE TRAVAIL.

LA CONDITION DE TRAVAIL INCLUT LE TEMPS DE TRAVAIL.

LA CONDITION DE TRAVAIL INCLUT LES HORAIRES.

LA CONDITION DE TRAVAIL INCLUT LE TÉLÉTRAVAIL.

LA CONDITION DE TRAVAIL EST DOCUMENTÉE.

LA CONDITION DE TRAVAIL EST TRAÇABLE.

### Concept : Rémunération de poste

LA RÉMUNÉRATION DE POSTE EST LA RÉMUNÉRATION ASSOCIÉE AU POSTE.

LA RÉMUNÉRATION DE POSTE EST DÉFINIE DANS LA FICHE DE POSTE.

LA RÉMUNÉRATION DE POSTE EST DOCUMENTÉE.

LA RÉMUNÉRATION DE POSTE EST TRAÇABLE.

### Concept : Compétence requise

LA COMPÉTENCE REQUISE EST UNE COMPÉTENCE NÉCESSAIRE POUR LE POSTE.

LA COMPÉTENCE REQUISE EST DÉFINIE DANS LA FICHE DE POSTE.

LA COMPÉTENCE REQUISE EST DOCUMENTÉE.

LA COMPÉTENCE REQUISE EST TRAÇABLE.

### Concept : Qualification requise

LA QUALIFICATION REQUISE EST UNE QUALIFICATION NÉCESSAIRE POUR LE POSTE.

LA QUALIFICATION REQUISE EST DÉFINIE DANS LA FICHE DE POSTE.

LA QUALIFICATION REQUISE EST DOCUMENTÉE.

LA QUALIFICATION REQUISE EST TRAÇABLE.

### Concept : Fiche de poste

LA FICHE DE POSTE EST LE DOCUMENT DÉFINISSANT LE POSTE.

LA FICHE DE POSTE INCLUT L'INTITULÉ DU POSTE.

LA FICHE DE POSTE INCLUT LES RESPONSABILITÉS.

LA FICHE DE POSTE INCLUT LES COMPÉTENCES REQUISES.

LA FICHE DE POSTE INCLUT LES CONDITIONS DE TRAVAIL.

LA FICHE DE POSTE INCLUT LA RÉMUNÉRATION.

LA FICHE DE POSTE EST DOCUMENTÉE.

LA FICHE DE POSTE EST TRAÇABLE.

### Concept : Cartographie des postes

LA CARTOGRAPHIE DES POSTES EST LA REPRÉSENTATION VISUELLE DES POSTES.

LA CARTOGRAPHIE DES POSTES INCLUT LES FAMILLES DE POSTES.

LA CARTOGRAPHIE DES POSTES EST DOCUMENTÉE.

LA CARTOGRAPHIE DES POSTES EST TRAÇABLE.
