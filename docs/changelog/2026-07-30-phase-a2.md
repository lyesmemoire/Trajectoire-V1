# Phase A.2 - Runtime Foundation with ReducerRegistry, SnapshotBuilder, Event Envelope, Runtime Hooks

**Date**: 2026-07-30  
**Objectifs**: Améliorer le Runtime avec ReducerRegistry, SnapshotBuilder, Event Envelope complet, Runtime Hooks

## Fichiers créés

- `apps/web/src/lib/ai/contracts/EventEnvelope.ts` - EventEnvelope avec métadonnées complètes
- `apps/web/src/lib/ai/runtime/ReducerRegistry.ts` - ReducerRegistry pour gestion de multiples reducers
- `apps/web/src/lib/ai/runtime/RuntimeHooks.ts` - RuntimeHooks (6 hooks pour telemetry)
- `apps/web/src/lib/ai/runtime/SnapshotBuilder.ts` - SnapshotBuilder pour InvestigationContext immutable
- `tests/phase-a2/runtime-a2-integration.test.ts` - Tests d'intégration A.2

## Fichiers modifiés

- `apps/web/src/domain/cognitive/SnapshotMetadata.ts` - Ajout de version, parentSnapshotId, createdAt, createdBy, traceId, correlationId
- `apps/web/src/lib/ai/runtime/CognitiveRuntime.ts` - Intégration ReducerRegistry, SnapshotBuilder, RuntimeHooks
- `apps/web/src/lib/ai/runtime/DummyEngine.ts` - Ajout EventEnvelope avec traceId/correlationId

## Breaking changes

- `CognitiveRuntime.initialize()` signature modifiée (pas encore utilisée en production)
- `CognitiveRuntime.execute()` retourne maintenant `ExecutionReport` (Phase A.3)
- `SnapshotMetadata` interface étendue avec nouveaux champs

## Tests ajoutés

5 tests d'intégration :
- Deux événements avec même traceId/correlationId
- Snapshots version N et N+1 avec parentSnapshotId correct
- Deux reducers enregistrés et exécutés dans l'ordre
- Moteur émet 3 événements, tous publiés/réduits
- SnapshotBuilder produit InvestigationContext immutable

## Couverture

Tests d'intégration validant les nouveaux composants

## Notes

- Pipeline amélioré : Events → Reducers → Domain State → SnapshotBuilder → InvestigationContext
- Runtime ne connaît pas les reducers concrets (KnowledgeGraphReducer, TimelineReducer, etc.)
- EventEnvelope impose métadonnées complètes dès maintenant pour éviter dette technique
- Runtime Hooks prêts pour telemetry, monitoring, replay, debug sans modifier le Runtime
