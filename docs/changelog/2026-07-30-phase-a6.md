## Notes

- EntityExtractionEngine remplace IdentityEngine (nom plus générique pour tous types d'entités)
- Catalogs évitent que le LLM invente des noms d'entités
- CanonicalEntityResolver normalise : k8s → Kubernetes, js → JavaScript, node → Node.js, aws ecs → Amazon ECS
- EntityExtractionEngine extrait : technologies, entreprises, dates, métriques
- NE fait PAS : inférer compétences, créer preuves, faire des affirmations
- Périmètre minimal : extraction uniquement, pas d'interprétation
- Prépare le pipeline pour Perception et Evidence qui travailleront sur des représentations canoniques
- Ordre pipeline maintenant : Normalizer → EntityExtraction → Perception → Evidence → Contradiction → Temporal → Confidence
