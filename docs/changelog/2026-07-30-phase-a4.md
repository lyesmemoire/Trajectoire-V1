## Notes

- BaseEngine fournit boilerplate : gestion erreurs, timing, validation, construction EngineResult
- Sous-classes n'implémentent que process() - tout le reste est fourni
- PromptRunner centralise retries, télétrie, structured output
- FactBuilder évite construction JSON manuelle dans chaque moteur
- EventFactory évite construction événement manuelle dans chaque moteur
- EngineManifest permet au Scheduler d'utiliser les métadonnées sans connaître les moteurs
- Tous les moteurs futurs (Normalizer, Identity, Perception, Evidence, Contradiction, Temporal, Confidence) hériteront de BaseEngine
