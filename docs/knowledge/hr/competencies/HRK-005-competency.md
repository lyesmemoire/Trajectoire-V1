# HRK-005 — Aptitude

## Identité

HRK-005 EST LE DOCUMENT DE CONNAISSANCE DÉFINISSANT L'APTITUDE DANS LE DOMAINE RH.

HRK-005 EST UN OBJET DE CONNAISSANCE DU CORPUS RH.

HRK-005 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LE CONCEPT D'APTITUDE.

## Définition

UNE APTITUDE EST UNE CAPACITÉ NATURELLE OU ACQUISE À RÉALISER UNE TÂCHE DE MANIÈRE EFFICACE.

L'APTITUDE EST LIÉE AU POTENTIEL INDIVIDUEL.

L'APTITUDE EST LIÉE AUX CAPACITÉS INNÉES.

L'APTITUDE EST LIÉE AUX CAPACITÉS ACQUISES.

L'APTITUDE EST LIÉE AUX TALENTS PERSONNELS.

L'APTITUDE EST LIÉE AUX PRÉDISPOSITIONS.
