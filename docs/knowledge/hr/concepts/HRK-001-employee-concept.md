# HRK-001 — Concept Employé

## Identité

HRK-001 EST LE DOCUMENT DE CONNAISSANCE DÉFINISSANT LE CONCEPT D'EMPLOYÉ DANS LE DOMAINE RH.

HRK-001 EST UN OBJET DE CONNAISSANCE DU CORPUS RH.

HRK-001 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LE CONCEPT D'EMPLOYÉ.

## Définition

UN EMPLOYÉ EST UNE PERSONNE PHYSIQUE LIÉE À L'ORGANISATION PAR UN CONTRAT DE TRAVAIL.

L'EMPLOYÉ EST SOUMIS AU DROIT DU TRAVAIL.

L'EMPLOYÉ EST SOUMIS AUX CONVENTIONS COLLECTIVES.

L'EMPLOYÉ EST SOUMIS AUX POLITIQUES INTERNES DE L'ORGANISATION.

L'EMPLOYÉ EST SOUMIS AUX RÈGLEMENTS INTÉRIEURS.

L'EMPLOYÉ EST SOUMIS AUX ACCORDS D'ENTREPRISE.
