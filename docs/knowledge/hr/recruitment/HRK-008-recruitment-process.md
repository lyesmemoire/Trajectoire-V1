# HRK-008 — Processus de Recrutement

## Identité

HRK-008 EST LE DOCUMENT DE CONNAISSANCE DÉFINISSANT LE PROCESSUS DE RECRUTEMENT DANS LE DOMAINE RH.

HRK-008 EST UN OBJET DE CONNAISSANCE DU CORPUS RH.

HRK-008 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LE CONCEPT DE PROCESSUS DE RECRUTEMENT.

## Définition

LE PROCESSUS DE RECRUTEMENT EST L'ENSEMBLE DES ÉTAPES PERMETTANT DE RECRUTER UN NOUVEL EMPLOYÉ.

LE PROCESSUS DE RECRUTEMENT COMMENCE PAR LE BESOIN DE RECRUTEMENT.

LE PROCESSUS DE RECRUTEMENT SE TERMINE PAR L'INTÉGRATION DU NOUVEL EMPLOYÉ.

LE PROCESSUS DE RECRUTEMENT EST SOUMIS AU DROIT DU TRAVAIL.

LE PROCESSUS DE RECRUTEMENT EST SOUMIS AUX CONVENTIONS COLLECTIVES.

LE PROCESSUS DE RECRUTEMENT EST SOUMIS AUX POLITIQUES INTERNES.

## Étapes du processus de recrutement

### Définition du besoin

LE PROCESSUS COMMENCE PAR LA DÉFINITION DU BESOIN DE RECRUTEMENT.

LE BESOIN DE RECRUTEMENT EST IDENTIFIÉ PAR LE DÉPARTEMENT.

LE BESOIN DE RECRUTEMENT EST VALIDÉ PAR LES RESSOURCES HUMAINES.

LE BESOIN DE RECRUTEMENT EST VALIDÉ PAR LA DIRECTION SI APPLICABLE.

LE BESOIN DE RECRUTEMENT EST DOCUMENTÉ.

LE BESOIN DE RECRUTEMENT EST JUSTIFIÉ.

### Création de la fiche de poste

LA FICHE DE POSTE EST CRÉÉE OU MISE À JOUR.

LA FICHE DE POSTE DÉCRIT LE POSTE À POURVOIR.

LA FICHE DE POSTE DÉCRIT LES RESPONSABILITÉS.

LA FICHE DE POSTE DÉCRIT LES COMPÉTENCES REQUISES.

LA FICHE DE POSTE DÉCRIT LES QUALIFICATIONS REQUISES.

LA FICHE DE POSTE DÉCRIT LES CONDITIONS DE TRAVAIL.

LA FICHE DE POSTE DÉCRIT LA RÉMUNÉRATION.

LA FICHE DE POSTE EST VALIDÉE PAR LES RESSOURCES HUMAINES.

LA FICHE DE POSTE EST VALIDÉE PAR LE DÉPARTEMENT.

### Publication de l'annonce

L'ANNONCE EST PUBLIÉE SUR LES CANAUX APPROPRIÉS.

L'ANNONCE EST PUBLIÉE SUR LES SITES D'EMPLOI.

L'ANNONCE EST PUBLIÉE SUR LES RÉSEAUX SOCIAUX SI APPLICABLE.

L'ANNONCE EST PUBLIÉE SUR LE SITE DE L'ORGANISATION.

L'ANNONCE EST PUBLIÉE PAR LES CABINETS DE RECRUTEMENT SI APPLICABLE.

L'ANNONCE EST PUBLIÉE PAR LE BOUCHE-À-OREILLE SI APPLICABLE.

L'ANNONCE EST CONFORME AUX RÈGLES LÉGALES.

L'ANNONCE EST CONFORME AUX POLITIQUES INTERNES.

### Réception des candidatures

LES CANDIDATURES SONT REÇUES PAR DIFFÉRENTS CANAUX.

LES CANDIDATURES SONT ENREGISTRÉES DANS LE SYSTÈME DE RECRUTEMENT.

LES CANDIDATURES SONT TRIÉES.

LES CANDIDATURES SONT FILTRÉES.

LES CANDIDATURES SONT CLASSÉES.

LES CANDIDATURES SONT DOCUMENTÉES.

### Sélection des candidats

LES CANDIDATS SONT SÉLECTIONNÉS SUR BASE DES CRITÈRES.

LES CRITÈRES DE SÉLECTION SONT DÉFINIS DANS LA FICHE DE POSTE.

LES CRITÈRES DE SÉLECTION INCLUENT LES COMPÉTENCES.

LES CRITÈRES DE SÉLECTION INCLUENT LES QUALIFICATIONS.

LES CRITÈRES DE SÉLECTION INCLUENT L'EXPÉRIENCE.

LES CRITÈRES DE SÉLECTION INCLUENT LES APTITUDES.

LES CRITÈRES DE SÉLECTION SONT OBJECTIFS.

LES CRITÈRES DE SÉLECTION SONT DOCUMENTÉS.

### Entretiens

LES CANDIDATS SÉLECTIONNÉS SONT CONVÉS À DES ENTRETIENS.

LES ENTRETIENS SONT CONDUITS PAR LES RESSOURCES HUMAINES.

LES ENTRETIENS SONT CONDUITS PAR LE DÉPARTEMENT.

LES ENTRETIENS SONT CONDUITS PAR LE MANAGER SI APPLICABLE.

LES ENTRETIENS SONT STRUCTURÉS.

LES ENTRETIENS SONT DOCUMENTÉS.

LES ENTRETIENS SONT ÉVALUÉS.

LES ENTRETIENS SONT BASÉS SUR DES CRITÈRES PRÉDÉFINIS.

### Tests d'évaluation

LES CANDIDATS PEUVENT ÊTRE SOUMIS À DES TESTS.

LES TESTS PEUVENT ÊTRE DES TESTS DE COMPÉTENCES.

LES TESTS PEUVENT ÊTRE DES TESTS D'APTITUDES.

LES TESTS PEUVENT ÊTRE DES TESTS DE PERSONNALITÉ.

LES TESTS PEUVENT ÊTRE DES TESTS TECHNIQUES.

LES TESTS SONT STANDARDISÉS.

LES TESTS SONT VALIDÉS.

LES TESTS SONT DOCUMENTÉS.

### Vérification des références

LES RÉFÉRENCES DES CANDIDATS SONT VÉRIFIÉES.

LES RÉFÉRENCES INCLUENT LES EMPLOYEURS PRÉCÉDENTS.

LES RÉFÉRENCES INCLUENT LES FORMATIONS.

LES RÉFÉRENCES INCLUENT LES CERTIFICATIONS SI APPLICABLE.

LES RÉFÉRENCES SONT CONTACTÉES.

LES RÉFÉRENCES SONT DOCUMENTÉES.

LES RÉFÉRENCES SONT CONFIDENTIELLES.

### Offre d'emploi

L'OFFRE D'EMPLOI EST FAITE AU CANDIDAT SÉLECTIONNÉ.

L'OFFRE D'EMPLOI INCLUT LE POSTE.

L'OFFRE D'EMPLOI INCLUT LA RÉMUNÉRATION.

L'OFFRE D'EMPLOI INCLUT LES AVANTAGES.

L'OFFRE D'EMPLOI INCLUT LES CONDITIONS DE TRAVAIL.

L'OFFRE D'EMPLOI INCLUT LA DATE DE DÉBUT.

L'OFFRE D'EMPLOI EST DOCUMENTÉE.

L'OFFRE D'EMPLOI EST SIGNÉE PAR LE CANDIDAT.

L'OFFRE D'EMPLOI EST SIGNÉE PAR L'ORGANISATION.

### Intégration

LE NOUVEL EMPLOYÉ EST INTÉGRÉ DANS L'ORGANISATION.

L'INTÉGRATION INCLUT L'ONBOARDING.

L'INTÉGRATION INCLUT LA FORMATION INITIALE.

L'INTÉGRATION INCLUT LA PRÉSENTATION DE L'ÉQUIPE.

L'INTÉGRATION INCLUT LA PRÉSENTATION DE L'ENVIRONNEMENT DE TRAVAIL.

L'INTÉGRATION INCLUT LA REMISE DES DOCUMENTS.

L'INTÉGRATION EST DOCUMENTÉE.

L'INTÉGRATION EST ÉVALUÉE.

## Obligations légales

### Égalité de traitement

LE PROCESSUS DE RECRUTEMENT DOIT RESPECTER L'ÉGALITÉ DE TRAITEMENT.

LE PROCESSUS DE RECRUTEMENT NE DOIT PAS DISCRIMINER.

LE PROCESSUS DE RECRUTEMENT NE DOIT PAS DISCRIMINER SUR LE GENRE.

LE PROCESSUS DE RECRUTEMENT NE DOIT PAS DISCRIMINER SUR L'ÂGE.

LE PROCESSUS DE RECRUTEMENT NE DOIT PAS DISCRIMINER SUR L'ORIGINE.

LE PROCESSUS DE RECRUTEMENT NE DOIT PAS DISCRIMINER SUR LA RELIGION.

LE PROCESSUS DE RECRUTEMENT NE DOIT PAS DISCRIMINER SUR LE HANDICAP.

LE PROCESSUS DE RECRUTEMENT NE DOIT PAS DISCRIMINER SUR L'ORIENTATION SEXUELLE.

### Protection des données personnelles

LE PROCESSUS DE RECRUTEMENT DOIT RESPECTER LA PROTECTION DES DONNÉES PERSONNELLES.

LES DONNÉES PERSONNELLES DES CANDIDATS DOIVENT ÊTRE PROTÉGÉES.

LES DONNÉES PERSONNELLES DES CANDIDATS DOIVENT ÊTRE CONSERVÉES CONFORMÉMENT À LA LOI.

LES DONNÉES PERSONNELLES DES CANDIDATS DOIVENT ÊTRE DÉTRUITES APRÈS LE DÉLAI LÉGAL.

LES CANDIDATS DOIVENT ÊTRE INFORMÉS DE LEURS DROITS.

LES CANDIDATS DOIVENT CONSENIR À L'UTILISATION DE LEURS DONNÉES.

### Obligations de transparence

LE PROCESSUS DE RECRUTEMENT DOIT ÊTRE TRANSPARENT.

LES CRITÈRES DE SÉLECTION DOIVENT ÊTRE COMMUNIQUÉS.

LES ÉTAPES DU PROCESSUS DOIVENT ÊTRE COMMUNIQUÉES.

LES CANDIDATS DOIVENT ÊTRE INFORMÉS DU STATUT DE LEUR CANDIDATURE.

LES CANDIDATS DOIVENT ÊTRE INFORMÉS DES MOTIFS DE REFUS SI APPLICABLE.
