# HRK-007 — Département

## Identité

HRK-007 EST LE DOCUMENT DE CONNAISSANCE DÉFINISSANT LE DÉPARTEMENT DANS LE DOMAINE RH.

HRK-007 EST UN OBJET DE CONNAISSANCE DU CORPUS RH.

HRK-007 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LE CONCEPT DE DÉPARTEMENT.

## Définition

UN DÉPARTEMENT EST UNE UNITÉ ORGANISATIONNELLE AU SEIN DE L'ORGANISATION.

LE DÉPARTEMENT EST REGROUPÉ PAR FONCTION.

LE DÉPARTEMENT EST REGROUPÉ PAR MÉTIER.

LE DÉPARTEMENT EST REGROUPÉ PAR PROJET.

LE DÉPARTEMENT EST RATTACHÉ À L'ORGANISATION.

LE DÉPARTEMENT EST RATTACHÉ À LA DIRECTION GÉNÉRALE.
