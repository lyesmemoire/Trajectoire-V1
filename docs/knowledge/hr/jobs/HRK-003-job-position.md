# HRK-003 — Poste de Travail

## Identité

HRK-003 EST LE DOCUMENT DE CONNAISSANCE DÉFINISSANT LE POSTE DE TRAVAIL DANS LE DOMAINE RH.

HRK-003 EST UN OBJET DE CONNAISSANCE DU CORPUS RH.

HRK-003 EST UTILISÉ PAR LE MOTEUR COGNITIF POUR COMPRENDRE LE CONCEPT DE POSTE DE TRAVAIL.

## Définition

UN POSTE DE TRAVAIL EST UNE FONCTION SPÉCIFIQUE AU SEIN DE L'ORGANISATION.

LE POSTE DE TRAVAIL EST LIÉ À UNE DESCRIPTION DE POSTE.

LE POSTE DE TRAVAIL EST LIÉ À DES RESPONSABILITÉS.

LE POSTE DE TRAVAIL EST LIÉ À DES QUALIFICATIONS REQUISES.
