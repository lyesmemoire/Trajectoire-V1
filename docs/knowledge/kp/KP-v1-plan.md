# Knowledge Pack RH v1

## Identité

CE DOCUMENT DÉFINIT LE PROGRAMME DE CONSTRUCTION DE LA MÉMOIRE COGNITIVE RH.

LE KNOWLEDGE PACK RH V1 EST LA PREMIÈRE BASE DE CONNAISSANCES MÉTIER RH UTILISABLE PAR LE MOTEUR COGNITIF.

LE KNOWLEDGE PACK RH V1 EST INDÉPENDANT DE TOUTE IMPLÉMENTATION TECHNIQUE.

LE KNOWLEDGE PACK RH V1 EST VERSIONNÉ.

LE KNOWLEDGE PACK RH V1 EST TRAÇABLE.

LE KNOWLEDGE PACK RH V1 EST EXTENSIBLE.

## Objectif

CONSTRUIRE LA PREMIÈRE BASE DE CONNAISSANCES MÉTIER RH UTILISABLE PAR LE MOTEUR COGNITIF.

LA BASE DOIT CONSTITUER LA SOURCE DE RÉFÉRENCE POUR L'ENSEMBLE DES TRAITEMENTS RH DU MVP.

## Règles de qualité

CHAQUE ÉLÉMENT DOIT POSSEDER :

- UN IDENTIFIANT STABLE
- UNE DÉFINITION NORMATIVE
- DES SYNONYMES
- UN DOMAINE
- UN NIVEAU DE MATURITÉ
- UNE PROVENANCE
- UNE DATE DE CRÉATION
- UNE DATE DE MISE À JOUR
- UN STATUT DE VALIDATION
- DES RELATIONS EXPLICITES AVEC LES AUTRES ÉLÉMENTS

## Objectif MVP

À LA FIN DU CHANTIER KNOWLEDGE PACK RH V1, LE MOTEUR DEVRA ÊTRE CAPABLE DE :

- COMPRENDRE UN CV
- COMPRENDRE UNE FICHE DE POSTE
- RECONNAÎTRE LES COMPÉTENCES MÊME LORSQU'ELLES SONT EXPRIMÉES DIFFÉREMMENT
- IDENTIFIER LES COMPÉTENCES TRANSFÉRABLES
- DÉTECTER LES COMPÉTENCES MANQUANTES
- EXPLIQUER UN SCORE DE MATCHING EN S'APPUYANT SUR LES CONNAISSANCES DU RÉFÉRENTIEL
