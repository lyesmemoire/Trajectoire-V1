## Component Dependencies

### Bootstrap Layer

- Engine depends on: Container, Application Layer
- Container depends on: Domain Layer, Application Layer, Infrastructure Layer

### Integration Layer

- InterviewEventHandler depends on: Domain Events, EventPublisher
- InterviewIntegration depends on: Use Cases, Ports

### Application Layer

- Use Cases depend on: Domain Layer, Ports
- Application Services depend on: Domain Layer, Ports
- Ports are interfaces (no dependencies)

### Domain Layer

- Aggregates depend on: Entities, Value Objects, Domain Services, Policies
- Entities depend on: Value Objects
- Domain Services depend on: Value Objects, Policies
- Policies depend on: Value Objects
- Domain Events are independent

### Infrastructure Layer

- Adapters depend on: Ports, Clients, Configuration
- Clients depend on: Configuration
- Mappers depend on: Domain Layer
- Configuration is independent
