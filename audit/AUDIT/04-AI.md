# 04 - Audit IA (Core)

- **Modèles** : Mistral-Small (ATS), Mistral-Large (Simulations).
- **Prompting** : Les prompts ont grandi organiquement. Ils méritent d'être modularisés (séparation Instruction / Format / Contexte).
