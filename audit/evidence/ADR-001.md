# Architecture Decision Record (ADR)
**ID**: ADR-001
**Title**: Sécurisation des RLS financiers et ATS
**Date**: 2026-07-30
**Status**: Accepted

## 1. Context
Les tables `credit_transactions`, `credit_usage`, `stripe_events`, `idempotency` et `cv_rewrites` sont actuellement exposées avec une politique `USING (true)` / `WITH CHECK (true)` pour le rôle `public`.
Cela représente un risque de sécurité critique (RSK-001), permettant à tout utilisateur authentifié ou non (via API REST publique) de lire, modifier ou insérer des données financières ou d'autres utilisateurs.

## 2. Decision
Nous mettons en place la migration `20260730000005_strict_rls.sql`.
Les règles suivantes seront appliquées :
- Les tables financières (`credit_transactions`, `credit_usage`, `stripe_events`, `idempotency`) seront totalement bloquées pour les requêtes client (`anon`, `authenticated`). Seul le rôle `service_role` (Backend) ou les fonctions `SECURITY DEFINER` (RPC) y auront accès.
- La table `cv_rewrites` bloquera les insertions directes par le client (gérées par le backend via la clé d'idempotence), mais permettra au client de `SELECT` ses propres analyses (`auth.uid()::text = user_id`).
- La table `User` et la vue `profiles` s'assurent que `auth.uid()::text = id` pour toute mutation.

## 3. Alternatives Considered
- *Faire des RPC pour la lecture client* : Trop complexe pour l'existant. Permettre le `SELECT` avec `auth.uid()` sur `cv_rewrites` est le standard Supabase.
- *Modifier le client web pour utiliser une API backend au lieu du client Supabase direct* : Impossible dans le temps imparti sans réécrire l'architecture de données existante.

## 4. Consequences
- Impossible de tricher sur les crédits depuis le navigateur.
- Les Webhooks Stripe ne peuvent être insérés que via la clé de service.
- Réduit la surface d'attaque à zéro sur les tables transactionnelles pures.

## 5. Rollback Plan
La migration contiendra sa clause de `DOWN` remettant les tables en `USING(true)` si nécessaire. Un test `UP -> DOWN -> UP` sera validé en staging.
