- [ ] 🔴 **Simulation Realtime — pipeline de rapport cassé, pas juste "Map à persister"**. Diagnostic complet fait le 2026-09-29 (aucun code écrit, périmètre trop gros pour ce soir) :
  - `realtimeSessions` (Map exportée dans `api/interview/realtime-session/route.ts`) n'est **jamais lue** nulle part (grep récursif confirmé) — écrite une fois, jamais consultée. Le commentaire du fichier ("même map que `/api/interview/route.ts`, on exporte pour partager") est faux : cette dernière a sa propre `Map` privée et distincte (`const sessions = new Map(...)`, non exportée).
  - `simulation/[id]/page.tsx` (`handleEnd`) appelle `POST /api/interview { action:'COMPLETE', session_id: <id DB interview_sessions> }` pour clôturer. `getSession()` (`api/interview/route.ts:271-277`) cherche cet id dans sa Map privée, ne le trouve jamais (le kernel Realtime a été créé sous un id `rt_...` différent, dans l'autre Map), et **throw** `Session introuvable`. L'erreur est avalée silencieusement côté client (`catch { /* redirige quand meme */ }`) et redirige vers `/report/<id>` quand même.
  - **Plus grave, trouvé en creusant** : `POST /api/interview` entier renvoie **404 en production** (`app/api/interview/route.ts:22-27`, gate `NODE_ENV === 'production'`), avant même d'atteindre `getSession()`. Donc un correctif qui relie juste `getSession()` à la DB (plan initialement approuvé) **ne change rien en prod** — utile seulement en dev.

Aucun appel à `/api/report/generate` n'a lieu dans ce flux.
  - **Conclusion** : en production, un entretien Realtime ne laisse aujourd'hui **aucune trace exploitable** en base (`interview_sessions.score`/`feedback`/`analysis` jamais renseignés pour ce flux). Ce n'est pas un problème de fiabilité d'une `Map` en mémoire à remplacer par Redis — c'est l'intégralité du pipeline de complétion/rapport du flux vocal qui n'a jamais été raccordée. Chantier de la taille de l'« Option B » (aligner le flux Realtime sur le flux texte tour par tour), pas un fix ponctuel. Prochaine session : partir de ce diagnostic, ne pas répéter l'investigation.
